## 复现

`python3 art-source/campaign20/slice.py`

源PNG始终不覆盖；切片采用透明度代价最小接缝切行列，保留原图坐标到 `slice-ledger.json`，8px atlas间隔，低于24 alpha去背景残留。张郃出招超出标准格的枪尖有显式列分界控制。低于主体4.5%面积的离散源图投射物不烘焙到角色帧，真实箭矢由运行时表现。

钩镰枪收势初始生成错持短刀，已对该角色用内置图片编辑工具重绘为完整钩镰枪，固定源 `goulianqiang-rec-fixed.png`；不使用初始错误帧。`fixed-review.png`展示张郃出招/收势、夏侯渊收势和修正后的主将钩镰枪。

源图出处和SHA见 `provenance.json`。`qa-0.jpg`至`qa-5.jpg`来自最终切片浅色背景检查；`contact-sheet.jpg`为总表；`map-review.jpg`为5段总览。它们均为资源QA，不是正式运行截图。

## 真实验收边界/未覆盖

- 逐帧看过最终6页资源QA。新人物头、躯干、双腿和持械轮廓完整；未发现半身或漂浮肢体。唯一原图边接触是敌盾兵蓄势红缨在源图顶端1像素处，未截断头部/肢体。
- 每个角色有1个跑动姿态，不是4帧跑步循环。实际步态/位移依赖游戏表现层，不能宣称交付了4帧跑步。
- 新坐骑图自带长枪，不能再叠出第二把完整兵器；未绘制16种兵器×2坐骑的独立组合。此限制已通知战斗代理，最终验收应具体列明，不能用待用户审美认可替代。
- 图标、角色、山河资源制作与切片通过不代表手机阅读性/地图接缝/战斗动作时点已经通过。须看正式构建绑定本版指纹的截图和录像。
- 各姿态 `bh` 是同一切片高度88%的初始绘制比例；若正式运行发现同角色体量不一致，需要依据正式画面校正，不能只凭资源板判通过。

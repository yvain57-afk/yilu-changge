# 定向单帧正确性素材（2026-10-01，第二种制作方法）

## 已实际核对的最小完整组

- 十二名新增人物：各2个独立支撑脚姿态，`r27_char_{id}_run0/run1`。run0引用其既有正确人物帧，run1是只修改腰部以下的新生成图。所有12组均逐组查看过，低脚从一侧切换到另一侧，高脚收起；服装、脸、武器保持对应人物身份。
- 这是真实两相步态，不是四个独立相，不用0/1/0/1改名冒称4相。原wind/rel/rec继续既有动作。步频仍由原时间相位驱动，不能改人物速度/攻击时点。
- 蓝披风主将：双手弩、双持、拉弓3类空手身体，各2个真实腿相；由原 `g_ios_gait0/1` 单帧编辑双臂，腿部保留。每帧两只手露出，附两手握点及14×14手指遮挡片。取代把左手持械固定在披风坐标的估值。
- 朝右诸葛连弩/机关弩独立道具：保留虎面金属连弩与木制齿轮机关弩区别。后握点与前支撑点分开，QA红点/黄点已实际查看。

## 接入合同

`frame-map.json` 是本组独立增量；不要覆盖根目录r26映射。`gait-contract.json`、`body-sockets.json`、`crossbow-contract.json` 给出角色与帧、握点和遮挡数据。新资源均为 `assets/resources/formal20260927/r27-*.png`，旧素材不改。

双手弩必须用 `two-grip-fit.ts` 的刚体两点匹配：先把后手/前手变换到角色空间，再按道具两握点求缩放和角度。只按第一只手做贴图、再额外加攻击旋转会使支撑手悬空。道具只画一次，最后盖两手遮挡片；可以移动整个上身+道具组合，但不能改变击中/射击时点。

动态肢体和武器必须跟随真实动画状态；两相跑步不替代攻击。新帧包含持械的人物不再附加完整持械图层；空手主将才挂独立兵器。所有角色只有一个body角色。

## 实际方法与剩余边界

第一批四张大图生成无法保持反向支撑脚，已留失败记录。这次改为每个角色单独输入原始run帧，明确图左/图右哪条腿收起、哪条腿落地；太史慈/黄月英小样看到成功后才扩展其余10名。没有从同一帧复制改名，无付费外部API。

已核对的是源图和切片，不是正式iPhone运行。尚需主代理在整备/战斗/骑乘切换中验证：两相播放无比例跳变、前后手接触、握持遮挡、武器边缘、动作节奏。没有把正式运行或B10所有组合标成通过。两相步态比四相更粗，四相中间过渡帧没有生成。

复现：`python3 art-source/regression-20261001/pose-targeted/pack.py`。只切片/归一化尺寸并生成独立r27图集；不改共享源码、存档或规则。

最终冻结清单：3张图集45帧（24人物腿相 + 6空手身体 + 12手部cap + 3弩/弓道具）。新增 r27_held_yanlinggong 是箭头朝右的已拉弦弓；其rearGrip是拉弦点、supportGrip是弓把，仍可用同一双点匹配函数。实际看过完整弓与箭头，不能沿用原朝左图标当朝右持械。旧赤兔/的卢另开 oldmounts-targeted 增量，不会继续改本45帧纹理。

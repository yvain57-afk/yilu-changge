# 战斗骑乘前进视角 · 2026-10-04

本轮实际通过内置 imagegen 生成，先生成惊帆棕马 8 帧，再以同一图集为编辑输入生成的卢白马、绝影黑马、赤兔红马。四份原始 RGBA PNG 均保留在本目录。没有调用外部 CLI/API，没有通过程序绘制替代人物、马或步态。

## 真实接入

- `assets/scripts/formal/WeaponPresentation.ts`：新增 `resolveBattleWeaponPresentation`。战斗使用新后背行进视角；整备/菜单仍调用原 `resolveWeaponPresentation`。
- `assets/scripts/formal/BattleFeelArt.ts`：32 个骑乘帧、实际手部/脚底/骨盆锚点和源图 SHA。
- `assets/resources/formal20260927/feel-mounted-*.png`：4 份真实图集。每份 4 个不同腿部步态、蓄势、出手、收势、受击。
- 原有 16 件兵器继续使用各自已接入资源、图标和发射身份；没有以一把通用兵器冒充。
- 兵器单独绘制并朝向行进方向。背面视角将远端握持兵器放在骑手之前绘制，使身体/披风自然遮挡手臂前方的部分，不在身体上悬浮叠加兵器。

## 生成与切片的边界

`pack-mounted.py` 是可复现的后处理脚本，只做切片、alpha 连通域归属、图集排列和元数据生成，不改造姿态或绘制马腿。只保留本格占 5 万余像素的完整角色主连通域及两像素抗锯齿边缘；删除孤立背景残点。本轮被删除的非主连通域最大 9 像素；未删除任何大部件。

所有帧保留 448×448 固定画布、424 身体参考高和手工核对的脚底位置，腾空相不是把原画重复缩放。`mounted-*-anchors.jpg` 供源图核对：青点为脚底，红圈为右拳；它不是游戏运行截图。

随后再通过内置 imagegen 制作 48 个专用后背远程姿态：4 马 × 诸葛连弩/雁翎弓/机关弩 × 行进准备/蓄势/出手/收势。`BattleFeelRangedArt.ts` 与 `feel-ranged-*.png` 真实接入。弩由双手握持、弓为左持右拉；图像自身含对应兵器，代码不再叠加第二把。原有武器ID/图标/攻击/伤害/声音未改。

**具体未完成项**：远程三类目前各有一个独立 run 身体帧及三攻击身体姿态，未补成四相独立 run；受击沿用收势身体叠加已生效的局部受击反馈，不冒称有三远程专用受击图。近战四相跑步/风姿/出手/收势/受击不受此限制。最终运行验证另附新代码指纹，首轮失败截图不改标。

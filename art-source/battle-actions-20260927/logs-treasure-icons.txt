## Usage Examples

### Generate an image
```bash
npx muapi image generate --prompt "minimalist golf course at sunrise, cinematic lighting"

```

```bash
npx muapi video generate \
  --prompt "close-up of golf swing in slow motion, golden hour" \
  --model seedance-2 \
  --duration 5 \
  --view
```

### Image-to-video
```bash
npx muapi video i2v \
  --image ./product.jpg \
  --prompt "product rotating slowly, studio lighting" \
  --model seedance-2 \
  --view
```

### AI Clipping (long video → shorts)
```bash
npx muapi video clip \
  --input ./long-video.mp4 \
  --count 3 \
  --aspect 9:16 \
  --view
```

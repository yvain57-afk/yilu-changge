- 工具：Stable 2.02.2608060；基础库 3.17.3；iPhone 12/13 (Pro) 模拟器，390×844。
- 身份：由开发者工具“测试号”入口分配小游戏测试 AppID；不是引擎的 touristappid，也没有借其他业务项目身份。不使用云服务。
- Cocos 3.8.8 微信小游戏构建通过（引擎退出码 36）；源码类型检查通过。

- 修复后的错误日志仍有微信 `WAGame.js` 的 `jsbridge not ready` 初始化错误；首页正常显示，尚未确认其对其他能力的影响。没有删除错误或称控制台零错误。
- 没有运行旧十局/长稳脚本，没有重录三关视频；未进行手机扫码、上传体验版或正式发布。

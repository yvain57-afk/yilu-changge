# 本轮构建与包体修复

Cocos 3.8.8 曾两次退出 36 但微信包的场景与 resources 为空。首次人工发现，第二次由新增输出校验改判退出 34。没有上传这些空包。分别保留 `.cache/v051-import-before-repair`、`-2`，将导入缓存与 library 移到备份后重新导入，最终场景及 v051 两张图集齐备。

首次有效构建为 25.4 MB，预览被微信 80051 拒绝（24,824 KB，限 20 MB）。设置 packOptions.ignore 后再次被同样大小拒绝，说明本次小游戏预览没有应用该排除表。随后只将已确认不被本版加载的旧图与停用曲目，从生成的 native 目录移到 `.cache` 备份；源图和音频仍完整保留。最终实际包体约 19.86 MiB，成功生成预览二维码。

原始失败回执和本地 AppID 保存在 .cache / 忽略文件中。本说明不含账户凭证；成功回执摘要为 phone-preview.json。最终产物指纹排除本地 project.config.json / project.private.config.json。

资源加载枚举改动后，100 项快速测试与类型检查重新通过。自然流程录像使用最终 Web 包。密集夹具只执行一次，结果属于移除旧晋升图集加载之前的同轮构建，未作为手机性能结论。

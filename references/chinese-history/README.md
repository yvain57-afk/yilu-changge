1. GPT 先读 [阅读指南](GPT_GUIDE.md)，再按 [目录](INDEX.md) 选择时期和讲次，避免声称一次读完未实际打开的材料。
2. [汉代综述](notes/02-%E6%9C%9D%E4%BB%A3%E4%B8%8E%E6%97%B6%E6%9C%9F/%E6%B1%89.md)、[唐代综述](notes/02-%E6%9C%9D%E4%BB%A3%E4%B8%8E%E6%97%B6%E6%9C%9F/%E5%94%90.md) 可作为西汉、唐关卡的阅读起点。汉代综述同时涉及西汉与东汉，不能混用制度和时间。
3. 先秦、战国素材不能由秦代篇目代替。本存档没有独立的战国综述；首关仍需补充对应地域与时代的博物馆、考古和学术资料。
4. 原稿保留 Obsidian `[[双链]]`，GitHub 不会将其自动渲染为链接。请用本目录的新索引跳转，它已提供标准 Markdown 链接。

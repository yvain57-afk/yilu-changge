# 清

## 时期总命题

清朝前中期的强大来自把满洲八旗的征服组织、蒙古联盟、汉地官僚财政和藏传佛教权威编成一套多中心帝国。努尔哈赤从明朝边防和女真竞争的裂缝中壮大，皇太极用八旗扩编、满汉蒙人才和“中国皇帝”语言为入关准备条件；真正积极设计灭明与治理汉地方案的，又常是归附的汉官。入关后的屠杀、圈地、投充、逃人法和剃发制造深重创伤，顺治式征服政策经康熙的政治整合才逐步转向常规统治。康熙用三藩、台湾、雅克萨、蒙古和西藏的一连串危机训练国家，把战争结果固化为盟旗、将军、办事大臣、条约和宗教册封。雍正不擅长边疆战争，却以秘密立储、密摺、军机处、耗羡归公、养廉银和摊丁入亩重建信息、财政与官僚执行。乾隆继承制度、抓住准噶尔内乱完成陆疆扩张，又在人口激增、财政公私分裂和统治焦虑中，以南巡、文字狱、一口通商与自我颂扬把强控制推向僵化。所谓康乾盛世因此不是虚构，也不是全民富足：疆域、财政、人口和行政能力达到高峰，人均贫困、生态透支、文化窒息和对外封闭也在同一结构中成长。

## 七组问题

### 一、满洲政权如何从边疆力量变成入关竞争者

- [[286-女真崛起：努尔哈赤如何在明朝的边防裂缝中壮大]]、[[287-立国之战：萨尔浒之战明军为何惨败？]]：明朝以羁縻、贸易和女真制衡治理东北；努尔哈赤整合组织，萨尔浒又让分兵明军被集中击破。
- [[288-怀柔蒙汉：皇太极如何稳固自己的权力？]]：皇太极扩展八旗、吸纳蒙古与汉人技术人才，把宗族共治逐步转成汗权主导。
- [[289-问答：如何评价袁崇焕、毛文龙（上）？]]、[[290-问答：如何评价袁崇焕、毛文龙（下）？]]：辽东防线、海岛牵制与皇帝用人互相冲突，英雄或奸臣标签遮蔽组织位置。
- [[291-扫荡中原：皇太极的野心如何被撩拨起来？]]、[[292-亡明之心：积极鼓吹灭掉明朝的是谁？]]：绕道入塞显示明朝腹地可袭，降清汉官又把军事机会翻译成征服中国的制度方案。
- [[293-灭明之道：松锦大战明军如何失败？]]、[[294-清兵入关：吴三桂降清是因为陈圆圆吗？]]：松锦把明军后勤、指挥与财政脆弱集中暴露；山海关选择来自多方压力而非爱情传奇。

### 二、明清鼎革怎样从征服转成统治

- [[296-桃花扇底：南明为何只撑了十八年？]]、[[297-永历之死：内斗亡国的最终章]]：南明并非毫无资源，而是多中心合法性、党争与军头竞争持续消耗动员能力。
- [[298-满汉之间：首崇满洲与五大弊政]]：剃发、圈地、投充、逃人法等把征服成本压向汉民，首崇满洲又是少数统治者安全感的制度表达。
- [[299-康乾盛世：民间故事和教科书里的高精力皇帝]]：康熙的魅力和勤勉真实，却需与官方塑造、个人能力边界和制度遗产分开。
- [[301-彩云之南：撤藩之战如何重塑云南]]、[[302-淳朴旧制：三藩之乱为何延续了八年]]：三藩是入关合作形成的半独立军事财政体，撤藩触发战争，胜利又使西南进入更直接治理。
- [[303-博学鸿儒：从民怨爆发到满汉平衡]]、[[305-问答：清朝修的《明史》，是不是抹黑明朝了？]]：清廷用科举、修史和遗民吸纳重建满汉合作，同时划定建州与南明叙事禁区。

### 三、台湾与海洋网络怎样进入清朝版图

- [[304-海上帝国：一个被招安的海盗如何影响台湾命运]]：郑芝龙以海贸、武装和跨国网络建立东亚海上力量，清廷征服思维却不能理解其交易价值。
- [[306-遐荒孤臣：郑成功收复台湾]]：北伐失败和补给困局促使郑成功转向台湾；组织经验与技术学习战胜荷兰殖民守军和棱堡。
- [[307-台湾设府：郑克塽降清]]：迁海造成沿海浩劫却封锁有限，清廷最终靠平三藩、建水师、用姚启圣施琅和明郑内斗攻台设府。
- [[310-问答：关于郑成功的传说]]：台湾神明、荷兰恶魔、日本武士和近代民族英雄反映各自需要，天地会源流不能由传说倒推。

### 四、清俄、蒙古、西藏与新疆为何是一个边疆系统

- [[308-国际条约：清朝前、中期是怎么治理东北的]]：《尼布楚条约》以多语“中国”和主权国界处理清俄冲突，雅克萨局部胜利却可能制造军事错觉。
- [[309-三分蒙古：噶尔丹崛起]]、[[311-蒙藏牵连：三征噶尔丹]]：漠南、漠北、漠西并非统一主体；康熙以战场、庇护和多伦会盟把喀尔喀纳入盟旗。
- [[312-驱准保藏：清代中前期的西藏问题]]：准噶尔入藏失去民心后，清廷以护送七世达赖填补权力真空，再用驻藏、摄政与金瓶掣签制度化。
- [[313-犁庭扫穴：乾隆如何平定准噶尔？]]：雍正猜忌前线、八旗衰退；乾隆抓住准噶尔继承内乱，以残酷征发和宗教动员完成灭国。
- [[314-治理边疆：清朝如何治理辽阔的疆域？]]：将军、办事大臣、因俗而治和分而治之强化中央控制，也用人口隔离与限制开发制造长期隔阂。

### 五、传教士与全球公司提供了什么新接口

- [[295-问答：传教士是怎么把西方文化引入中国的？]]、[[315-问答：传教士的记录有什么价值？]]：传教士通过翻译和技术进入皇权网络，其日常、边疆和仪式记录珍贵，却因依附私人保护而难社会化。
- [[300-问答：“东印度公司”是怎么来的？]]：公司是国家授权、武装、垄断与股权融资的混合体，不是普通商业企业。

### 六、雍正怎样重建皇权、财政与官场

- [[316-九王夺嫡：康熙为什么选了雍正]]：康熙混合早立太子与实战培养，制造高素质夺嫡；胤禛以行政能力和不站队进入接班位置。
- [[317-秘密政治：秘密立储、密摺和军机处]]：秘密继承阻断新中心，密摺逆转信息差，军机处以贴身执行加速行政，也把权力压到皇帝个人。
- [[318-耗羡归公：雍正如何重塑大清财政与官场]]：先换执行者，再把灰色耗羡纳入藩库、用养廉银合法化行政成本，才使反腐与转移支付可行。
- [[319-人口爆炸：乾隆盛世，为什么普通百姓很穷？]]：摊丁入亩、广域户籍、移民和新作物推动人口；总量高峰同时造成低人均与生态透支。
- [[320-答疑：怎样培养一个合格的皇帝？]]：皇家无法复制世家掐尖，道、法、术中政治实践最必要却也最威胁在位君主。

### 七、乾隆为什么把强大推成僵化

- [[321-书生皇帝：乾隆“宽缓之政”的真相]]：政治经验有限的乾隆迅速从宗室放权转向收权，以孤立元老、绕过督抚和选择性继承建立个人控制。
- [[322-六下江南：乾隆为何反复南巡？]]：南巡把治河、反腐、孝亲、军事威慑、免赋和文化表演组合成移动政治剧场。
- [[323-文字之祸：康雍乾三朝，文字狱为何愈演愈烈？]]：人口和仕途压力削弱信任，文字狱、四库删改与自我审查把显性惩罚变成日常心理。
- [[324-十全影帝：大清为何在巅峰时刻走向僵化？]]：不完全财政、内务府私财、高支出与完美叙事制造越反越贪；害怕社会失控又让开放与调整失去空间。
- [[325-西洋镜像：西方人怎样评价帝制中国？]]：课程收束提醒，外部赞美与批判随观察者处境变化，不能代替对清朝具体制度交换的检验。

## 六条贯穿线索

### 征服联盟必须转成常规制度

八旗、降将、三藩和海上势力能快速扩张，却各自保留利益与武装。清廷通过撤藩、设府、科举修史和财政官僚化把临时联盟拆成常规统治，转换过程本身就是最危险的战争期。

### 多元帝国靠接口而非同质化运转

盟旗连接蒙古，达赖班禅与活佛连接藏传佛教，将军和办事大臣连接边疆，汉官和科举连接内地，传教士连接欧洲知识。清朝强大在能切换接口，代价是刻意保持群体分隔。

### 信息能力是康雍乾统治差异的核心

康熙善于现场观察、人物魅力和多线外交；雍正把密摺、朱批、军机处做成制度；乾隆继承信息网又更擅长叙事控制。信息越集中，皇帝衰老或判断错误时系统也越难纠偏。

### 财政公私边界决定腐败能否治理

耗羡归公一度承认真实行政成本，乾隆时期固定低税、蠲免、内务府截取增量和高支出再次撕裂国家账本。没有合法财源，严惩贪官只能在非法筹款与个人侵吞之间循环。

### 盛世总量与个人生活可以反向变化

人口、耕地、疆域和税收组织达到高峰，不等于人均粮食和生活质量上升。人口追上土地、垦荒破坏生态、职位增长慢于读书人，都会把“强大国家”与“贫困个人”同时生产出来。

### 控制成功会压低适应能力

盟旗、秘密政治、文字审查、一口通商都先解决真实风险；当它们变成对人口流动、知识交流和社会自主性的普遍防范，短期稳定便以长期僵化为价格。

## 一条演变时间线

明朝以羁縻、贸易和女真制衡治理东北 → 努尔哈赤整合女真、八旗与边贸资源 → 1619年萨尔浒击败分进明军 → 皇太极扩编满蒙汉八旗、吸纳降官并改国号清 → 绕道入塞和松锦胜利摧毁明朝辽东防线 → 1644年李自成入京、吴三桂与清军合作入关 → 清廷以剃发、圈地、投充、逃人法巩固征服集团，南明在多中心内耗中退向西南 → 郑芝龙降清被拘，郑成功整合海上网络抗清 → 康熙初撤藩引发八年战争，平定后加强西南直接治理 → 博学鸿儒与修《明史》吸纳遗民、重写合法性 → 郑成功收复台湾，明郑延续 → 迁海封锁失败，清廷建设水师，1683年郑克塽降、1684年设台湾府 → 康熙建设东北后勤、雅克萨围城，1689年签《尼布楚条约》 → 噶尔丹攻漠北，乌兰布通战败，1691年多伦会盟将喀尔喀纳入盟旗 → 康熙三征噶尔丹，准噶尔在策妄阿拉布坦下复兴 → 准军入藏失去民心，1720年清军护送七世达赖入拉萨 → 雍正设驻藏大臣，边疆战争因猜忌与八旗衰退受挫 → 雍正以秘密立储、密摺、军机处重组皇权，以耗羡归公、养廉银、摊丁入亩重组财政税基 → 清准议和后准噶尔继承内乱 → 乾隆抓住窗口，两次出兵灭准并平大小和卓，设伊犁将军 → 将军、办事大臣、因俗而治和分而治之形成完整陆疆架构 → 人口超过三亿，移民、新作物和免税垦荒带来人均贫困与生态破坏 → 乾隆从宽缓初政转向宗室收权、督抚换代 → 六下江南以河工、恩惠和军威控制江南 → 文字狱与《四库全书》搜毁把社会推向自我审查 → 内务府吸收盐业外贸增量、一口通商集中粤海关，国家财政与皇帝私财分裂 → 乾隆以“十全武功”总结盛世，社会适应和对外开放却被强控制压低。

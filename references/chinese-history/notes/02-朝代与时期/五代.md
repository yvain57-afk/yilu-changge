# 五代

## 时期总命题

五代十国不是“唐亡以后换了五块招牌”的空白期，而是唐末旧秩序解体后，三个区域同时寻找新组织方式：中原的朱温、李克用集团以军功和禁军反复争帝，唐晋汉周更替多是同一太原—沙陀军事体系内的强将夺位；南方九国拒绝继续为北方无底线战争输血，把盐运、税赋和水利留在本地，经济重心由此超过北方；契丹则抓住回鹘衰落和中原内乱，以汉城、农业人口、南北面官、五京与捺钵把部落军事和汉地行政拼成成熟辽朝。短短五十年里，草根与边疆领袖取代门阀，禅宗从底层生产共同体走向士大夫文化，冯道的跨朝行政伦理又在宋代被重写为失节。柴荣将藩镇精兵集中到禁军，结束一类五代循环，却把最后的夺位机会交给禁军统帅；宋朝由此既是五代的产物，也必须用新的忠义、文官和财政秩序否定五代。

## 五组问题

### 一、中原五代为何反复更替

- [[153-五代更迭（上）：平定黄巢的两大受益者]]：朱温以开封财赋与暴力清障建后梁，李克用、李存勖以河东地势、骑兵、养子网络和复唐旗号逆转强弱。
- [[154-五代更迭（下）：皇帝的“救命恩人”怎么总叛变？]]：后晋、后汉、后周多由太原强将或禁军拥立完成更替，救驾功劳、独立地盘与皇权猜忌构成重复机制。

### 二、南方分裂为何变成经济增长窗口

- [[155-九国兴衰：南方草根是怎么躺赢的？]]：“十国”是欧阳修定型的史学范畴；吴、南唐、吴越、前后蜀以地方自救保护生产，原本北输资源转为水利、城市和文化积累。

### 三、契丹怎样从部落联盟变成王朝

- [[156-契丹崛起：天皇帝、地皇后、人皇王]]：阿保机以汉化集权、跨阵营结盟和汉城盐铁改变部落力量，清除推举可汗传统的受益者，再向西、向东扩展国家资源。
- [[158-南北面官：契丹如何用40年成为成熟王朝？]]：辽太宗入开封失败暴露后勤和行政不足，继承退让保住国家；南北面官、五京和四时捺钵随后为不同空间配置不同制度。

### 四、宗教如何跨越国家崩解

- [[157-问答：禅宗如何成为影响力最大的佛教宗派？]]：禅宗以低门槛修行和生产组织立足民间，借武周、安史度牒取得政治资源，再用清规、劳动和庄儒表达接通士大夫。

### 五、乱世伦理为何到宋代被重新审判

- [[159-长乐冯道：四朝为官，他是人精还是贤臣？]]：冯道跨朝维持选官、民生和战乱救助，五代重实际秩序，北宋中期则为防重回改朝常态而把忠君死节提升为核心规范。

## 五条贯穿线索

### 旧问题被暴力清除，不等于新秩序建立

朱温杀宦官、士族与魏博牙兵，确实消灭晚唐三个顽疾的承担者，却同步摧毁皇权支持、知识网络和地方军政。耶律德光能用军队进入开封，也因后勤、贵族分利和文官不足无法治理。五代的共同教训是：破坏可以由最高权力快速完成，建设必须让利益、粮饷和行政一起改变。

### 军事集中只会转移政变位置

后唐至后周，镇守太原、救过皇帝的强将最有条件反叛。柴荣把藩镇精锐逐步抽入中央禁军，使地方不再容易推翻朝廷；可幼主继位时，掌禁军的殿前都点检便成为唯一能低成本改朝的位置。宋初问题不是消灭所有军力，而是怎样让中央军力不再属于某个可黄袍加身的个人。

### 地方化能在特定阶段保护生产

南方政权的军阀野心真实，社会自救同样真实。北方每一方都以消灭对手为唯一目标时，继续北输税赋会摧毁地方生存；吴越等政权把收益留在本地，统治者因家业与长期回报一致，更愿意维护中小水利。这不是证明分裂普遍优越，而是说明治理规模和激励需要匹配。

### 多元制度比单一模仿更有韧性

阿保机利用汉城与中原制度强化契丹世袭国家，却没有把全部部族强制改成汉地。南北面官均为混合制度，五京承担区域职能，捺钵让政治中枢随草原季节移动。辽的成熟来自同时容纳农业城市和游牧空间，因此宋朝面对的是已完成四十年制度积累的对手。

### 唐宋转型也发生在宗教与道德评价中

门阀崩解后，禅宗靠生产共同体、度牒财政、清规和士大夫趣味穿越政权断裂；冯道则以可复用的行政能力维持民生。到宋朝稳定后，前者成为士大夫文化资源，后者却因跨朝任职成为忠义反例。同一乱世遗产被选择性吸收，正说明宋代新秩序需要定义哪些五代经验可以保留、哪些必须否定。

## 一条演变时间线

黄巢败亡后朱温降唐据开封、李克用以沙陀军据河东 → 朱温控制昭宗并屠杀宗室、宦官、士族、牙兵，907 年建后梁 → 阿保机同年任契丹可汗，以汉城收益和暴力清除推进世袭，916 年称帝 → 李存勖借复唐名义与河东组织灭梁，923 年建后唐 → 李存勖死于兵变，李嗣源被出征军拥立 → 925 至 926 年契丹灭渤海、建东丹，阿保机死后述律平推动耶律德光继位 → 石敬瑭镇太原受调任威胁，936 年借契丹兵建后晋并承认燕云归辽 → 石重贵抗辽，内应导致 947 年后晋亡，耶律德光入开封又因掠夺和行政不足北撤 → 刘知远由太原入开封建后汉，短期即因继承与强臣冲突灭亡 → 郭威在出征途中被黄旗拥立，951 年建后周 → 南方吴、南唐、吴越、前后蜀等在北方混战期保留财赋、发展水利城市，门阀垄断加速瓦解 → 郭威传位养子柴荣，柴荣以战役胜利抽调藩镇精锐、建立禁军优势并规划先南后北 → 959 年柴荣早逝、幼主继位，禁军统帅赵匡胤获得改朝窗口 → 同期辽以南北面官、五京和四时捺钵完成多元治理，禅宗与冯道评价则把五代经验带入宋代文化政治。

## 待外部核验的总问题

- 朱温夜袭李克用、宦官与士族屠杀、魏博牙兵被杀的时序和规模。
- 后梁与后唐的人口、财赋、军种、地理优势各自对战局的权重。
- 张承业族源、理财作用与《财计书》的目录记录，李存勖亡国与优伶政治的完整因果。
- 燕云十六州逐州控制过程、云地荒废与燕地防线价值，石敬瑭族源及政治身份。
- 后晋澶州战绩、内部通辽、耶律德光许帝与入开封统治的不同史源。
- 柴荣集中禁军的具体步骤、兵员规模及对赵匡胤机会的直接影响。
- “十国”范畴形成，杨行密地方支持、李昪谱系发明的当时接受度。
- 钱镠海塘、西湖工程规模，南方经济超过北方的指标和转折年代。
- 契丹族源、白马青牛传说、可汗推举规则与阿保机宴杀故事的材料层次。
- 迁徙汉人的编户与私人隶属，渤海国资源对辽国家建设的贡献。
- 述律平杀将、断腕和继承让步，南北面官形成时间、五京与捺钵实际决策功能。
- 《六祖坛经》、神秀神会关系、安史度牒和敦煌北宗材料所见顿渐分歧。
- 百丈清规可上溯年代，以及禅宗的基层组织与士大夫接受之间的中介。
- 冯道民生事迹、战乱救助和跨朝实际权力，五代高评到宋中期低评的文本变化。
- 中唐、后周、宋初户籍差异中的战争死亡、逃亡、脱籍和统计范围。

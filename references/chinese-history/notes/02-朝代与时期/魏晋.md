# 魏晋

## 时期总命题

魏晋不是“统一失败后持续混乱”的单线故事，而是三套旧秩序同时失效、又不断寻找替代方案的过程。汉末中央失去资源与暴力垄断，曹魏、蜀汉和孙吴遂以不同联盟重建区域国家；三国都依靠开国者的个人权威和非顶级士族集团，却又在继承中向可持续生产人才的门阀让权。司马氏凭北方恢复的国家能力完成统一，却把宗室军权、低合法性、地方差异、内迁族群和皇族衰弱压进同一体系，八王之乱最终摧毁协调中心。此后北方的内迁人群、流民、寒门官僚与边缘地区重新组合，既产生多族合作，也反复滑向特权、迁徙与屠杀；南方则以皇帝名义、士族治理和流民武力维持低限度秩序。前秦与东晋在淝水的胜负表明，征服、行政和整合是不同能力：前秦扩张快于整合，东晋防守有余却受北伐合法性、门阀利益和独立军队牵制。到孙恩之乱，皇权、门阀与军队之间的旧平衡已开始转向军事强人政治。

## 五组问题

### 一、为什么会有四百年分裂

- [[070-分裂时代：为什么分裂长达400年？]]：长期分裂来自皇权、士族和多族群关系的同步重组，气候压力只会抬高整合成本，不能单独解释政治结果。
- [[071-曹操崛起：为什么胜出，又为什么止步？]]：曹操以资源汲取、军事执行和政治名分统一北方，却无法把北方战争模式直接复制到经济成长、水网密布的长江流域。
- [[072-问答：了解汉代历史，为什么建议从《汉书》开始？]]：《汉书》的断代结构适合追踪制度和年代，同时必须辨认班固的国家视角、家族处境与官修条件。

### 二、三国为何并立，又为何同命

- [[073-诸葛治蜀：“隆中对”其实并不神奇？]]：隆中对抓住长江流域的整合机会，却低估“跨有荆益”与“联孙抗曹”的内在冲突；失荆州后蜀汉只能在有限资源和艰难交通中反复北伐。
- [[074-坐断东南：孙权的征途是星辰大海]]：东吴的联盟善用水网、山地人口和海路守住东南，却缺少让淮泗武装、北来士人与江东大族共同承担北伐成本的机制。
- [[075-三国同命：魏、蜀、吴的命运何其相似]]：三国都以合法性不足的开国者和战时集团建立集权，后继者无法复制个人权威，最终向扎根地方、能持续再生产人才的世家让权。
- [[076-西晋一统：司马家族的权力之路]]：司马氏利用北方人口、土地和官僚恢复完成统一，灭蜀灭吴也服务于篡位后的合法性与家族竞争。
- [[077-问答：东汉太学为何衰落？民间有哪些儒学大师？]]：太学的仕途和政策依附损害知识公信力，古文经则借民间教学、家族网络和皇帝认可产生另一套学术生命。

### 三、西晋统一为什么迅速崩解

- [[078-五重危机：司马家族为何守不住江山？]]：边疆内迁人口、吴蜀新附区、中原门阀、带兵宗室和衰弱皇族并置，使财政、任官和军权风险相互放大。
- [[079-八王之乱：愚蠢与贪婪怎样摧毁了一个王朝？]]：宗王拥有可撤销的地方军权，却没有稳定封国和退出保障；人人都能争中央、又不能容忍别人长期掌权，宫廷清洗遂升级为全国战争。
- [[080-五胡入华：北方为何陷入“十六国”大乱？]]：所谓“五胡十六国”不是五族突然外侵，而是长期内迁且认同可变的人群，在八王之乱造成的救灾与军政失能中同流民重新组合。

### 四、北方多族政权怎样重建又再度失序

- [[081-胡汉之间：“汉化理想”与“杀胡令”]]：刘渊、刘曜和石勒尝试以汉朝名分、双轨制度或胡汉合作统治；石虎的强制特权破坏生产与合作后，冉闵才可能把怨恨推向族群屠杀。
- [[082-问答：中国古代人们信仰什么？]]：古代信仰一直普遍，变化的是跨地域宗教组织；东汉国家缩减基层存在后，民间教团借用官府文书、官阶和军政结构填补空间。
- [[083-前燕前秦：站在后赵的废墟上]]：前凉、前燕和前秦分别利用河西避乱地、鲜卑军权、寒门官僚和强制迁徙网络，在后赵废墟上重建区域秩序。
- [[086-淝水之战：前秦为何全局崩溃？]]：前秦拥有强君与官僚，却没有把被征服的军事集团整合进共享秩序；双向迁徙又把氐族核心打散，淝水失败遂成为各网络退出联盟的共同信号。
- [[087-问答：王猛是酷吏还是贤相？]]：王猛以严法打击氐族旧贵、帮助苻坚中央集权，同时建设官僚、农业和儒学；酷吏手段与贤相能力可以同时成立。

### 五、东晋最低秩序为何由防守走向转型

- [[084-衣冠南渡：东晋建国的天时地利人和]]：江南开发空间、战略据点、北方分裂和“皇帝垂拱、士族当权、流民出力”的联盟，共同构成东晋的最低可行秩序。
- [[085-是否北伐：东晋朝廷的两难]]：不北伐有利于江南积累，却损害正统与北来士族地位；真北伐又耗费资源并可能把军功交给权臣，朝廷只能在口号与有限行动间摇摆。
- [[088-门阀丧钟：朝廷的基本盘因何动乱？]]：南北认同折旧、皇权争夺门阀人口、乐属征兵和宗教水运网络共同催生孙恩之乱，扬州门阀受创后，朝廷反而更依赖北府军。

## 五条贯穿线索

### 征服、行政与整合必须分开

曹操能征服北方，不等于能穿越水域社会；西晋能灭吴，不等于已消化吴蜀、内迁族群和宗室军权；前秦拥有强大的官僚和军队，也不等于各集团认同同一秩序。地图扩张最快的时刻，常恰是整合欠账最大的时刻。

### 个人权威与可继承制度

曹操、刘备、孙权、司马氏开国者和苻坚都能用个人关系拼合异质联盟，后继者却必须回答谁能稳定提供人才、税收和军队。门阀、部落领袖和流民军队之所以反复上升，不只因其强大，还因为它们比君主魅力更能跨代延续。

### 人口、迁徙与组织边界

流民不是无组织人口，内迁胡人也不是固定族群方阵。迁徙可能产生屯田、军队、宗教网络和新国家，也可能打断旧保障、把潜在冲突搬进政治中心。判断迁徙政策，要同时看人口去向、原网络是否保留、谁掌握登记和武装。

### 合法性是一项可消耗资源

汉献帝名义帮助曹操整合北方，蜀汉与东晋的“恢复”口号支撑偏安，司马氏和前秦则面对篡位或正统不足。合法性不能替代粮食与军队，却能降低联盟合作成本；北来士族对中原认同代际折旧后，东晋北伐的道德内容也随之变薄。

### 史料叙事与结构解释

《汉书》的官修视角、诸葛亮的神机形象、八王的愚蠢标签、苻坚与王猛的道德故事，都可能把复杂结构压缩成好人坏人。人物选择仍然重要，但需要放回交通、财政、军权、组织和材料成书过程，才能解释为何个人错误会被放大成系统崩溃。

## 一条演变时间线

董卓入洛使汉朝统一实质终结 → 曹操在北方重建资源、军队和名分，赤壁后止步长江 → 刘备集团据益州、孙权联盟经营江东，三国区域国家成形 → 开国者去世后，三国都向地方世家让权 → 司马氏控制魏国并利用北方恢复灭蜀、灭吴 → 西晋把多重差异纳入低合法性中央，宗王军权竞争演成八王之乱 → 救灾与治安崩溃使流民、内迁人群和地方集团重组，成汉与汉—赵兴起 → 后赵从胡汉合作转向强制特权，杀胡令又把政治报复族群化 → 前凉、前燕与前秦在边缘地区、迁徙网络和寒门官僚支持下重建 → 衣冠南渡在江南形成皇帝、士族与流民武装的东晋联盟 → 前秦统一北方后继续攻晋，淝水失败触发既有军政网络同时退出 → 东晋虽胜，却因南北认同衰退和门阀利益无力完成统一 → 皇权试图以乐属争夺人口，孙恩之乱重创扬州门阀 → 北府军更加不可替代，门阀共治开始让位于军事强人政治。

## 待外部核验的总问题

- 四世纪气候变化的时间、区域差异及其与人口迁徙、战争之间的因果权重。
- 曹操屯田、北方户口恢复、赤壁兵力与疫病记载，以及长江经济成长的可量化证据。
- 隆中对成文年代、荆益战略与孙刘联盟破裂之间的关系，蜀汉南中汲取和北伐成本。
- 东吴山越人口、海上航路、辽东交往与江东大族利益的地区差异。
- 三国至西晋九品中正、士族婚姻和地方人才再生产的实际运行范围。
- 司马氏灭蜀灭吴的决策链、西晋人口财政数据、宗王兵权与八王战争规模。
- “五胡”“十六国”的后世分类如何遮蔽具体人群的迁徙、通婚与身份变化。
- 后赵特权、强制劳动、冉闵杀胡规模及史料中的族群标签是否稳定。
- 秦汉国家压制宗教组织、东汉行政收缩与道教形成之间的证据链。
- 前凉、前燕、前秦的户籍、屯田、迁徙路线和基层汉族官僚连续性。
- 东晋人口增长、江南开发、门阀庄园和流民军队规模的统计口径。
- 桓温北伐的补给与战果，北伐合法性和篡位动机在不同阶段的权重。
- 前秦疆域的直接控制程度、淝水兵力、王猛遗言与“天王”称号的文本解释。
- 褚裒失败后人口损失、淝水后掳卖、乐属身份及孙恩之乱的多重诱因。

# 隋

## 时期总命题

隋朝的短命不宜写成文帝全好、炀帝全坏，也不能由大运河或三征高丽一个事件解释。杨坚接手的是部落组织已长期瓦解、关陇胡汉军人和成熟北齐官僚都可被重新组合的北方；他恢复汉姓、整理三省六部、裁撤郡级、集中地方人事、清查户口和建立仓储，把数百年分裂中形成的组织资源接成高效统一国家。可同一能力从一开始就有两面：中央命令能下县，也能把抑商、貌阅误判、库存崇拜和对江南的文化同质化贯彻到底。杨广并非没有才干，他靠灭陈、江南怀柔和北击突厥取得太子位，洛阳与运河也回应区域整合、供粮和边防需求；危险在于他清除兄弟元老、边缘化关陇、把皇帝声望押上御驾亲征，令国家更强的资源集中能力失去停止机制。三征高丽、雁门失信和南逃江都连续摧毁社会承受、旧集团合作与军队信用，最终让本可服务统一的官僚、运河和禁军转成亡国通道。

## 五组问题

### 一、统一国家怎样整理中央与地方

- [[103-开皇新政：隋代中央官制有何变化？]]：恢复汉姓顺应关陇集团内部汉文化转向，三省六部则是汉魏内朝外朝化和北齐制度输入的长期结果。
- [[104-地方行政：“工作狂”隋文帝的执行力有多强？]]：州县二级、中央任佐官、考核、貌阅和义仓让国权下县，也让错误指标和抑商偏好失去地方缓冲。

### 二、灭陈功劳如何进入太子竞争

- [[105-灭陈之战：灭陈的大功劳该给谁？]]：陈朝结构性弱势使战争结果高度确定，三路编组把统一名义功劳预先集中给杨广，战术贡献与政治署名由此分离。
- [[106-太子之争：杨广如何谋得太子之位？]]：北方治理套餐激起江南叛乱后，杨素镇压、杨广借文人高僧怀柔，证明其治理能力并形成继承联盟。

### 三、宗教网络怎样超越政权边界

- [[107-问答：魏晋南北朝时，南、北方佛教有何异同？]]：南北佛教同样提供苦难解释、庇护并占有资源，强弱皇权与门阀结构却分别塑造佞佛—灭佛和佛玄合流。
- [[112-问答：基督教和道教有何异同？]]：基督教与道教的可比点不在同源，而在世俗国家服务不足时，城市、女性、家庭和瘟疫互助怎样生成替代组织。

### 四、权力交接为何消除内部制衡

- [[108-炀帝登基：权力交接的迷雾]]：文帝死因无法定论，太子—杨素控制宫禁信息却较可信；登基后的兄弟与元老清洗使“大业”失去纠错网络。

### 五、宏大工程如何转成过度动员

- [[109-大业肇始：洛阳与运河]]：东都与分段运河有真实区域和物流价值，急征、奢华与形象工程成本仍不可由后世收益抵消。
- [[110-三征高丽：隋炀帝为何一定要御驾亲征？]]：可辩护的边疆目标被错误时机、超大规模与皇帝声望绑定，第一次失败遂触发连续加码和杨玄感叛乱。
- [[111-炀帝之死：两个致命失误，“失信”与“南逃”]]：雁门解围后毁约使皇帝承诺归零，与突厥决裂又把太原军权交给李渊；南逃江都最终激化关中骁果兵变。

## 五条贯穿线索

### 国家能力与政策质量是两个变量

三省六部、州县二级、中央任佐官和大索貌阅让命令、人口和物资更可见，这是统一的真实基础。但汴州抑商、江南强制五教、貌定丁口和义仓只进不出同样靠这套能力实现。能做成事不等于做的是对事；能力越强，错误目标的覆盖范围也越大。

### 征服、统治与继承会争夺同一功劳

灭陈在战场上胜负悬殊，政治难题却是统一天下的功劳只能授予一次。杨广通过主攻统帅名义吸收贺若弼、韩擒虎的战术贡献，又在江南以文人、高僧和文化工程证明统治能力。太子竞争因而不是私人宫斗，而是战争分工、区域声望和朝堂联盟的再分配。

### 基础设施会放大使用者的战略

洛阳帮助连接三大区域，运河减少粮运瓶颈、支持仓储和边防；它们既是后世资产，也是杨广三征高丽的动员前提。运河没有在建成时直接摧毁隋朝，却让皇帝能把全国资源更快投向连续战争。评价工程必须同时看目标、施工和后续使用。

### 最高权力押注后更难停止

杨广清除元老后缺少可信反对者，又坚持御驾亲征。第一次失败若交给将军重试，就像承认自己不如部下；第二次中断后再停，又像承认巨大牺牲无意义。个人声望、国家目标和沉没成本绑在一起，理性退出遂变成政治上最难选择的方案。

### 亡国临界点是信用而不只是库存

隋朝有巨大粮仓、运河和人口登记，却在雁门解围后取消赏布、降官、严审功劳并打算再征高丽。危机时皇帝亲口承诺都不能兑现，士兵就没有理由相信下一次交换；随后南逃江都又告诉北方，风险由他们承担、统治者却离开。国家仍有资源，联盟和服从已经失去价格。

## 一条演变时间线

北周武帝灭齐后早死 → 宣帝重用岳父杨坚，幼帝禅让，关陇内部以较低阻力完成隋代周 → 恢复汉姓、吸收北齐官制，汉魏以来尚书、中书、门下的职能迁移被整理为三省六部 → 州郡县改州县二级，中央任地方佐官并以高频考核推动国权下县 → 583 年大索貌阅扩大丁口，585 年义仓继续集中粮食，强指标同时产生误认和只储不救 → 589 年三路灭陈，杨广以主攻统帅取得统一功劳 → 北方治理套餐激起江南叛乱，杨素镇压、杨广借文人高僧怀柔，592 年局势平定 → 高熲倒台、杨广北击突厥，600 年取代杨勇为太子 → 604 年文帝死因留下多层材料，杨广掌权后处理兄弟、杨素和元老 → 急建洛阳，605 年通济渠、608 年永济渠把江南粮源、中央仓城和涿郡前线接通 → 609 年户籍约四千六百万，国力账面达峰却已疲惫 → 612 年首次征高丽失败，613 年第二次因杨玄感从粮运端起兵而中止 → 614 年第三次取得名义胜利，国内民变和关陇撕裂已公开 → 615 年北巡遭始毕可汗围雁门，杨广靠停战和重赏承诺解围后毁约 → 隋突厥决裂，李渊获太原军权 → 616 年杨广南下江都，北方被弃感与关中骁果思乡合流 → 618 年江都兵变，隋炀帝死，统一国家的组织遗产转入唐朝。

## 待外部核验的总问题

- 北周武帝遗骸砷异常与死因，杨坚代周时关陇集团边界和真实反对规模。
- 恢复汉姓命令的执行范围，北齐官制具体影响隋三省六部的路径。
- 三省在隋代的名称、职权和实际流程，六部与汉代九卿的连续性。
- 546 年州郡县统计的名义与实际建制，撤郡后官员安置、中央负荷和地方用人网络。
- 大索貌阅新增一百六十多万口、四十多万丁及东部十之六七避役的统计口径。
- 义仓官控程度、征收上限与实际救灾记录，关中灾荒不开仓的运输和粮质条件。
- 陈朝二百五十万户籍、隋灭陈五十一万兵力和贺若弼、韩擒虎战功传记。
- 江南限寺、五教、叛军三十万和食官肉叙事，杨素镇压与杨广怀柔的相对效果。
- 智顗、潘徽、陆知命和杨广关系，佛教跨域网络对政治统一的实际贡献。
- 文帝病逝、杨素传可疑链与野史弑君故事的成书、互抄和胜者修订过程。
- 关中水利衰退、东都民夫和外围长沟规模，回洛仓容量与江南运河地方志证据。
- 609 年四千六百多万户籍的覆盖率，各地民困与国家总量之间的差异。
- 三征高丽水陆兵力、死亡、骁果招募、杨玄感粮运位置和第三次“胜利”标准。
- 李氏预言是否事前存在、李姓贵族死亡数，隋朝分化突厥与雁门四十一城战况。
- 雁门奖赏承诺与兑现口径、李世民勤王角色、第三次江都行及骁果兵变细节。
- 罗马迫害强度、早期基督教城乡与阶层构成、女性比例、婚龄生育和瘟疫存活模型。

# 两宋

## 时期总命题

两宋的成就与失败来自同一套选择：赵匡胤从五代军人政治中提炼出“皇权集中、军将分离、文官共治”的安全结构，结束了强将反复改朝，却使军队越来越难形成持续指挥和专业共同体；科举、城市、商业和士大夫文化因此繁盛，朝廷的财政与行政也高度精细，但这些能力在对内抽取时最有效，在对辽、夏、金的战争中却被猜忌、责任切割和政治正确不断抵消。北宋以澶渊和平进入仁宗高点，又因西夏冲击和财政焦虑走向庆历新政、王安石变法及党争，徽宗把皇权和财政技术推到极致，最终在靖康危机中暴露为对外失能、对内搜刮。南宋经十余年战争重建军力，高宗却只接受保住秦岭—淮河以南的有限目标，岳飞的组织能力因此既是救国资产，也是皇权威胁。同期金朝从勃极烈、猛安谋克的扩张共同体转向中原式官僚帝国，陷入治理、汉化和族群特权矛盾。两国军事上都更善守而难攻，长期和平之下，南宋皇权又旁落于权相；朱熹用四书和道统重构儒家，海贸则用市舶、航海、货币和书籍网络，把失去北方的宋朝变成更广区域的经济文化中心。

## 九组问题

### 一、宋初怎样终结五代循环

- [[160-北宋帝系：九位天子，一副重担]]：宋代把皇帝安全置于军队效能之前，九帝多数亲政而无外戚宦官长期篡权，代价是最高决策负担和边防能力同时集中。
- [[161-游侠皇帝：赵匡胤如何走出历史循环？]]：赵匡胤以五代军人经验夺位，又通过整编禁军、分割军权和厚待功臣降低下一次黄袍加身的概率。
- [[162-问答：为什么罗马帝国再也不能复兴？]]：中国反复统一与罗马长期分裂的差异，不能归给民族性，而要看地理、文字、行政和政治资源如何延续。
- [[163-先易后难：两顿酒、一夜雪、几场仗]]：宋初先取南方财赋、再处理北方威胁，统一战略体现资源顺序，也把燕云问题留给后继者。

### 二、辽宋竞争为何走向长期和平

- [[164-烛影斧声：宋太祖赵匡胤的最后一夜]]：太祖传弟还是太宗夺位，史料不能定案；继承疑云却真实塑造太宗的合法性和北伐需求。
- [[165-高梁车神：宋太宗的北伐惨剧]]、[[166-燕燕于飞：“母寡子弱”的辽，为何能反杀宋朝？]]：宋太宗以为辽幼主寡母可欺，实际辽军组织、萧太后与韩德让合作都强于刻板印象。
- [[167-问答：五代时，中原是如何失去幽州的？]]：幽州并非由一个卖国者瞬间丢失，实际控制经历后唐、后晋与契丹多阶段转换。
- [[168-澶渊之盟：谁才是力挽狂澜的“大男主”？]]：真宗亲征、寇准坚持、辽方压力与前线偶然共同促成和议，岁币买到的是双方都需要的可预期边界。

### 三、文官共治与社会繁荣如何形成

- [[169-偃武修文：“重文轻武”是初心还是结果？]]：宋初不是从第一天就完全重文，战事受挫、将领难控和文官供给扩大才让政策逐渐定型。
- [[170-科举革命：试卷失去姓名，寒门迎来春天]]：锁院、糊名、誊录把考试从关系识别改成文本比较，扩大机会，也加强中央对士人的定义权。
- [[171-共治天下：唐宋之变与祖宗之法]]：皇帝与士大夫以经书、台谏和惯例共享政治语言，祖宗之法既约束皇权，也会把历史选择冻结成不可讨论的边界。
- [[172-问答：文成公主入藏，本质上是个什么故事？]]：和亲人物如何在政治、宗教和现代叙事中层累，提醒我们区分当时婚盟与后世民族团结象征。
- [[173-最好成绩：大宋繁荣背后的天助与人事]]：仁宗朝的和平、人口经济、地方治理和杭州区位共同形成宋代高点，并非单靠仁君品格。

### 四、西夏冲击怎样逼出改革议程

- [[174-党项崛起：大宋如何亲手养出西夏强敌？]]、[[175-西方之夏：身份焦虑下的“抄作业”]]：党项借宋朝授官、贸易和内部竞争成长，再用汉制、吐蕃经验和本族符号建构西夏身份。
- [[176-庆历危机：一战不如一战，可骇也]]：宋军有资源却在连续战役中因指挥、情报和责任链条失败，辽又趁机施压。
- [[177-问答：《杨家将》里，大反派的历史原型有多冤？]]：潘美、王侁与陈家谷责任被文学压缩到一个奸臣角色，显示公共记忆如何寻找单一恶人。
- [[178-拓边西北：积贫积弱下的求变之路]]、[[179-警报解除：辽夏相争与变法夭折]]、[[180-安石不出：新政与变法之间]]：边将主动性、财政压力和庆历新政相互牵连；外患暂退后，改革联盟迅速解体，留下更激进方案的空间。

### 五、王安石变法为何从政策变成党争

- [[181-廊庙乏材：一诗明志、一书言政、一争开局]]：王安石以地方经验、万言书和神宗支持进入中央，其上升也依赖濮议后重组的政治环境。
- [[182-问答：什么是羌族？一个民族概念的千年流变]]：古代羌名、不同人群与现代民族分类不可直接连成单一血缘谱系。
- [[183-开源节流：王安石与司马光的分歧]]：双方争论不是善恶，而是国家该通过开源主动调动资源，还是以节制支出减少扰民。
- [[184-富国害民：王安石变法的悖论]]：地方上有效的财政技术放大到全国，遇到信息和人员错配，可能增加国家收入却把成本转给百姓。
- [[185-强兵梦碎：四十万大军溃败西夏]]：强兵政策有局部成果，却未修复战略、后勤和统一指挥，大军仍能在永乐城系统性崩溃。
- [[186-新忧旧患：新法沦为党争工具]]、[[197-问答：王安石变法为什么这么难评？]]：政策立场逐渐变成政治身份；《神宗实录》反复改修、高宗法统和程朱兴起又把评价延伸数百年。
- [[187-问答：为什么《资治通鉴》唐史部分最精彩？]]：史料距离、三长与司马光的人生条件共同决定史书质量，砸缸故事则显示名人童年如何被典型化。

### 六、徽宗与靖康为何不是简单亡国故事

- [[188-徽宗真相：是文艺皇帝，还是权谋高手？]]：徽宗不是不理政务的艺术家，而是主动选择蔡京、党籍碑和御笔手诏的权力使用者。
- [[189-海上之盟：从西北大捷到东北危机]]、[[190-宣和北伐：一场盟约、几番犹豫、满盘皆输]]：西北局部胜利制造自信，宋廷却对女真、辽和燕云信息不足，在云州、燕京目标间摇摆。
- [[191-进退失据：燕京得而复失，东京兵临城下]]：以重金换来的空城、张觉事件、难民和常胜军共同暴露宋廷信用与河北防线。
- [[192-问答：金庸笔下的契丹和女真，符合历史吗？]]：小说错置年代、改写辽道宗和阿骨打，却以个人不能战胜时代制造历史感。
- [[193-城下之盟：胜机在手，败于内斗]]：第一次汴京之围仍有坚城与勤王军，求和利益、争功和提前夜袭却耗掉翻盘窗口。
- [[194-汴京之围：金兵再来，帝国瘫痪]]、[[195-靖康之耻：十万俘虏和一个覆灭的王朝]]：九个月内皇权清算压过备战，流程推诿让帝国瘫痪；北宋机器对外无能、替金人搜刮本国社会却高效，构成“耻”的制度含义。

### 七、南宋怎样重建军队，又为何杀掉岳飞

- [[196-岳飞早年：河北起兵，开封失守]]：岳飞从河北基层军事化和忠义武装中成长，宗泽把其高风险独立性接入有效组织。
- [[198-和战之间：岳飞收复建康，秦桧推动和谈]]：岳飞以不扰民军纪和收复建康进入高宗视野；秦桧则以保留赵氏代理统治更划算的成本逻辑推动和谈。
- [[199-绍兴北伐：岳飞战场得意，朝堂失意]]、[[200-难解难分：和战反复，君臣渐生猜忌]]：岳飞把胜利视为恢复中原起点，高宗只想以战促和；淮西兵权、辞职和立储建议让战略分歧转为身份猜忌。
- [[201-武穆奇冤：刚立战功，就获死罪]]：朱仙镇战果需存疑，郾城胜利和冤狱本身仍成立；枢密升迁实为二次释兵权，张宪供词被用于构陷。
- [[203-英雄必死：宋高宗为何一定要杀岳飞？]]：岳飞战功高而官场孤立，岳家军又靠公平、资源和统帅自律形成军魂；杀人立威与拆除个人忠诚结合，使处决成为高宗的理性恶。
- [[202-问答：乱世中失踪的皇室女性，究竟经历了什么？]]：沈氏、柔福帝姬与疑似伪书提醒，乱世女性史必须优先审查材料年代，并把普通女性苦难从贵族奇闻后面找回来。

### 八、金朝从扩张共同体转向中原帝国

- [[204-金朝困局：打江山容易，守江山难]]：勃极烈、猛安谋克适合短链条征战，吞下辽宋人口后却面临治理不足、战力下降和勋贵内斗。
- [[205-大金炀帝：杀戮中的政权收缩]]：完颜亮屠杀宗室、依靠汉官、迁都北京，在其他边界退让，却集中资源豪赌灭宋。
- [[206-金以儒亡：南征失败与汉化危机]]：1161年南征被海陆防线和军中兵变击碎；世宗以守成开盛世，却用土地特权维持女真基本盘，既养废军力又阻碍汉人认同。

### 九、南宋后期用什么维持文明与交换网络

- [[207-问答：宋朝人如何理解“中国”？《满江红》真是岳飞写的吗？]]：宋人的“中国”主要是文明正统概念；抵抗意愿不等于能力，《满江红》因宋元无传播痕迹和家集不收只能存疑。
- [[208-南宋行暮：弱势皇帝与强势宰相]]：绍兴体制集中皇权，后继弱帝却让高权位落入秦桧、韩侂胄、史弥远等权相，正常罢相程序逐渐被政变替代。
- [[209-天理昭昭：朱熹理学如何重塑儒家传统？]]：四书以低门槛、高上限重设儒学入口，道统则给士人面对君统和多政权分裂的共同文明语言。
- [[210-面朝大海：从御夷狄到通商路]]：贸易获得国防正当性，市舶、航海、海军、铜钱和书籍网络使南宋成为区域经济文化中心。

## 六条贯穿线索

### 政权安全与国家能力并非一回事

宋初制度非常擅长让赵家皇帝不被武将推翻，却不擅长让同一支军队在陌生前线快速协同。北宋九帝皇位总体稳定、社会文教繁荣都是真成就；高梁河、庆历战败、永乐城、宣和北伐和靖康又反复证明，政权越防自己的专业组织，国家越难在外部危机中行动。

### 财政与行政能力有明确方向性

王安石试图把分散财富转成国用，徽宗继续扩张皇权财政技术，靖康时这台机器却替金人高效搜刮汴京。国家“有没有能力”必须追问能力用于保护、供给、征战还是抽取；同一体系可以在一个方向极强、另一个方向近乎瘫痪。

### 和平不是战败的反面，而是制度选择

澶渊之盟、绍兴和议都被屈辱叙事包围，却分别提供百年与数十年恢复时间。问题不在是否和谈，而在和平收益是否转化为备战、治理与社会韧性。北宋把和平消耗为军队失能，南宋则在十余年战争后形成更有效防线，却又清除最强的独立军队。

### 族群制度要同时回答治理、身份和利益

辽的南北面官保留不同生活方式，西夏以汉制和本族符号建国，金朝则在官僚汉化和女真特权间摇摆。文化相似不等于政治认同；若身份保护主要表现为土地和地位优待，既可能腐蚀基本盘能力，也会提醒多数人口自己仍是被统治者。

### 历史记忆总在替现实寻找可用人物

潘美变奸臣、王安石评价翻转、徽宗变文艺昏君、岳飞成为近现代民族英雄、《满江红》被牢牢绑定作者，都是后世根据自身问题重排材料。纠正神话不是取消人物价值，而是把事件事实、政治指控、文学功能和现代投射分别放回证据等级。

### 失去北方不等于失去全部中心性

南宋在军事和版图上明显收缩，却通过四书、道统、市舶、海军、铜钱和书籍构成另一种中心。文明、经济与政治边界并不重合；这种非领土中心性真实存在，也不能反过来美化普通百姓的税负、战争和权相统治。

## 一条演变时间线

960年赵匡胤由禁军拥立，逐步分割军权、先南后北完成大部统一 → 太祖猝死、太宗继位并两次北伐失败 → 辽萧太后与韩德让稳住幼主政权，1004年南下与宋订澶渊之盟 → 真宗以后战事减少，文官、科举和祖宗之法日益定型 → 仁宗朝和平繁荣达到高点，党项建西夏、宋夏战争暴露积贫积弱 → 庆历新政随外患缓解和内部反对夭折 → 神宗重用王安石，以富国强兵重建国家动员，新法执行异化并转为新旧党争 → 徽宗用蔡京、御笔手诏和文化工程扩权，联金灭辽 → 1125年金兵南下，宋军在燕京、河北和两次汴京围城中失去组织能力 → 1127年北宋亡，赵构在南方即位 → 宗泽整合忠义武装，岳飞等将领在长期战争中重建宋军，金朝亦因治理和兵源问题失去早期优势 → 1130年代宋金边打边谈，岳飞收建康、复襄阳并北伐，高宗目标转为以战促和 → 1141年前后双方和议，高宗收兵权并杀岳飞，绍兴体制成形 → 金熙宗、完颜亮清洗勋贵并迁都中都，1161年完颜亮南征失败被杀 → 金世宗与南宋维持长期和平，女真汉化与特权矛盾并存 → 高宗退位仍影响孝宗，光宗以后弱帝与权相相继出现 → 朱熹以四书道统重构儒学，南宋海贸、市舶和区域货币书籍网络持续扩张。

## 待外部核验的总问题

- 陈桥兵变、杯酒释兵权和太祖死因的材料年代、叙事层累与真实制度步骤。
- 宋辽各次北伐、澶渊之役、宋夏三战、永乐城及宋金战争的兵额、伤亡和后勤数据。
- 锁院、糊名、誊录的施行范围，以及科举扩大机会与社会出身变化的量化关系。
- 仁宗朝人口、财政、城市和救荒材料能否支持“最好成绩”的全国尺度评价。

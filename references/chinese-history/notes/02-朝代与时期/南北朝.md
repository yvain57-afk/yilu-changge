# 南北朝

## 时期总命题

南北朝不是南方越来越文弱、北方越来越汉化后自然归一的直线过程，而是多个政权用不同办法把军人、官僚、宗室、士族、寺院与普通编户接回国家。南方在刘裕之后拥有经济文化活力，却始终没有解决创业军功如何转成可信继承、宗室军队如何服从共同目标、社会财富如何进入财政的问题；侯景之乱把这些裂缝集中引爆，并使南陈失去长江中上游和淮南两道纵深。北魏从平城的农牧双重中心出发，以离散部落、太子监国、均田三长和迁洛逐步国家化，但强汲取、权贵特权与六镇机会坍塌又把统一北方撕成东西两部。北齐保有东部财富，却把汉人治理与鲜卑作战固定成互相怨恨的分工；西魏—北周则用周礼与鲜卑传统的双重语言，把关陇胡汉军人纳入共同上升通道。最终胜出的不是最富或最纯粹的一方，而是能让资源、身份与军事责任彼此转换的一方。这一重组又使“中国”从中原地理概念扩展为南北竞逐的文化身份，为隋唐统一提供更大的组织、人口和空间底盘。

## 五组问题

### 一、南朝军功如何取得并耗损合法性

- [[089-刘宋篡晋：刘裕的合法性是怎么得而复失的？]]：刘裕以恢复晋室、平乱和北伐让寒门军人取得开国资格，却因关中失守和杀害退位皇帝破坏最低安全规则。
- [[095-刘宋萧齐：政权更迭，一波N折]]：开国军权无法转成可信继承，低安全感促使皇室先发清洗；高门占名位、寒门掌实务又改变了南朝权力入口。
- [[097-问答：辛弃疾为何写下“元嘉草草，封狼居胥”？]]：元嘉北伐把功名冲动置于专业判断、后勤储备和地方责任之上，胜利幻觉遂转成江淮灾难。

### 二、北魏国家化为何同时积累新裂缝

- [[090-平城时代：拓跋珪为什么放弃繁华之都，选偏远之地？]]：平城同时连接草原兵源、农耕财政和河北通道，离散部落与人口集中使拓跋联盟转成官僚国家。
- [[091-子贵母死：乳母干政到太后专权]]：太子监国和子贵母死削弱旧部落与母族，却制造父子军政分裂，并把亲密政治交给乳母、养母。
- [[093-孝文帝改革：汲取了哪些中原经验？]]：均田、三长和俸禄先增强人口土地可见性，迁洛与身份改革再加速整合，也制度化了洛阳权贵与旧北镇的距离。
- [[094-六镇之乱：北方为什么再次分裂？]]：强国家能力若不能约束权贵、补偿边镇和安置灾民，汲取越深入，饥荒和机会差距越可能转成腹地战争。

### 三、象征、战争与组织状态怎样改变强弱

- [[092-问答：历代传国玉玺，是真实存在，还是神秘传说？]]：日常行政用玺与传国象征必须区分；多条互相冲突的传承说明，被相信的赝品同样能产生真实合法性效果。
- [[098-南北交兵：陈庆之如何创造军事奇迹？]]：七千白袍军深入洛阳既利用北魏组织瘫痪，也靠无退路和掠夺维持短期战意；北方网络恢复后，异常胜利很快触及上限。

### 四、梁武帝的扩大联盟为何没能阻止侯景之乱

- [[096-菩萨皇帝：“佛化治国”治得怎么样？]]：宽待宗室、尊重高门、教育寒门与佛化皇权扩大了联盟，却没有解决白籍逃税、宗室问责和财富转成军力的问题。
- [[099-侯景之乱：一个降将如何搞垮梁朝？]]：接纳侯景并非事前显然错误；宗室统帅、后勤不信任、换俘威胁、萧正德内应与勤王军保存实力共同摧毁台城。

### 五、谁能把富裕、兵源与身份接成统一能力

- [[100-注定出局：南陈和北齐为什么一定会失败？]]：南陈缺少上游和淮南纵深，北齐则把汉人筹资治理与鲜卑军人作战固化为分裂结构，二者都难把财富变成国家能力。
- [[101-北周之锋：宇文泰占据关中后，推行什么政策？]]：周礼和鲜卑传统为既成关陇权力提供双重接口，复姓、八柱国与府兵又让胡汉共享军事上升通道。
- [[102-问答：魏晋南北朝，为隋唐打下了哪些基础？]]：门阀入口、官僚复建、文化中国、南北核心区和东亚文明圈一起扩大，但这些结果不能为战乱代价辩护。

## 五条贯穿线索

### 合法性既能积累，也会被行动反向定价

刘裕的平乱与北伐能积累开国资格，杀害退位皇帝却提高此后每次权力交接的恐惧；传国玺的物质真假未必决定效力，关键是政治网络是否愿意承认；梁武帝即使被俘，名义仍足以遣散勤王军。合法性不是抽象道德评语，而是降低命令、继承和合作成本的可消耗资源。

### 国家看见人口之后，还必须约束代理人

北魏均田三长让土地与户口更可见，南朝白籍则展示普通人逃离赋役的相反策略。前者若缺少权贵约束，强汲取会变成土地兼并；后者虽给商业和个人留下空间，也削弱战时动员。登记能力本身没有固定善恶，关键是新增资源由谁取得、以何种规则使用。

### 财富、军队和责任需要同一转换接口

南梁富而弱、北齐富而败，都说明社会总量不会自动成为国家能力。宗室军队若把继承收益置于救援收益之上，汉人文官若只负责筹资而鲜卑勋贵只负责作战，财富与暴力就会落在不同责任体系。北周的相对优势，是让关陇胡汉都能经军人身份上升，并把土地、军户和战争义务接在一起。

### 改革解决旧问题时会制造新权力位置

子贵母死切断母族，却把乳母养母推入权力中心；迁洛消化中原，却让六镇军人从功臣变成边缘；梁武帝宽容宗室降低开国杀戮，却使亲族缺少问责。评估改革不能只看原目标是否实现，还要追踪被移除者留下的空位由谁填补。

### 统一的文化与空间底盘在分裂中扩大

南北双方互称索虏、岛夷，恰说明两边都把“中国”当成需要争夺的最高身份。人口与技术又在战争中进入河西、辽东、江南和东亚周边，北京、大同、南京、广州等节点上升。统一不只是恢复旧中原，也是在更大空间里重接此前形成的区域网络。

## 一条演变时间线

桓玄篡晋与孙恩余波削弱旧门阀—北府平衡 → 刘裕以恢复晋室、平乱和北伐取得军人开国资格，关中失守与弑杀二帝又损耗合法性 → 拓跋珪在平城连接草原、农耕与河北，以离散部落推进北魏国家化 → 太子监国、子贵母死切断旧部落干政，却形成乳母太后与父子分权 → 冯太后以均田三长、俸禄强化基层，孝文帝迁洛并重塑权贵身份 → 刘宋、南齐在继承暴力中依赖寒门实务官，社会文化仍继续发展 → 洛阳权贵与六镇军人机会分化，饥荒安置失败引爆六镇之乱，高欢、宇文泰分掌东西 → 梁武帝以宽容、教育和佛化合法性扩大联盟，白籍与宗室问责问题却未解决 → 陈庆之利用北魏组织真空深入洛阳，异常胜利反过来抬高梁武帝对北方冒险的信心 → 侯景降梁后遭不信任和换俘威胁，借寿阳、内应与掠夺性动员围攻台城 → 勤王宗室为保存继承实力互相观望，侯景借被俘皇权瓦解救援 → 梁朝余部继续内斗，西魏夺上游、北方取淮南，南陈失去纵深 → 北齐以汉人文官供养鲜卑军团而难约束功臣，北周以双重传统、复姓和府兵整合关陇胡汉 → 北周统一北方，隋唐将继承更宽的官僚、军人、身份与地理底盘。

## 待外部核验的总问题

- 刘裕北伐的兵力、关中撤退决策、刘穆之死亡影响，以及晋安帝、晋恭帝之死的材料层级。
- 拓跋珪离散部落、迁徙人口和平城粮食供给的实际规模；北魏为何不列传统十六国名单的编纂史。
- 太子监国与子贵母死的实施范围、拓跋珪家庭案件，以及常太后、冯太后权力来源。
- 秦汉六玺制度与传国玉玺各条传承的成书年代、实物证据和相互抄袭关系。
- 北魏均田、三长、俸禄的执行差异，迁洛决策和语言、姓氏、婚姻命令的长期效果。
- 刘宋、南齐宫廷暴力记载的作者立场，典签、寒门实务官与高门名位的实际边界。
- 梁武帝舍身、佛寺资源、黄白籍人口及南朝财富无法转成税役的量化证据。
- 元嘉北伐、悬瓠守城、陈庆之北伐的兵力与战果数字，以及后世文学如何重塑两场战争。
- 六镇灾荒、赴河北就食的命令与执行，高欢、宇文泰整合军团的具体路径。
- 侯景叛乱兵力、台城人口和勤王军行动；宗室继承动机与补给、命令混乱各占多大权重。
- 南陈失去上游、淮南后的真实防御选择；北齐财富、僧籍人口和文武族群分工的地区差异。
- 八柱国名单、府兵形成阶段、北周灭佛资源效果，以及唐代法统对周齐史书的影响。
- “中国”语义从地域向文化身份扩展的文本样本；日本四世纪移民假说与 410—413 年东亚通道的多证据核验。

# 元

## 时期总命题

蒙元史不能压缩成“骑兵征服、异族统治、九十余年而亡”。成吉思汗先用千户、怯薛、法令和文字把草原联盟改造成高动员国家，三次西征又以极端暴力重组欧亚人员、技术与贸易网络；但黄金家族与忽里勒台的世选原则无法匹配世界帝国尺度，大汗死亡多次让战争停顿、宗支竞争升级。忽必烈依靠汉地幕府夺位，以中原皇帝和蒙古大汗双重身份建立元朝，也使大蒙古国永久分裂。他用色目网络、行省放权、宗教户计、海运和纸币低成本连接多元疆域，却将赏赐、财政与身份差序的成本集中压向汉地特别是江南。科举恢复取得士心，基层重赋却失民心；“开河变钞”把长期吏治、灾害与白莲教组织汇成红巾起义。朱元璋胜出既靠军纪与组织，也靠南京、江南财赋、淮西骑兵和对手约束，并以天命而非现代民族主义承接元朝正统。1368年之后北元仍长期存在，说明中原王朝的终结与草原政治力量的消失不是同一事件。

## 七组问题

### 一、蒙古怎样从草原联盟变成征服国家

- [[211-一代天骄：成吉思汗统一草原]]：千户制打散旧部落，怯薛连接首领，文字与法令提高命令复制能力，骑射优势由组织放大。
- [[213-天道循环：女真衰落，蒙古崛起]]：野狐岭不是民族天赋战胜文明，而是蒙古机动协同撞上猛安谋克空心化、金廷误判和内耗。
- [[216-西进狂飙：三次远征，重组欧亚]]：西征既摧毁旧中心，也加密欧亚网络；征服范围越大，继承机制越难维持统一。
- [[212-问答：普通人读《昭明文选》还有用吗？]]：从古代选本的实用功能转向今日求知审美，提醒我们不要给经典硬造即时用途。

### 二、扩张为何反复被继承问题打断

- [[218-忽里勒台：蒙古汗位继承困局]]：黄金家族资格、忽里勒台认可、指定、长幼和实力并存，草原协调机制在欧亚尺度变成漫长空位与宗支冲突。
- [[219-汉化之路：忽必烈的汉人幕府]]：金莲川幕府、汉人世侯和东道诸王给忽必烈建立独立基本盘；钩考危机反映的是人心归属竞争。
- [[220-蒙哥之死：一个帝国，两个大汗]]：蒙哥死于攻宋途中后，忽必烈与阿里不哥同时称汗，大蒙古国的最高权威正式分裂。
- [[217-问答：云南怎么从南诏国变成了大理国？]]：南诏、大理和高氏相权展示西南贵族联合秩序，忽必烈征大理扩大控制却未自动解决攻宋问题。

### 三、忽必烈怎样建立既是中国又超出中国的元朝

- [[221-元朝诞生：从草原帝国到中原王朝]]：忽必烈以汉地财政军事赢得内战，以年号和文治补草原合法性，又保留大汗身份；元朝成立与四汗国自治同时发生。
- [[228-四等人制：忽必烈的平衡术]]：没有整齐统一的“四等人法典”，却有按归附时间与亲疏形成的身份圈层；色目官员成为财税代理和政治缓冲。
- [[231-中途改辙：从信用儒术到多元帝国]]：忽必烈巩固后疏远北方汉人，更多依赖蒙古、伊斯兰和藏传佛教网络，以汉地财富支付帝国联盟。
- [[233-放权增效：蒙古人的治国之道]]：皇帝凭怯薛式主奴信任向宰相和行省大幅放权，行政简洁，却缺少宋式制衡和共同官僚伦理。
- [[234-众教奔流：元代的宗教格局]]：诸色户计把信仰职业化，宣政院与帝师以宗教权威连接西藏，多宗教并存既是开放也是统治工具。

### 四、金宋覆亡为何不只是蒙古军强

- [[214-借道南宋：一条绝路通开封]]、[[215-君死社稷：金朝最后的抵抗]]：拖雷绕道、三峰山断补给和工程化围城摧毁金朝；金哀宗殉国又显示女真王朝已深度进入中原君主伦理。
- [[223-端平北伐：灭金成功，入洛惨败]]：南宋联蒙是受仇恨、现实威胁与借道压缩的选择，灭金后为政治象征排除专业将领、无补给入三京才是致命重复。
- [[224-似道有术：一战成名，一法误国]]、[[225-襄阳沦陷：贾似道的困局]]：贾似道有真实能力，却以夸大战果和派系化清算损坏组织；刘整水军、堡垒封锁、回回炮和宋军二重委托共同决定襄阳。
- [[226-崖山之败：帝国终于海上]]、[[227-问答：文天祥是怎么死的？]]：临安投降前宋的军事文官网络已离散；文天祥忠宋同时承认元朝文明资格，不能套成现代族群民族主义。

### 五、帝国连接怎样制造繁荣，也怎样分配成本

- [[229-马可·波罗：真的来过中国吗？]]：行纪有吹嘘和抄本层累，护送使臣、货币盐税等独立互证仍支持本人来华。
- [[230-东征日本：世界帝国的失败]]：蒙古骨干、高丽资源和宋降军被强行拼装，统帅制衡、会师失败与风暴共同造成失败。
- [[235-南来北往：求名北上，逐利南下]]：海运把南粮输往北京，财富南聚、官位北聚促成人口双向流动，也加速理学与汉文化扩散。
- [[236-士民异心：科举得士心，重赋失民心]]：小规模分榜科举提供象征公平，海运效率和帝国开支却把税负集中到江南少数地区。
- [[237-问答：一个阿拉伯商人为什么要屠杀宋朝皇室？]]：蒲寿庚事件来自私人海权、宋室特权、张世杰劫船与投元纳状，不能简化为某族群天性。
- [[334-书单推荐：想了解元朝历史，该读什么书？]]：战争、空间、财政、制度与史源辨伪需要不同书籍互证。

### 六、元末危机怎样被组织成全国反抗

- [[238-顺帝不顺：压垮元代的最后两根稻草]]：伯颜排汉与脱脱反向改革反复摆动；治河高效征发和无准备变钞把国家能力转成民众负担。
- [[239-元末大乱：红巾军起义是怎么爆发的？]]：白莲教把灾害、劳役、复宋想象与南北不平等编码成可识别组织，中央镇压又不得不依赖地方地主武装。
- [[240-和尚造反：被逼出来的开国皇帝]]：朱元璋从灾民、行童、乞食者到红巾将领，是退路逐一消失后的被动入局；南京和北方红巾才使长期积累成为可能。
- [[241-得天独厚：朱元璋的制胜密码]]：军纪与笼络士人是真能力，南京、淮西战马、对手约束和元大都对江南的依赖则是被官宣隐藏的硬优势。

### 七、元明鼎革该怎样理解，元朝又何时结束

- [[242-问答：元末起义算民族主义吗？]]：元末批判失政，朱元璋承认元曾受天命；“驱逐胡虏”到明中后期和晚清才被重写成民族革命符号。
- [[243-元朝余波：一个亡国政权的漫长告别]]：1368、1388、1402、1635分别对应中原统治、汉式朝廷、忽必烈谱系和大元象征的不同终点。
- [[232-问答：崖山之后无中国？唐宋变革论是怎么回事？]]：“崖山之后无中国”和唐宋变革论都经历了近代政治化，不能把文化创伤直接当作文明断绝。

## 六条贯穿线索

### 军事优势首先是组织优势

耐力马和复合弓只有在千户、狩猎协同、情报与纪律中才成为征服能力。蒙古军后来腐化，也说明所谓民族天赋不能脱离组织生命周期。

### 世界帝国与草原继承机制规模不匹配

忽里勒台适合能及时到场的贵族联盟，跨越欧亚后，大汗死亡会让远征和治理一起停顿。忽必烈以汉地基本盘解决自己的胜利，却以汗国分裂支付代价。

### 多元治理既是开放，也是成本配置

宗教并存、色目网络、行省放权和海运连接真实扩大了人口流动与知识交换；同一结构也用身份圈层和汉地财政维持精英联盟。评价“开放”必须追问谁承担账单。

### 国家能力有方向，效率不自动等于善治

回回炮、海运、治河、纸币和户计都显示元廷有动员和技术能力；当目标是征服、赏赐或紧急抽取时，效率越高，社会承压也可能越快越重。

### 正统叙事不断重写真实优势

忽必烈用中原皇帝身份补草原合法性，朱元璋又承认元朝天命以切断宋朝法统，并把南京、骑兵和对手弱点改写为仁义取天下。正统不是事实反面，而是对事实的选择性排序。

### 王朝边界不等于历史力量边界

1271、1368都只是特定政权形态的节点。四汗国、北元、鞑靼瓦剌与女真崛起让蒙古政治遗产继续塑造明朝，整齐断代必须由跨朝线索修正。

## 一条演变时间线

成吉思汗以千户、怯薛和法令统一草原 → 1211年野狐岭重创金军，蒙古由机动破坏转向围城与治理 → 1219年起三次西征重组欧亚，每逢大汗死亡即受继承牵制 → 窝阔台以后都城驿站扩张，黄金家族世选矛盾加深 → 蒙古绕道南宋、三峰山灭金主力，1234年宋蒙联合灭金 → 忽必烈经营金莲川、征大理，蒙哥攻宋途中死去 → 1260年忽必烈与阿里不哥并立，前者借汉地基本盘胜出，大蒙古国分裂 → 1271年建大元，以双重身份、行省、色目代理和多宗教网络治理 → 南宋端平入洛失败，贾似道政治与军队组织矛盾累积，刘整投元 → 襄阳失守，伯颜沿江推进，1276年临安降、1279年崖山亡 → 科举、海运、纸币与跨洲交流发展，帝国开支和江南税负同步上升 → 忽必烈东征日本失败，晚年政策转向多元帝国联盟 → 元中期行省放权、宗教竞争和南北流动持续 → 顺帝朝伯颜排汉、脱脱改革摆动，治河与变钞成为危机触发器 → 1351年红巾起义，中央军失能、地方武装坐大 → 朱元璋被迫投军，取南京后积累财赋骑兵，先灭陈友谅张士诚 → 1368年建明并北伐，元顺帝离大都 → 明军先夺山西甘肃，1372年深入草原失败，继而拆除云南辽东高丽支持 → 1388年捕鱼儿海重创北元朝廷 → 1402年前后蒙古分为鞑靼瓦剌，恢复草原军事形态并长期牵制明朝 → 1635年林丹汗之子向后金献玉玺，大元政治象征的一条延续线终止。

## 待外部核验的总问题

- 千户、怯薛、札撒和蒙古文字的形成时间、覆盖范围与后世追述。
- 野狐岭、三峰山、围攻开封和三次西征的兵额、伤亡与屠城数字。
- 大汗死因、忽里勒台召集范围及各宗支继承主张的材料差异。
- 忽必烈幕府、汉人世侯、钩考与征大理的具体行政财政关系。
- 1271建元和1260称汗两种起点所对应的制度变化。
- 四等身份圈层是否在地区、司法与任官方面一致，色目定义如何变化。
- 宋蒙联盟、端平入洛、襄阳救援、回回炮和崖山人口数字。
- 贾似道鄂州谈判、打算法、刘整投元及吕氏网络的史料冲突。
- 文天祥被俘后三年言行、亲属仕元与作品编纂的文本层次。
- 《马可·波罗行纪》抄本谱系及护送阔阔真、货币盐税等互证强度。
- 两次东征日本的舰队规模、会师决策与风暴影响权重。
- 行省实际自主权、蒙古语硬译公牍和基层吏员社会来源。
- 宣政院、帝师、诸色户计、儒户与宗教户免役的实际运作。
- 海运损耗、江南粮额、元大都消费和南北人口财富数据。
- 蒲寿庚家族来源、张世杰劫船与泉州宋室遇害材料年代。
- 顺帝朝治河人数、纸币发行、物价和灾害之间的量化关系。
- 白莲教、弥勒信仰、复宋口号与不同红巾集团的组织关联。
- 朱元璋早年传记、南京与淮西马场优势、陈友谅张士诚实力比较。
- 《谕中原檄》版本传播及元明鼎革民族革命叙事的形成阶段。
- 北元1388、1402、1635三种终点的蒙古文、明代和后金材料。

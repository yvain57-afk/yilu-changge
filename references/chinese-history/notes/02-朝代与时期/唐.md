# 唐

## 时期总命题

唐朝不能被压缩成“盛世开放、安史转衰”的抛物线。它接过隋朝统一后的官僚、交通和区域资源，先由李渊的旧网络与李世民的军事能力共同完成建国；太宗再以多来源官僚、纳谏机制和“天可汗”身份，在有限国力上经营多族帝国。武则天突破女性称帝障碍，不只靠个人强势，而是借高宗长期授权、佛教合法性、扩大选官和告密政治重组精英；她最终仍受父系宗庙和男性继承制度限制。玄宗清理政变联盟、恢复行政秩序，募兵、检括和节度使又把资源更快推向边疆；同一套高能力体制在晚年因君主信息封闭、宰相替皇帝背责、边将不可替代而失去安全冗余。安史之乱既有河北、财政、选官和跨族网络的长期燃料，也被玄宗杀将、逼战与父子双中心等具体决策放大。战后朝廷没有简单崩溃，而与藩镇、宦官、翰林、寺院及新财政工具维持了一个多中心百年；到黄巢之乱，两京精英、地方输血、军事服从与漕运同时断裂，唐朝才从仍能调节的弱帝国变成只剩名义的王朝。唐宋变化由此不是一日改朝，而是门第、科举、师生网络、地方幕府和文化正统长期重组的结果。

## 五组问题

### 一、隋末资源怎样变成唐初秩序

- [[113-大唐三百年：大唐为何成为永恒的文化符号？]]：以 755 年为转折而非终点，向前看魏晋隋制，向后看宋代新结构，并把帝王史扩展为社会与交流史。
- [[114-为驱除难：谁是隋唐之际的项羽？]]：李密受兵源和地方认同约束，虽未入关称帝，却以瓦岗军消耗隋朝东部主力，为唐朝承担了最难的清场成本。
- [[115-天策上将：正史美化李世民的战绩了吗？]]：李渊凭资历、亲缘和旧官僚建国，李世民以连续决定性战争完成统一；正史修饰不能消除真实军功。
- [[116-玄武兵变：是被逼无奈，还是蓄谋已久？]]：文学馆、十二卫与玄武门禁军构成长期准备，胜者的自卫叙事需由墓碑、敦煌材料和制度位置校正。
- [[117-问答：为什么评书里的隋唐人物，和历史上不一样？]]：说唐故事用历史人名承载草根豪杰伦理，人物原型考证与文学价值解释应分开。
- [[118-贞观之治：用人、纳谏和爱民]]：纳谏的制度价值在扩大信息样本、制造决策刹车；爱民既减轻痛苦，也服务户口、税役和国力恢复。
- [[119-天可汗：渭水之盟与漠北之战]]：灭东突厥依靠对手内裂、灾害与唐军多路机动；“天可汗”带来跨族权威，也带来长期秩序成本。
- [[120-高昌高丽：开拓边疆的得意与失意]]：高昌战争把丝路安全转为州县财政负担，高丽战争则因亲征把有限战果绑定为必须灭国的目标。
- [[121-太子之争：被教坏的、被偏爱的、被低估的]]：太宗的严厉教育和公开偏爱共同制造换储预期，储位零和竞争反过来影响亲征等当朝决策。
- [[122-问答：高句丽和正统王朝的关系，怎么论？]]：高句丽可同时向中原称臣、在半岛自居中心；唐通过联合新罗、先灭百济和利用内乱完成长期拆解。

### 二、女性称帝怎样突破又撞上制度边界

- [[123-则天传奇：什么因素成就了女皇武则天？]]：武则天早年并无既定称帝路线，储位变动、后宫制衡和皇帝挑战旧臣才逐层打开通道。
- [[124-小题大做：一桩桃色纠纷，还是一场权力革命？]]：长孙无忌集团把私案扩大为谋反清洗，高宗与武后又用后宫议题撬动辅政权臣，私人叙事可成为政治保护色。
- [[125-好风借力：从才人到女皇，谁为武则天推波助澜？]]：高宗长期授权让武后积累治理经验，敌手失败、武氏祥瑞与佛教语言再把临朝可能推向称帝。
- [[126-圣母临人：武则天的帝王上任“三板斧”]]：扩大选官、酷吏告密和形象工程分别招募支持、清除敌人、制造天命，也同步产生冗官、恐惧和财政成本。
- [[127-问答：了解魏晋南北朝，要先读正史吗？]]：隋唐史馆把多元个人著史重组为国家集体工程，“正史”身份的形成不等于每条材料天然可靠。
- [[128-边疆告急：武则天面对的时空困局]]：疆域最大化后，府兵反激励和多线作战已成结构负担；武后的军费分配与用人又使问题恶化。
- [[129-左右为难：江山姓武，儿子姓李，怎么办？]]：女皇可取得个人权力，却难在父系宗庙中建立母系法统，迎回李显是多种高风险方案中的最小风险选择。
- [[130-盖棺难定：子孙后代如何评价武则天？]]：神龙政变争的是临终控制和遗诏安全，后世评价又随血缘、创伤和政变合法性反复改写。
- [[131-边缘王子：那些被唐玄宗挪开的绊脚石]]：李隆基的边缘经历让他掌握基层军人和地方人才，韦后、太平公主占据高层却忽视执行链，终被斩首政变击败。
- [[132-问答：狄仁杰是怎么从“儒家官员”变成“神探”的？]]：狄仁杰的历史核心是儒家治理和政治说服，清代公案、高罗佩改写与影视传播才把他塑成全球神探。

### 三、开元能力为何在天宝转成风险

- [[133-明皇恩威：唐玄宗上位后的三大难题]]：玄宗以严惩、优待和制度化分别处理政变功臣、宗室与武周遗产，为开元治理清场。
- [[134-开元施政：用权术、立规矩、重改革]]：姚崇清网络、宋璟立规则，张说募兵和中书门下、宇文融检括逃户共同提升军政财政能力，也改变旧有均衡。
- [[135-口蜜腹剑：堂堂宰相，为啥上赶着“背黑锅”？]]：李林甫的长期权力来自行政能力和替晚年皇帝执行、担责，奸相叙事反而保护了明君形象。
- [[136-十节度使：边疆的辉煌战果与暗流涌动]]：资源集中换来突厥、吐蕃和中亚战果，却让专业军队依附边将；安禄山因真正有效才变得不可替代。
- [[137-问答：《长安的荔枝》里，高力士是隐形主角？]]：历史小说以普通人代价呈现抽象制度，高力士则展示接近皇帝而主动避开大政判断的安全型权力。
- [[138-国忠乱政：斗垮李林甫，再斗安禄山]]：峰值户口与边疆捷报遮蔽了安全冗余枯竭；杨国忠能理财、敢压太子，却无力维持官僚与边将之间的脆弱平衡。

### 四、安史之乱为何成为双输战争

- [[139-渔阳鼙鼓：一场酝酿已久的意外]]：河北相对衰落、跨族网络与选官财政是长期燃料，玄宗杀将、逼哥舒翰出关才把可控局势推向崩溃。
- [[140-马嵬惊变：这场兵变，玄宗在劫难逃]]：秘密逃亡、断粮和问责恐惧使禁军在无统一主谋下逐步越线，系统性失信让人人选择局部安全。
- [[141-天家父子：太上皇与皇帝暗斗，苦的是谁？]]：玄宗、肃宗维持礼法和谐，却争同一批军队、财政与合法性，前线因双中心承担额外损失。
- [[142-问答：粟特人为何能垄断丝路贸易，又为何渐渐消失？]]：粟特优势来自跨洲定居与萨保网络；其群体边界在故乡伊斯兰化、中国境内汉化中逐渐溶解。
- [[143-河北难收：这八年，大唐和叛军谁更惨？]]：叛军依个人威望而连续内斗，唐廷因猜将和外援代价无法彻底清剿，最终以赦免换取河北有条件归顺。

### 五、中晚唐怎样维持，又怎样失去全部支点

- [[144-中道沧桑：中唐的九位皇帝]]：安史平定至宣宗近百年并非直线衰亡，削藩、改革、反宦官和灭佛都受禁军、财政、身体及继承条件限制。
- [[145-藩镇利弊：藩镇问题为什么一直解决不了？]]：藩镇以地方调度效率交换中央控制，既截留财兵、又承担防务并需要皇帝任命保护，是弱唐也维唐的结构。
- [[146-宦官治国：掌禁军、掌枢密、娶妻养子]]：皇帝隔离成长、神策军、枢密信息和宦官婚养网络合流；宦官能拥立弑君，却必须依附李唐合法性。
- [[147-问答：古代帝王为何灭佛？唐朝朝廷和佛教的关系如何演变？]]：国家在合法性、治安和税基间时紧时松，度牒短期收入侵蚀长期税基，会昌法难又改变不同宗派的生存优势。
- [[148-仕宦生涯：唐代士人的理想仕途]]：门第、地域、科举、铨选、幕府和婚姻共同塑造仕途；翰林因皇帝私人秘书需求进入宰相—宦官之间。
- [[149-古文运动：从韩愈看中唐社会变化]]：韩愈以古文、道统、排佛和师生网络把个人突围变成文化工程，为宋代士大夫预制新模板。
- [[150-黄巢之乱：千万别惹卖私盐的落榜秀才]]：兵役失约、盐政网络、科举堵塞、灾荒与治理失灵汇合，使地方冲突沿贸易和运输线扩散全国。
- [[151-帝国落日：黄巢没赢，但大唐彻底输了]]：黄巢因长安粮运断裂而败，唐廷却同时失去两京精英、地方输血、军事服从和旧都承载能力。
- [[152-问答：少林寺的千年传说，有几分真，几分假？]]：少林的悠久历史与武术品牌应分层考证；不断吸收禅宗、武僧、秘密会社和大众媒介，才是传统延续的机制。

## 五条贯穿线索

### 功劳分配决定继承安全

李密替唐消耗隋军却不能取得唐的建国功，李渊与李世民分别拥有创建网络和统一战功；玄武门之变因此不是偶发宫斗。太宗处理承乾、李泰、李治时仍在解决“功劳、偏爱与法定身份”错位。武则天能取得最高权力，却无法把个人成就稳定转化为母系继承；玄宗、肃宗在战争中又因即位与平叛功劳相争。唐代政治反复证明：谁完成关键任务，与谁有资格继承，从不自动一致。

### 扩张能力会创造新的责任和依赖

“天可汗”让草原军力进入唐军，也要求朝廷维持多族秩序；安西四镇保护丝路，同时把遥远州县变成持续财政责任。府兵在远征、自备装备和授田不足下从奖励变成惩罚，募兵和节度使提高专业效率，却让军队忠诚越来越指向边将。安禄山不是因为无能而危险，恰因能解决东北问题而获得不可替代性。

### 信息质量比表面繁荣更能决定危机

贞观纳谏的价值是打破高级官员的信息垄断；玄宗早年也借不同类型宰相恢复秩序。到李林甫长期替皇帝执行和背责、杨国忠与安禄山互相刺激时，官方户口与边疆捷报仍好看，中央却失去对风险的可靠判断。潼关、马嵬和玄肃双中心不是经济数字自然导出的结果，而是信息封闭后的连续决策失败。

### 地方化既侵蚀王朝，也维持王朝

安史平叛以保留河北武装换停战，节度使由此可自行筹饷、用人和作战；可他们仍需要皇帝任命对抗部下，中央也需要其防御边疆。宦官同样能控制神策军与拥立，却无法脱离李唐名分自立。中晚唐不是“中央消失”，而是多个不完整权力中心互相借用，延长王朝也提高协调成本。

### 唐宋转型发生在职业与文化网络中

恩荫、门第婚姻和地理优势没有因科举立即消失，但进士、铨选、幕府与翰林让仕途出现新组合。韩愈以公开文章、师生网络和道统为资源不足者搭建替代关系；会昌法难又使更基层化宗派取得相对韧性。黄巢及后续战争重创两京高门，宋代更广泛的士人官僚结构不是突然发明，而是在这些断裂和替代中形成。

## 一条演变时间线

隋末李密据粮仓牵制东部主力 → 李渊凭旧网络起兵，李世民以陇西、河东、洛阳—虎牢战役完成统一 → 李世民经营文学馆、十二卫和玄武门关系，626 年夺位 → 贞观以多来源官僚和纳谏治理，630 年灭东突厥并获“天可汗” → 高昌纳入州县，高丽亲征受挫，储位在承乾、李泰、李治间重排 → 高宗借废王立武削弱长孙集团，武后因长期代理政务积累人事基础 → 690 年武则天称帝，以选官、酷吏和形象工程巩固武周 → 府兵衰败、多线边疆告急，698 年迎回李显 → 705 年神龙政变，李武两家围绕临终安全共同迫使退位 → 李隆基借基层禁军发动政变，清功臣、安宗室、用姚崇宋璟恢复秩序 → 张说募兵、宇文融检括，节度使集中边防资源 → 李林甫长期任相，安禄山兼有军事、贸易与跨族网络 → 杨国忠取代李林甫，宰相与边将冲突失去退路 → 755 年安禄山起兵，玄宗杀封常清、高仙芝并逼哥舒翰出关，潼关失守 → 马嵬兵变，玄宗入蜀、肃宗灵武即位，双中心争夺平叛目标 → 安氏、史氏连续内斗，唐借地方军与回纥收复两京 → 763 年以追首恶、赦胁从结束战争，河北三镇保留自治资源 → 代宗至宣宗近百年间，藩镇、神策军、宦官枢密、翰林和度牒共同维持多中心王朝 → 会昌法难重分寺院资源与宗派机会 → 门第、科举、幕府和师生网络继续重组士人社会 → 868 年庞勋之乱暴露兵役信用和东南财赋脆弱 → 黄巢沿私盐、灾荒与运输网络扩张，先下广州后入洛阳、长安 → 长安粮运断裂，朱温转降，沙陀军介入，黄巢败亡 → 两京精英、地方输血和军政关系无法重建，唐朝进入名义延续阶段。

## 待外部核验的总问题

# 明

## 时期总命题

明朝的兴亡不能归结为几个勤奋或昏庸的皇帝。朱元璋继承元末精简而薄弱的政府，把废相、地方三司、军户、里甲、海禁和严刑推到极致，短期形成低成本、高控制的皇权国家，也把行政能力押在皇帝个人判断上。朱棣依靠北方实战网络夺位，用内阁、宦官、科举与大型工程重建合法性；迁都北京和经营海洋边疆扩大国家动员，却把北防、南粮与皇帝私人执行体系的成本留给后世。中期以后，成熟官僚制能维持日常秩序，却难把商业繁荣、白银流入和社会活力转成可靠财政与军事能力。海禁制造倭患，低俸和刚性税役制造腐败，卫所逃亡与财政失真制造兵弱；张居正、戚继光等人的改革只有在政治联盟、组织建设和政策松绑同时存在时才有效。到万历、天启、崇祯，南方繁荣与北方危机并存，党争、灾害、白银收缩和女真崛起叠加。崇祯的勤奋没有修复组织，反以拒绝妥协、频繁换人和逃避具体责任放大了高度集权的错误。

## 七组问题

### 一、洪武国家怎样把皇权推到极致

- [[244-乾纲独断：朱元璋改写权力的游戏规则]]：废相和地方三司拆分中间权力，却使六部和全国事务直接压到皇帝。
- [[245-淮西集团：老乡变功臣，功臣变冤魂]]、[[251-孤家寡人：朱元璋的权力困境]]：创业信任网络在守成期变成威胁想象；清洗功臣、实封诸王和弱主继承互相冲突。
- [[246-反腐风暴：当严刑峻法碰上制度缺陷]]：空印、郭桓两案显示，严刑不能修复低俸、经费不足和刚性任务迫使官员违规的结构。
- [[248-小富难安：明初富户的四重劫难]]、[[249-苟全性命：洪武年间的平民生活]]：治理成本压向缺乏政治保护的富户、军户与普通家庭，秩序恢复不等于财富安全和自由流动。
- [[250-军户难捱：明朝的士兵为何成了逃兵？]]：卫所试图以世袭义务降低养兵成本，最终用逃亡、役使和战力衰退支付代价。

### 二、永乐政权怎样从夺位走向帝国经营

- [[253-塞上皇子：燕王朱棣的北平岁月]]、[[254-靖难之役：和平年代养不出战争之师]]：北平地理、边军与长期实战构成朱棣基本盘，压倒了承平后的南方朝廷。
- [[255-恩威并举：朱棣如何收服江南士大夫]]：惩罚建文旧臣后，朱棣仍须用内阁、科举和编书重建士人合作。
- [[256-太监出击：永乐年间的开疆拓土]]：宦官因依赖皇帝而成为情报、外交、宗教和边疆执行者，效率与绕开制衡同时增长。
- [[258-七下西洋：万邦来朝的盛世幻影]]：郑和航海展示国家组织力，却服务合法性与海禁管控，没有转化为民间持续扩张。
- [[259-迁都北京：一个正确的决定，两个错误的安排]]：北京连接北防与南粮，但让出大宁、停掉海运削弱了两条安全冗余。
- [[260-太子之争：永乐朝的储位风波]]、[[261-最后北伐：明成祖的草原执念]]：皇帝既要能干继承人又怕替代中心；群臣失去劝阻能力后，个人执念直接变成国家成本。

### 三、成熟官僚制为何既能续命又会失灵

- [[262-明朝帝系（上）：从仁宣之治到正德荒唐]]：仁宣恢复、英宗被俘与复辟、成化弘治守成和正德出走，是皇权与官僚制不断重组。
- [[263-土木之变：明军为什么打不过瓦剌？]]、[[265-御驾亲征：二十万大军的末路]]：卫所空心、情报瞒报、后勤仓促和无人纠错，使御驾亲征把结构脆弱集中引爆。
- [[266-保卫北京：瓦剌战略失误，大明险中求生]]：于谦的临时重组和瓦剌的目标混乱共同决定北京得守。
- [[267-畸形相权：文官与宦官撑起的权力中枢]]：废相后相权功能转入内阁票拟与司礼监批红，两者协作才构成真实中枢。
- [[268-正德突围：被简单化的“坏皇帝”]]：武宗借体制边缘人打破官僚因循，却没能建立可替代的新秩序。

### 四、思想、技术与全球联系怎样改变明朝

- [[252-问答：历代王朝的国号是怎么来的?]]、[[264-问答：谁终结了延续千年的封禅传统？]]：国号和礼制不是固定古制，而是统治者对族名、经典、空间与正统的重编。
- [[247-问答：刘伯温为什么会被神化？]]、[[257-问答：西方工业革命真是抄的《永乐大典》吗？]]：预言和技术民族主义都把后来的愿望倒写进历史，遮蔽真实人物与文献价值。
- [[269-问答：哥伦布发现美洲，是偶然还是必然？]]：个人到达充满偶然，多国竞争和高回报却提供反复试错；技术存在不等于制度允许试错。
- [[270-阳明心学：儒学走到明朝，为什么必须变？]]：知行合一与致良知回应八股官场的知行分裂，也释放个体主体性。
- [[279-问答：古代怎么培养翻译人才？]]：四夷馆随低地位和世袭化衰败，跨海贸易却持续培养民间多语者。

### 五、海禁为何把贸易社会推成倭患

- [[272-倭患爆发：大明朝的东南之乱从何而来]]、[[273-真假倭寇：海禁一日不除，倭患一日不止]]：日本战国、朝贡暴利中断、明军海防弱与沿海贸易生计叠加，把大量中国海商推入武装走私。
- [[274-问答：戚继光凭什么成为大明抗倭第一名将？]]：练兵、细节和文官信任使戚继光能在旧军制外创新；隆庆开海才把军事成果转成和平。
- [[271-明朝帝系（下）：从嘉靖到崇祯的百年沉沦]]：嘉靖以权术代治理，隆庆靠松绑缓解南倭北虏，万历以后有限增量追不上无限官僚成本。

### 六、改革与东亚战争怎样检验国家能力

- [[275-居正改革：一位务实政治家的十年]]：考成法、清丈、一条鞭与边防用人能执行，前提是皇帝、太后、司礼监和相权结成政治联盟。
- [[276-壬辰倭乱：一场改写东亚秩序的战争]]：丰臣秀吉的扩张、朝鲜军备腐化与明朝信息迟缓，使体制外翻译和商人成为临时外交工具。
- [[277-和战之间：三年谈判，一场骗局]]：平壤火炮胜利没有消除家丁损失、后勤疾病和内部排挤；和谈是在双方无力决胜时出现的制度替代。
- [[278-龙头蛇尾：四百年前的战争，为何至今仍是东亚心结？]]：战争恢复了明—朝鲜秩序，却给三国留下不同成本；前现代多元主权与现代民族叙事继续冲突。

### 七、晚明繁荣为何没能阻止系统崩溃

- [[280-成败万历：大明朝的南北撕裂]]：南方市场文化繁荣与北方财政防务危机同时存在，固定银税和掠夺式加派阻断财富转化为公共能力。
- [[281-何以忠贤：大明第一权宦的升职路]]、[[282-天灾人祸：崇祯面临怎样的烂摊子]]：魏忠贤的异常授权依赖正常班子崩坏，文官又借其权势清算，系统自毁先于个人奸恶。
- [[283-进退失据：数目字管理与红夷大炮]]：百姓负担重而国库所得少；三饷、裁驿和放弃葡萄牙炮兵体系，使应急政策反向资助对手。
- [[284-问答：历史上真实的于谦和海瑞是什么样的？]]：清官能局部纠偏，却难替代可持续制度，越不肯通融也越难与低薪腐败系统协作。
- [[285-亡国之君：崇祯的勤奋为何成了灾难]]：拒绝和谈、频繁换人和只作宏观罪己，使勤政在高度集权下连续放大错误。

## 六条贯穿线索

### 集权消灭中间人，也消灭缓冲器

废相、清洗功臣、分割地方权力能压低篡位风险，却让政策、用人和危机应对直接依赖皇帝。内阁与司礼监后来悄然重建相权功能，证明复杂国家无法真正没有中间层。

### 低成本国家把账单转给特定家庭

军户、富户、里甲、差役和低俸看似节省国库，实际把军事、行政和征收成本固化给缺乏议价权的家庭。逃亡、腐败和隐匿不是偶然道德失败，而是长期成本外包的回声。

### 国家能力越强，方向错误时损失越大

洪武严刑、永乐北伐与远航、嘉靖海禁、崇祯三饷都显示明朝并非没有动员力。问题在于能力服务何种目标、能否接收坏消息、能否在失败后调整。

### 社会繁荣不自动转化为公共财政

晚明市场、出版、思想与海贸蓬勃，固定税额、税收中介和北方防务却让国家越来越穷。经济总量增长与财政组织能力是两件事。

### 专业能力需要政治与制度容器

于谦、海瑞、戚继光、张居正、沈惟敬都不能只凭个人品质改变系统。专业成果能否留下，取决于信任网络、授权、财政、政策松绑与继任安排。

### 全球连接既提供资源，也制造比较压力

白银、火器、翻译、郑和航海、哥伦布和朝鲜战争让明朝始终处在跨区域网络中。海禁并未切断联系，只把合法渠道压窄，让国家更难识别和利用已经发生的社会变化。

## 一条演变时间线

朱元璋以南京和江南财赋建立明朝 → 废相、地方三司、严刑与军户里甲把皇权推向极致 → 清洗淮西功臣、实封诸王，太子早逝后形成强藩弱主 → 燕王朱棣凭北方实战网络发动靖难夺位 → 惩罚建文旧臣后以科举、内阁和编书吸纳士人 → 宦官被用于情报、外交与边疆，郑和七下西洋展示国家能力 → 迁都北京，停海运、让大宁埋下北防与南粮风险 → 仁宣转向恢复，成熟官僚制形成 → 土木堡因卫所空心、后勤仓促和无人纠错惨败 → 于谦重组北京防务，瓦剌战略犹疑使明朝脱险 → 内阁票拟与司礼监批红形成事实双中枢 → 正德以边缘人冲击官僚因循，未能建立新秩序 → 嘉靖海禁与东南贸易需求冲突，武装走私被统称倭寇 → 戚继光组织新军，隆庆开海与互市把军事胜利转成和平 → 阳明心学和民间多语人才反映社会主体与跨海联系成长 → 张居正以政治联盟、考成法、清丈和一条鞭恢复执行与财政 → 丰臣秀吉侵朝，明朝经平壤、碧蹄馆与三年和谈进入东亚大战 → 秀吉死后日军撤退，旧秩序恢复但三国成本深重 → 万历后期南方繁荣、北方危机与财政汲取失灵并行 → 天启朝正常中枢破坏，魏忠贤与文官党争相互利用 → 崇祯除魏后同时面对官僚腐败、灾害、白银收缩和女真崛起 → 三饷、裁驿、拒绝和谈、频繁换将和放弃火器合作连续放大危机 → 1644年李自成入北京，崇祯自缢，明朝中枢覆亡。

## 待外部核验的总问题

- 洪武废相后六部奏事量、朱元璋实际工作强度及地方三司协作方式。
- 胡惟庸、蓝玉案的案卷层累、牵连人数和后世政治加工。
- 空印案、郭桓案的发生时间、定罪逻辑、处决与追赃数字。
- 洪武富户迁徙、鱼鳞图册、里甲、路引与各地实际执行差异。
- 军户逃亡率、屯田产出、军官役使和卫所战斗力的地区变化。
- 朱棣生母、北平战功、《明太祖实录》重修与靖难叙事的史源层次。
- 永乐宦官使团、郑和船队规模、财政成本和朝贡贸易收益。
- 大宁、海运与迁都北京的长期成本如何量化。
- 土木堡兵额、路线决策、伤亡和也先内部目标的材料差异。
- 内阁票拟、司礼监批红在不同时期的实际权重。
- 《永乐大典》收书规模、散佚过程和辑佚贡献；所谓工业革命抄袭说的传播链。
- 明代封禅决策、五岳礼制及历朝国号解释的文本演变。
- 王阳明思想与商业社会、皇权松动之间的因果强度。
- 嘉靖倭寇人员构成、王直与地方官军关系、隆庆开海效果。
- 戚继光战绩、戚家军编制、军饷来源及张居正政治保护。
- 张居正清丈数字、一条鞭法地区差异与考成法实际执行。
- 丰臣秀吉战争目标、平壤与碧蹄馆战损、降表与诰命的真伪及解释。
- 壬辰战争人口、耕地损失和援朝对明财政、女真崛起的影响权重。
- 明代官方翻译机构人数、语种与民间多语者活动材料。
- 万历时期经济繁荣、白银流量、固定税额与矿税使的真实财政比例。
- 魏忠贤早年经历、阉党边界、东林党内部差异及天启中枢运作。
- 明末人口、灾害、白银收缩、三饷、内帑与裁驿的量化关系。
- 葡萄牙炮兵合作、红夷炮实战效果以及决策中断原因。
- 崇祯议和、换相换将频率与具体责任链的材料分歧。

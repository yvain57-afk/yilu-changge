# 307 台湾设府：郑克塽降清

## 一句话命题

清廷从借荷兰海军、以迁海切断明郑，到培养水师、任用姚启圣和施琅，经历了二十余年才补上海战短板；迁海以沿海社会的巨大灾难换来有限封锁，最终决定台湾归属的仍是大陆统治稳定、明郑内斗与清廷组织学习。

## 内容地图

### 论点

1. 1663 年清荷合作攻克厦金，所谓《清荷协约》包含自由贸易、驻军和台湾让荷等条款，却须清廷批准；荷方始终未获正式批准，协议没有效力。
2. 清军不懂水战，荷兰又退出合作，清廷遂把明代海禁升级为沿海迁界，企图直接清空辽东至广东的海岸人口。
3. 迁海造成急迫搬迁、焚屋毁船、冻饿与屠杀，官方记录却淡化责任；它没有切断两岸贸易，反而迫使明郑屯田、加速开发台湾。
4. 三藩之乱期间郑经重占厦金并扩张，随后败回台湾、死后再起权斗；清廷平定三藩后才得以集中资源解决东南。
5. 姚启圣改善福建治理、反对封禁并建设水师；施琅带着郑氏海战经验和私人复仇动力领兵，1683 年迫郑克塽降清，1684 年台湾设府隶福建。

### 因果链

清军海战无能 → 借荷兰舰队但互不信任 → 迁海封锁造成社会灾难 → 贸易仍以地下方式延续、明郑转向台湾屯田 → 三藩平定与明郑内斗改变力量对比 → 清廷任用专业降将、建设水师 → 郑克塽降清 → 台湾府进入常规行政体系。

## 关键对象

- **郑经、郑克塽：** 明郑第二、三代领袖，继承合法性与内部争斗持续消耗政权。
- **迁海令：** 以清空沿海人口实现军事封锁的极端政策，成本主要由平民承担。
- **姚启圣：** 兼顾福建治理、招抚与水师建设的总督。
- **施琅：** 郑氏旧将、清军攻台统帅；专业能力和复仇动机被康熙定向使用。

## 刘勃在反驳什么常识

反驳“清荷正式签约把台湾许给荷兰”，也反驳“严厉海禁自然能饿死海上政权”。纸面禁令无法消灭亲缘与利润驱动的网络，反而可能把资源和人口推向对手。

## 这一讲改变了什么视角

台湾设府不是一次海战孤立决定，而是大陆与岛屿两套政权在财政、内部稳定、海军学习和对外合作上的长期竞赛。康熙用人不要求道德完美，而是把施琅的长处和动机放到限定任务中。

## 争议、证据边界与外部核验

- 《清荷协约》的文本、签署权限与清廷是否口头认可需比对荷兰档案和中文奏疏。
- 迁海范围、死亡和屠杀数字多来自地方志与私人笔记，官方沉默本身不能替代个案核证。
- 明郑屯田对台湾原住民土地与社会的影响需引入地方和族群史研究。
- 清军攻台兵力、战损及姚启圣、施琅各自贡献存在功劳叙事竞争。

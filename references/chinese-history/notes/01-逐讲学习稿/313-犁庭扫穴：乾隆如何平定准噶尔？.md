# 313 犁庭扫穴：乾隆如何平定准噶尔？

## 一句话命题

雍正为集中对付准噶尔而在边界上让步，却因猜忌汉将、远程微操和八旗衰落未能取胜；乾隆抓住准噶尔继承内乱，以高风险、残酷征发和宗教动员完成七十年战争的终局，换来陆地边疆稳定，也留下战争伦理与开发方式的沉重问题。

## 内容地图

### 论点

1. 雍正与俄国签《布连斯奇条约》、向安南让地，体现传统天下观轻视边界不可逆性，也服务集中力量对准噶尔的战略。
2. 年羹尧、岳钟琪有西北经验，雍正却在稳权后清除前者，又因岳飞后裔想象、告密案和身份不安持续猜忌后者。
3. 1729 年两路出征中，雍正误信和谈、频繁干预；和通泊八旗惨败，岳钟琪西路获胜却仍被治罪，显示绿营精锐更能战而皇权更不敢信任。
4. 1734 年清准议和维持二十余年。噶尔丹策零死后，诸子争位、汗国分裂，大量难民向清廷提供情报，乾隆判断出现了一次性灭国窗口。
5. 乾隆仓促出兵并要求“因粮于敌”，第二次征发转压漠北蒙古并引发反叛；章嘉、哲布尊丹巴协助安抚，清军最终消灭准噶尔，手段极其残酷。

### 因果链

雍正集中战略 → 边界让步、猜忌前线将领 → 缓兵误判和八旗惨败 → 清准暂时议和 → 准噶尔领袖死、继承崩裂 → 难民带来情报 → 乾隆抓住窗口仓促远征 → 后勤不足压榨盟友并引乱 → 宗教网络安抚、清军取胜 → 汗国消失而南疆再起反抗。

## 关键对象

- **年羹尧、岳钟琪：** 有前线能力却被继承初期的皇权不安逐步排斥。
- **和通泊之战：** 八旗衰退、绿营精锐与政治信任错位的集中暴露。
- **噶尔丹策零：** 维持准噶尔强盛的最后一位优秀汗王，其死触发继承崩溃。
- **章嘉、哲布尊丹巴：** 把皇帝意志翻译为宗教诉求、安抚漠南漠北的权威节点。

## 刘勃在反驳什么常识

反驳“雍正只因勤政所以擅长一切”，也反驳“乾隆平准只是准备充分后的必胜”。勤奋微操可能伤害前线，乾隆的胜利来自抓住对方内乱窗口，同时承担极高后勤和政治风险。

## 这一讲改变了什么视角

战争能力不等于名将或精兵数量；皇帝能否信任专业人、识别短暂机会、组织补给并维持盟友，决定资源能否转成结果。边疆胜利还需与战争手段、当下民生和长期稳定分别评价。

## 争议、证据边界与外部核验

- 雍正让地数量、条约含义和天下观动机需结合谈判档案核验。
- 年羹尧、岳钟琪与雍正关系不能仅由小说或皇帝朱批的表面亲疏判断。
- 和通泊兵额、伤亡以及八旗、绿营战力对比存在地区与时期差异。
- 准噶尔灭亡人口损失和清军政策需用多语种材料处理，避免用胜利者叙事淡化暴力。

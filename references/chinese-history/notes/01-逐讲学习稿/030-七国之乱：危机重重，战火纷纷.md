# 030 七国之乱：危机重重，战火纷纷

## 一句话命题

文景低干预政策释放财富，也使贫富分化、私人暴力和诸侯资源同步增长；吴国以盐铜收入提供中央郡县给不起的低税低役，获得真实吸引力，景帝粗暴削藩遂把长期猜疑推成战争。七国经济虽强，仍在三个月内败给西部中央军，叛乱反而成为朝廷收回封国军政权的加速器。

## 内容地图

### 问题

贾谊为何在繁荣时期写下充满危机感的《治安策》？文景时期的贫富分化怎样直接削弱国家能力？游侠为什么会在低干预与治安缺位中成长？分封制除了割据风险，还有哪些统治成本和地方激励优势？吴国为何能比相邻中央郡县更优待民众？刘邦预言刘濞造反的故事承担什么叙事功能？景帝削藩怎样把不信任变成七国之乱，朝廷胜利后又如何重启集权？

### 论点

贾谊《治安策》用痛哭、流涕、长叹表达对文帝时期的深度忧虑，原文残缺使各项具体所指仍有争议。综合课程材料，文景繁荣背后至少有四组问题，严重程度依次上升：贫富分化、社会治安、匈奴威胁、诸侯王坐大。它们不是盛世的反面标签，而是低干预政策的内生副作用。

自由经营和商品流动增加社会财富，却使本就有资本、技术与网络的人更快积累，农民则更容易陷入债务、失地或贫困。司马迁在《货殖列传》中肯定商人组织流通的价值，贾谊、晁错、董仲舒等许多思想家却把商人巨富与奢侈视为严重道德问题。双方争论之外，朝廷最焦虑的是穷人卖身为奴后从户籍与税役体系中消失：私人财富吸收了国家原本可以征发的人口。

贫富分化还与治安相连。市场不会自动保护走投无路者，穷人可能用暴力求生，富人则购买暴力保护财产或压迫他人，游侠因此膨胀。官府不愿或无力介入时，侠提供私人秩序；到景帝时期，某些大侠号称能调动接近诸侯国的力量。

《史记》塑造少数守信重义的大侠，成为后世文人侠客想象的来源；司马迁自己也承认多数侠并无高尚人格。其作品一处称文帝时期物质充足、人较自爱，另一处的游侠故事却显示犯罪和私人暴力并不少。《汉书》把肉刑减轻与违法顾忌下降联系起来。课程在这里更信班固的总体判断，同时提醒“中民”家庭的安定经验不能代表所有阶层。

匈奴是第三组压力。和亲与消极防御能降低大规模战争，却没有消除边境骚扰，中央仍要承担长期戍边和财物支出。更严重的是诸侯国问题：在自由放任环境中，中央直辖郡县的发展不一定优于封国，重新显示分封制在特定条件下的吸引力。

大一统郡县有长期统一优势，也有高昂固定成本。即使文帝薄葬，霸陵仍动用大量刑徒；课程把其规模与秦始皇陵对比，强调“比秦节制”不等于按现代标准低成本。边防更要让远离北方的百姓自备路粮、长途服役，往返时间还可能不计入役期。中央提供全帝国安全，负担却不均匀压到直辖人口。

诸侯国治理半径短，国王又有世袭预期，可能比频繁调动、追求任期业绩的郡守县令更愿作长期经营。吴王刘濞拥有盐、铜和铸币优势，可以不向民众征税；本地一月劳役按市价付酬，也少有远距离戍边。郡县人口逃入吴国时，他还阻止中央官吏跨境抓捕。中央臣民承担国防而吴国共享安全，造成明显的待遇与责任不对称。

文帝个人即使愿意爱民，也受中央国防、宫廷、陵墓和贫困地区开支约束，无法复制吴国政策；中央命令经过郡县长链也会变形。吴国、齐国则有盐铜、商业传统和较短治理链，经济与城市繁荣长期领先。临淄到武帝初仍可被齐人称作比长安繁华，说明中央能汲取天下，不等于地方市场自然不如首都。

七国之乱的史书叙事先安放一条宿命线：刘邦封侄子刘濞时便预言五十年后东南之乱会由他发动。开国皇帝预知未来，是正史常用套路，可把叛乱写成早有征兆、最终仍在王朝掌握中。司马迁随后又写出吴与朝廷长期结怨，责任并非只在一方。

中央因吴国繁荣和实力不断怀疑诸侯，诸侯又因削弱预期而加强防备。景帝的政治技巧不如文帝，接受晁错建议直接削减封地，使各王相信即使不反也会逐步失去一切。刘濞联络七国起兵，表现出一种自我实现机制：预设对方必反、连续采取预防措施，最终让反抗成为对方剩余的选择。

吴国吸引力在周丘支线中格外明显。这个一向被视为无用酒徒的人独自回到东海郡下邳，号召反汉，一夜得到三万人并攻城略地。数字和情节可能夸张，但邻近郡县民众长期比较吴国待遇后愿意转投，并非不可解释。叛军动员不仅靠诸侯野心，也借助中央治理成本的不公平分配。

朝廷平叛时亦有恐慌、私怨和残酷命令。景帝要求深入、多杀为功，对议论或执行不力者处以重刑。司马迁没有因此把叛军写成正义一方，也把周亚夫、窦婴等汉将塑造得极有英雄气概。他保留双方动机和污点，使七国之乱不像单线忠奸剧。

战争结局仍显示结构差异。东部封国有经济优势，生死战争中却不及西部中央的军事、地理和组织优势；只要长安朝廷没有完全失控，七国联盟难与中央持久对抗。叛乱约三个月平定，景帝随即取消诸侯国部分军权，让更多封国官员由中央任命。原本由低国家能力造成的危机，反而为国家机器重启和加速提供正当性。

### 论据类型

- 政论文：《治安策》的危机语言与残篇争议，显示盛世内部的忧虑。
- 财政机制：贫民卖身后脱离户籍，私人占有人口侵蚀税役基础。
- 史书互证：《史记》的游侠浪漫、自爱说与《汉书》的治安判断互相校正。
- 成本比较：皇陵刑徒、边防戍役和长途自备粮说明中央统治固定成本。
- 地方政策：吴国免税、役工付酬、阻止跨境抓人及盐铜铸币收入。
- 城市比较：临淄与长安的繁荣声誉，显示封国经济并非天然落后。
- 叙事套路：刘邦预言刘濞反叛，为官方历史加入宿命与掌控感。
- 战争结果：周丘动员、景帝严令、周亚夫窦婴平叛与三个月结束。

### 因果链

文景自由放任和低干预 → 财富总量增长但资本向富商、旧贵族集中 → 贫民卖身、国家税役人口流失，私人暴力与游侠扩张 → 盐铜资源与较低统治成本使吴齐等封国发展更快 → 中央承担国防而封国以低税低役吸引人口 → 朝廷把封国繁荣视为安全威胁 → 景帝直接削藩使各王人人自危 → 吴楚七国起兵 → 东部经济优势不敌中央军事优势 → 三个月平乱 → 景帝借机收回封国军队与官员任命权。

### 结论

七国之乱不是文景之治突然出现的意外，而是低干预、郡国并行与中央国防成本长期叠加的结果。封国对当地人的善政可以真实，中央对割据的恐惧也可以合理；双方互不信任把制度张力转成战争。中央取胜后，危机本身成为集权扩张的资源。

## 关键对象

### 人物与群体

- 贾谊：在文帝繁荣期用《治安策》指出结构危机的政论家。
- 晁错：推动景帝直接削藩、触发诸侯集体恐惧的政策人物。
- 汉景帝：以较粗暴方式削藩，并在平乱中使用严厉动员。
- 吴王刘濞：凭盐铜、铸币和低税役经营强大封国的叛乱领袖。
- 周丘：以地方待遇差异动员下邳民众的叛军支线人物。
- 周亚夫、窦婴：被司马迁写出英雄气概的汉军平叛将领。
- 富商、农民、奴婢与游侠：财富分化和官府缺位中位置不同的社会群体。
- 郡县官吏与诸侯王：短期任职激励与世袭经营激励的对照者。

## 刘勃在反驳什么常识

第一，文景之治不是没有严重问题的黄金时代。低干预带来的繁荣与分化、暴力、边防和诸侯风险同时增长。

第二，商人不直接耕作不等于不创造社会价值；但财富增长也不会自动解决穷人失地和国家税源流失。

第三，《史记》的侠客英雄不能代表多数私人暴力。浪漫叙事与治安现实需要分开。

第四，分封制不只有割据缺点。治理半径短、固定成本低、统治者有长期经营预期，可能改善地方待遇。

第五，皇帝仁爱不保证郡县民众待遇优于封国。中央承担的国防成本和行政长链会限制善意落地。

第六，七国之乱不是刘濞天生反相的命定事件。长期猜疑、利益差异和景帝削藩共同制造了行动条件。

第七，中央集权不是只靠预先设计推进。一次叛乱失败也会成为收权、改官和重启国家能力的机会。

## 这一讲改变了什么视角

同一项公共安全可能出现受益范围大、付费范围小的问题：中央郡县居民承担边防，诸侯国居民同样受保护却少服外徭。若治理体系不能解释这种责任差异，人口就会用迁徙投票。地方更受欢迎不必证明它能承担全国责任，却足以削弱中央合法性。

## 争议、证据边界与外部核验

- 《治安策》篇章残缺，“一痛哭、二流涕、六长叹”各指何事存在长期争论。
- 把文景问题按贫富、治安、匈奴、诸侯排序是课程综合模型，不是贾谊原文的完整目录。
- 商人致富、农民贫困和卖身为奴的规模及因果关系需以户籍、契约和区域材料量化。
- 《史记》《汉书》对犯罪率的判断立场不同，“中民”经验与底层经验的区分仍属解释。
- 霸陵刑徒三万一千、秦陵七十万等人数及劳动方式应结合考古报告和传世记载核验。
- 诸侯王比流动官吏更关心长期民生是一种激励模型，也可能出现世袭剥削和地方暴政。
- 吴国免税、付役工钱、盐铜收入和阻止跨境执法的范围，应按《史记》《汉书》具体条目复核。
- 周丘一夜得三万人极可能经过夸张，适合说明地方动员，不宜作精确数字。
- 刘邦预言刘濞反叛具有史书套路，不能作为刘濞先天有反意的证据。
- 七国兵力、平乱三个月的起止时间、景帝诏令与战后收权措施需按纪年核对。

# 311 蒙藏牵连：三征噶尔丹

## 一句话命题

噶尔丹失去准噶尔本部后选择南下，以俄国暧昧支持和驼城火器逼近北京，却被清军重炮与康熙的外交拖延击败；三次亲征消灭了噶尔丹个人，多伦会盟则把漠北纳入盟旗，而准噶尔、俄罗斯和藏传佛教的三角问题仍延续数十年。

## 内容地图

### 论点

1. 噶尔丹不愿回师与侄子内战，转而要求清廷交出土谢图汗和哲布尊丹巴，并以南下胜利恢复声望。
2. 俄方代表戈洛文只派观察者，保留“胜则分利、败则不认”的空间；噶尔丹夸大为俄军援助，康熙则一面和谈拖延集兵、一面以开战威胁俄国。
3. 1690 年乌兰布通，噶尔丹以骆驼、轻火器筑驼城，适合远征并压制传统骑兵；在北京附近却遭清军重炮摧毁。
4. 1691 年多伦会盟把盟旗制度扩至喀尔喀，漠北由藩属式朝贡转为清朝深度管控疆域。此后两次亲征将无本部可归的噶尔丹逼至死亡。
5. 策妄阿拉布坦重新壮大准噶尔并与俄国冲突。蒙古依赖藏传佛教的低成本权威，达赖与和硕特汗又需清廷册封，使蒙古竞争必然牵动青藏高原。

### 因果链

噶尔丹丢失伊犁本部 → 选择南下争取声威 → 俄国提供模糊信号、双方假意和谈 → 驼城推进到北京近郊 → 清军重炮击破 → 多伦会盟制度化漠北归附 → 噶尔丹死而准噶尔未亡 → 准噶尔竞争转向俄国与西藏。

## 关键对象

- **乌兰布通之战：** 轻火器远征体系撞上清军近地重炮优势的决战。
- **多伦会盟：** 清廷将盟旗推广到漠北、把救援回报转成制度控制的节点。
- **策妄阿拉布坦：** 噶尔丹侄子和准噶尔新主，使汗国在噶尔丹死后复兴。
- **达赖与和硕特汗：** 西藏宗教、世俗权威的两端，均接受清廷册封。

## 刘勃在反驳什么常识

反驳“三征噶尔丹等于彻底消灭准噶尔”，也反驳清俄条约自动排除秘密博弈。战争消灭一位领袖，制度会盟重组一片地区，但跨境力量仍会寻找新的联盟和战场。

## 这一讲改变了什么视角

蒙古、西藏、俄罗斯不是三条独立边疆线：宗教权威、武力保护、册封名分和火器贸易把它们连成一个系统。康熙的优势在于能同时运用外交、拖延、重炮和制度吸纳。

## 争议、证据边界与外部核验

- 俄国对噶尔丹的支持程度需区分中央政策、戈洛文行动和噶尔丹宣传。
- 乌兰布通双方兵额、战果及“驼城”细节有史料差异。
- “三次御驾亲征”中康熙实际前线指挥程度不同，第一次因病缺席决战。
- 清朝对青藏的“完整宗主权”是名分判断，不能等同当时直接行政能力。

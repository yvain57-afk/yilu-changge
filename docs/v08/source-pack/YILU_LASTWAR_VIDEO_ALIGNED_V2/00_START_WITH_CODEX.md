## 本轮一次交付
将现有三关改为同一连续跑道规则的三种组合：
A. 动态正负门＋兵员/武器耐久奖励＋敌群；
B. 同路多列目标＋中央分隔视觉/可见结构＋特殊桶释放连续+1门；
C. 前段准备和换装＋高耐久目标＋距离推进中的大型敌将。
不是三套游戏；没有软件锁路线、侧路扩展/合流、强制近战对决或自动清兵。

第一关先内部打通，再复用到二三关。这个顺序不是新的用户审批停点。出现真正权限/素材阻塞，只停受影响部分，继续其余任务。不要用草模/单图/测试日志结束整轮。

## 必须看到的改变
- 持续瞄准红门，数字逐次变小，跨0后变成蓝门；来不及则可横移绕开。
- 打桶时耐久下降；桶顶图标说明奖励。打破耐久60的桶，绝不能默认加60人。
- 扩军后阵形与出弹数量增长；武器桶带来另一条火力成长。打桶与打敌人竞争同一份时间和火力。
- 特殊目标释放一串独立+1门，必须实际经过它们才能逐个获益。
- 队形边缘接近负数门也有真实风险；每扇门各自只结算一次，不再以旧“每排互斥”冒充参考规则。
- 常规关的剩余敌军、大型敌将血条、距离进度是不同数据，不能用一个数字乱换名称。

# 《一路长歌》Last War 视频实证对齐包 v2

交付性质：根据用户2026-09-23上传的下载录像与Codex分析，规划并提供可执行开发合同、三关初值和少量纯函数参考。未修改用户工作区，未运行Cocos或手机游戏。

## 怎么使用
将整包交给当前开发中的Codex，复制 `00_START_WITH_CODEX.md`。以当前最新本地工作区为准；不要回退到之前的固定倍增门、独立难易分路或击杀升级版本。

## 核心变更
可射击改变的正负门；独立耐久和奖励的兵员/武器箱；多源弹道的真实命中；一串要亲自经过的+1门；同路多列目标；独立的清敌、距离和大敌将进度。装备升级来自路上的奖励，不能只靠击杀计数。

## 文件
- 01_IMPLEMENTATION.md：真实行为与迁移合同。
- 02_EVIDENCE.md：九类机制与原视频时间对照，逐项标明未知。
- 03_DELIVERY.md：实施顺序、验收与节约测试预算。
- 04_LEVELS_AND_TUNING.md：三关的体验和调参依据。
- config：可读取的39个跑道对象、20组敌人事件及规则初值。
- reference/rules.mjs、tests/reference.test.mjs：独立Node参考函数与15条合同检查，非引擎替代品。
- tools/validate.mjs：配置完整性检查。
- references：用户的原始拆解与精选研究帧，禁止纳入运行资产。
- PACK_VALIDATION.json：本包自检结果，不能当游戏测试结果。

## 数值性质
原版触控、每点门值所需伤害、奖励领取、队形碰撞、失败细则没有完整底层证据。所有未获证据的公式和数值均集中列为本作初值，以便实际校准，不宣称破解原游戏代码或完全还原数值。

## 资源边界
未重复打包原252MB录像；包含研究图，不含第三方可复用游戏素材、字体或音频。Cocos接入继续使用本项目自制三国资产和兼容的TypeScript语法；reference模块只在Node里作合同示例，不直接复制Node专用API到微信运行端。

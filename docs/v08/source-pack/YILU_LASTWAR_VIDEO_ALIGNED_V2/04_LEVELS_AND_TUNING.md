# 三关编排与调参边界

`config/levels.json`是本作试制数据，非原录像逐帧重建。`sourceAnchors`仅定位借鉴的机制；`at`与`spawnAt`均为本作世界距离/战斗秒，绝不伪装成视频中的时刻。

采用首关1人、第二关1人、第三关3人的小队起步，用途中兵员奖励建立增长；这是参考小队起步的初值，明确替代旧8/12/16在新profile中的起兵，不改旧存档/老模式配置。

## 关1：动态门和火力选择
目标：学会蓝门可打高、红门可打正，桶有耐久与不同奖励，站位决定火力。
开局约6个世界单位处：左-2、右+2，两门都可打。正常站位向右可逐步把正门打高，再经过。
随后兵员箱与敌群重叠进入视野；拿到基础兵力再打武器箱，火力变化帮助打开后一排高耐久箱。
中后段有-12、-40等不同负门，不要求每扇都打正。左右目标不同时有明显最优位置，允许早放弃来不及打破的奖励。
第一关按清敌完成，不新增强制近战竞技场。最后一名强兵可以承载原第一关守将的故事身份。
建议自然目标36—55秒，不设置超时失败。

## 关2：连续+1与多列目标
起步迅速获得几名同袍。中部出现敌群侧、奖励侧，以及中央可见分隔。下方随时可调整站位。
特殊补给目标释放连续+1门。玩家停留在这一侧能够扩军，但暂时不能用这些弹药清另一侧逼近的怪；何时转火是关键。
中后段多列摆放高耐久兵员箱、武器箱、负门；数量大不表示现在来得及拿到。
建议自然目标44—70秒。继承第一关武器外观与永久解锁，但本关战斗火力仍从standard起步。

## 关3：先准备，再应对大型敌将
同一路中提前扩军、拿连发，再争取爆裂奖励。末段出现大型敌将，距离条与其HP同时可读。
高耐久奖励与巨大负数门在近处交错。不能因为已经有很多兵就忽视负门；危险值和可见接触边界必须一致。
不要照搬录像末段x8为队伍乘法；本作不加该标签，避免误解。
首轮以到达目的地且击败大型敌将结束；来不及击破可继续交锋，不用硬倒计时判输。
建议自然目标56—85秒，具体依实测调整。

## 调参只围绕四条可见因果
1. 初始几名队员能在目标接近前打掉低耐久箱，普通路径至少有可见可行解。
2. 装备奖励后，同样的高耐久箱明显更易打破；不需要后台给桶偷偷降HP。
3. 贪一个高耐久目标时，敌群或负门确实造成可解释风险；不能完全无脑站中间打穿所有目标。
4. 大队形仍可避让正确校准后的负门；不能大到无论站哪都必死。

固定调整：箱耐久、门damagePerPoint、显示提前量、个体射速/伤害、怪HP/间隔、兵员数量、队形间距与宽度。每次改一个主要原因，不按实时表现暗改任何值。

全队弹是多列命中，不能只用一个理想总DPS式子宣称关卡平衡。初值需要当前引擎跑一次真实轨迹；命中选择、错过和失败都记录。

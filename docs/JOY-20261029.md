# 连续正反馈优化 · 2026-10-29

目标：以真实击杀、实际成长、明确永久收益和下一关目标，改善每一关的反馈密度。保留现有20关、画风、兵器表现、敌将交锋和收藏存档；不增加登录奖励、体力、付费、失败扣收藏或离线倒计时。

1. 战意：击杀积1、击败副将积4、成长箱积2；满12触发6秒「破阵」，全军伤害+18%、攻击速度+12%。没有击杀时累积战意不丢失。敌将有效命中最多每秒积1，避免独战时没有积累。
2. 连破：4秒内真实击杀连计，超时只结束显示，本局最高记录保留，不扣任何奖励。HUD显示战意与连破；破阵与收势重击显示真实事件。暂停冻结战斗时钟，结算后不能继续充能。
3. 满级箱仍有收益：优先转成未满的攻击/攻速/护盾；全部满级时补盾、积战意。破阵期间的成长箱延长0.75秒，最多保留8秒剩余时间。
4. 结算展示击破、最高连破、成长次数和破阵次数；直接显示当前兵器永久等级、军功升级成本。升级由玩家主动点击，沿用已有存档事务。
5. 每关下一目标直接展示真实首通奖励，已获得的奖励说明如何使用；保留整备、返回营地和暂停。

验收：同策略20关模型前后比较、真实击杀去重/收益实际生效/暂停冻结/重开清零/满级箱/永久升级保存与下一关奖励验证；运行渲染确认没有遮挡和资源异常。模型不代表玩家胜率，浏览器不代表手机触感与帧率。

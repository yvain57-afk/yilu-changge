# 关内成长与前期击杀体验 · 2026-10-22

依据用户对 iPhone 0.12.10 第3关的实玩反馈：普通兵难以击杀，军械/宝物无法形成局内成长，人物与装备收益难以理解。此文是对统一玩法规则中相关条款的定向修订；保留视觉基线、20关身份、历史奖励、原存档、敌将交锋与增兵门。

## 玩法变化

- 每关先给成长机会，再逐段增加波量。第3关不再同时跨过一箭击杀门槛、提高数量并提前加入远程兵。敌人的压力由固定章节/路段决定，不跟随玩家装备暗中上涨。
- 威力宝箱设置在第6个行军秒对应的位置，之后最长8个行军秒有一次成长机会。箱子可提前看见并击破，所以实际获得通常早于路线到达时间。墙段箱子在可走的一侧。
- 破军：全军伤害每份增加12个百分点；疾风：攻速每份增加6个百分点；铁壁：增加每10秒恢复的护盾容量。战斗顶部常驻显示本局加成和当前护盾。
- 兵器匣击破即刻换装或升阶。两次升级匣始终升级当前兵器，不把试用兵器换回旧兵器；换装保留阶位。满Ⅲ阶继续增加本局威力。
- 宝匣击破即刻激活额外被动。不同宝物各增加8个百分点威力，同类特效不重复叠加；重复宝物改为威力强化。槽位已有装备时仍获得额外被动，原槽技能保留。
- 雷链：每3次主将出招，命中后连锁最多3名近敌。烈焰：每3次出招的命中产生一次近敌溅射。扇刃：每3次出招增加两道有实际命中范围的侧刃。护盾：抵消真实战损，按战斗时钟每10秒恢复，暂停时不计时，伏兵门不吃护盾。
- 武将匣开出本局援将，立即加入自动攻击。保留原本编入的两名随军与支援，额外援将最多一名；重复援将转为威力强化。援将不会与本关敌将同时作为同一人出场。
- 第1/3关提供赵云与青釭剑的本局组合，第2关提供孙尚香与古锭刀；试用内容不提前永久解锁。
- 本主武器与其随军/支援同场时，主将伤害额外+25%；原有武将专招和盟约效果继续保留。整备、人物、兵器、宝物详情明确展示收益和搭配。
- 新强化、援将与尚未永久取得的试用物品只在当前一局生效，永久人物/装备仍依照首通奖励解锁。失败不会污染已有收藏或配装；中途获得传国玉玺也会立即得到原有增兵效果。

## 上限与实现边界

威力等级8、疾风4、铁壁4；不同宝物累积后的全军威力倍率上限2.4，攻速上限1.24，护盾容量上限5。阶位、永久等级、主将共鸣独立保留。链雷/烈焰不递归触发，目标数和特效绘制量有上限，不使用战斗随机数驱动装饰动画。

`RunGrowth.ts`保存纯局内状态；`battle.ts`执行伤害、拾取、护盾和援将；`GrowthPresentation.ts`只根据真实事件绘制；`data.ts`和`CombatTuning.ts`定义所有20关路线。`FullMenu.ts`复用共享说明。新增模块使用`Array.from(new Set(...))`以兼容当前Creator编译，真实WebGL检查必须验证effects为有效字符串并发生实际被动伤害。

## 验证与边界

模型前后对照在`.cache/iphone-quick/run-growth-20261022/early-baseline.json 与 early-final.json`，所用输入策略与证据说明在同目录`early-combat-findings.md`。真实新档、前2关合法结算、未花军功、未配装：第3关普通三档走位击杀由176/264提升为148/148，宝箱8/12提升为19/19，首次火箭56.53秒提前至18.85秒；最终候选仍因敌将攻击损失18兵（中间候选为37）。

一直不升级、不整备可自然连续通过16关，在第17关首次失败；这用于刻画默认玩法边界，不代表所有玩家胜率。合法整备与真实预警的20关回归另行执行。模型和WebGL不能替代iPhone触感、声音、发热、帧率及人类试玩。

旧90–180秒区间属于此前的总时长目标，新成长使击杀加快。保留原时长检查并如实报告偏差，不通过加血拖延或放宽断言把检查变绿。原行军时长、Boss HP和全部首通奖励未为此修改。其它旧测试契约更新说明见`RUN-GROWTH-20261022-TEST-NOTES.md`。

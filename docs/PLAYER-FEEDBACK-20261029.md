# 一将成军 0.12.14：玩家反馈修复

## 逐条处理

1. 拖动不流畅、像断触：反向拖动立即以主将当前位置为基准，不再等待旧目标追完；墙内限制同步约束目标，避免积压横移。阴影保留绘制几何，图集矩形按纹理和区域复用，避险计算复用同一候选位置的阵型。没有减少兵数、删除特效或降低图集分辨率。真机FPS和触控体验仍待实测。
2. 二选一宝箱落在栅栏中：原避让逻辑排除了带choiceId的箱子。现在两只箱子及对应守卫一起调整到栅栏外，保留二选一的位置、奖励差异和互斥领取规则；普通箱子也按实体范围避让。
3. 入口穿栅栏：原逻辑在主将进入墙段之后才横向夹持，能出现穿入再侧向挪出的观感。现在正面木栅阻挡前进，需滑到空路才能继续；墙段内夹持位置与目标，离开墙尾才恢复跨路。
4. 随从与专属兵器没有联系：已获得的专属兵器自动配给本主随军，不再要求主将手持该兵器。随军获得50%出招伤害加成、永久兵器等级收益、共鸣脚环、专属色招式与装备提示；主将拿同兵器时原25%共鸣保留。固定角色动作与身份保持，未实现任意随从任意换武器。
5. 打完不能装备、像白打：沿途实际拾取的兵器和宝物，胜利后永久入库；失败不授予新装备，原收藏不变。奖励页增加装备动作，兵器详情的选择按钮前移，宝物替换保留确认。临时援将仍为本局助阵，永久武将继续按关卡解锁。

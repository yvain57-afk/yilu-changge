# UI-01 视觉与尺寸

方向：轻量三国军阵。现有暖色手绘世界保持明亮；UI用墨青的薄旗签承托，朱红只突出主行动/危险，旧金只表示身份、兵器与成长。取消满屏米黄双金线，暖纸只留给暂停/结果等内容小面板。

## 交互与动态

按钮可见框与热区一致，至少44×44。主按钮56高。按下色深、内容下移1逻辑单位；热区不跟着动。禁用态降低对比且不响应。不要给整个透明 HUD 加点击拦截。

状态条不可点击。觉醒只显示自动生效与自然结束；随军待命保留名字、取消强调；无队友直接收起。真实事件的出现条件、优先级、停留时间不由本轮设计重写。

## 可编辑结构

- `source/design.js`：布局生成器、色值、图标路径，所有文字仍是文字。
- `source/*.svg`：40份分层静态源；FullBleedWorld / SafeUIRoot / PlatformOcclusion 可分开编辑。世界是原引擎底图，UI是矢量与文本。
- `index.html`：单文件离线演示，图片已内嵌，无CDN、无字体下载。选择器和六秒演示属于交付工具，不是游戏新增按钮。
- `COMPONENTS.svg`：组件共用页，另有 PNG。
- `runtime-ui/`：小型可选九宫格与首页透明渐变，文字不烘焙。

静态 SVG 在不同编辑器中的字体替代可能改变文字宽度，导入后应看字体与 bbox；不可声称已经创建 Figma 文件。

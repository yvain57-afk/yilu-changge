# UI-01 接入说明｜一路长歌：三国

这是可编辑高保真设计交付，基线为 `7ee7685 / v0.5.1-rc1`。本轮没有修改游戏源文件，没有构建或上传新的微信版本；下述位置是接入建议，不是已经完成的补丁。

先打开 `index.html`，再对照 `exports/H01-home-platform.png`、`B01-run-platform.png`、`B02-boss-platform.png`、`B03-awaken-platform.png`。SVG、尺寸记录与组件文件均可直接编辑。保留角色、三关、战斗与存档，不再重选方向。

## 1. 接入文件与最小改动

|现有文件|仅允许的 UI 接入|保持不变|
|---|---|---|
|`assets/scripts/Game.ts`|首页层级、HUD、按钮、暂停/结果/整备/过渡的共用外观；节点与 hits 由同一布局矩形生成|页面分支、回调、解锁条件、保存顺序|
|`assets/scripts/Platform.ts`|增加只读窗口/安全区/胶囊指标采集，并监听有效变化|音效、震动、存档与平台权限|
|`assets/scripts/BattleView.ts`|对象标签与血条的屏幕层排布；Boss 血条改由 HUD 表示|角色、队伍、武器、世界投影、危险区域和攻击判定|
|新增 `ui/UiLayout.ts`（建议）|归一坐标、矩形与有限避让|不引入另一套游戏状态|
|新增 `ui/UiTheme.ts`（建议）|本包色值、字号、切角与可选九宫格|不增完整字体包或大背景|

**不要修改** `core/model.ts`、`core/weapons.ts`、`Volley.ts`、`WorldScenery.ts`、存档键、伤害、门值、奖励、解锁、关卡时长或 BattleNotice 优先级/寿命。不要把 SafeArea 套在世界根节点上。BGM 保持关闭。

## 2. 三层根节点

1. **FullBleedWorld**：保留现有全屏背景和战斗根。所有本包战斗底图均由原引擎在各自视口重新提取；没有把 390 图压进短屏，也没有为 UI 移动或缩小队伍。
2. **SafeUIRoot**：首页字标/任务/按钮、战斗 HUD、通知、暂停与选择界面。仅此层参与平台避让。
3. **PlatformOcclusion**：本包中是黑色灵动岛、微信胶囊和底部手势条的合成校验层。游戏中不要重复绘制假的系统元素；真实平台拥有这些内容。

首页允许独立陈列原人物：设计稿使用原长枪主将、背向构图、310 设计单位展示高（原首页为 180），没有生成新人像。此设置不能传播到战斗，战斗角色仍用原来的尺寸与坐标。

## 3. 安全区与热区同源

所有指标先归一为**窗口左上角原点的逻辑坐标**。先记录实际窗口原点、窗口尺寸、Canvas 显示矩形、引擎可见尺寸、设备安全矩形 S 和胶囊矩形 M；每个值注明坐标来源。DPR 只在明确转换物理像素时使用一次。

平台读取前先核对本地微信小游戏 SDK 能力。`wx.getWindowInfo`、`wx.getMenuButtonBoundingClientRect` 仅作为候选接口；先判断是否存在并验证返回矩形合法，不能由这份设计稿断言所有环境支持。Cocos 的设备安全区与微信胶囊不能视为同一件事，也不要将两套 padding 重复相加。无法取得有效胶囊时保留明确的 fallback 状态和诊断记录，真机核验前不宣布通过。

```text
L = S.left + 16
R = S.right - 16
T = max(S.top, M.valid ? M.bottom : S.top) + 8
B = S.bottom - 16
```

不要相加 `statusBarHeight + S.top + M.bottom`。它们可能是同原点的绝对坐标。

本包五组 fixture 的左右 safe inset 为 0，设计源中的相应横向坐标是这些夹具的结果。生产布局必须使用实际 L/R，不能把 `16`、`390` 或截图 `941` 硬编码成设备事实。设备/窗口指标变化时重新排布，不在每帧轮询平台接口。

若 Canvas 覆盖整个窗口、根居中、FIXED_WIDTH 的可见设计宽为 D，转换校验式为：

```text
k = D / windowWidth
xDesign = (xWindow - windowWidth / 2) * k
yDesign = (windowHeight / 2 - yWindow) * k
```

有容器偏移或不同 viewport 时，必须改用真实 Canvas 与节点坐标转换；拿四角点核对一次。`UiLayout` 输出矩形 → 同时生成 Label/图形位置和 `hits`，不能只挪可见按钮。命中测试仍在现有输入通道执行，不给非交互 HUD 增加吞拖动事件的全屏节点。

## 5. 战斗 HUD 数据与排布

普通稿严格使用用户指定的 **第二关 / 兵力24 / 枪Ⅰ / 邢道荣随军 / 行路10%**。战场底图是当前源码的合成定格，不是对用户截图的像素涂改。该定格山石的实际 `loss=8`，所以标签显示 −8；用户原图的 −6 未被拿来覆盖当前模型。所有标签必须读所属对象的真实 loss，不写死设计数字。

- **兵力旗签**：102×48，左缘单条旧金识别线；30 字号数字、12 字号“兵力”，固定右边界，覆盖 1 / 24 / 48 / 256。
- **阶段区**：宽度占剩余可用空间，高44。行路标题 + 百分比 + 2px 进度线；Boss 时在同一区换成姓名、真实 HP 数字和 3px 血条。不要再叠一条通栏 Boss 板。
- **暂停**：44×44，24 图形，始终位于胶囊下方。
- **第二行**：T+54，高24；长枪Ⅰ/长刀Ⅲ、自动觉醒、队友姓名。没有队友收起；同名 Boss 呈“邢道荣 · 待命”。选用军旗图标而非微小头像，以免小屏再出现不可辨识的人脸。
- **短屏普通行路**：采用两侧排布，阶段信息移到左侧兵力下方，武器/队友在右侧，给远处障碍保留中间通道。这是 UI 重排，不是相机或敌人位移。短屏 Boss/觉醒沿用紧凑两行，保护近战区。
- **通知**：普通行路放 B−64，32高，教程仍按原逻辑出现在 B−11 的基线；Boss/觉醒通知放 B−32，32高，避免压到短屏队尾。禁止新建“仅首次教程”存档逻辑。

`specs/layouts.json` 是五种视口逐屏的数值结果；`source/design.js` 是可编辑排版源。后者是设计参考，不要整段搬进游戏，也不要把静态底图搬进战场。

## 6. 世界标签

层级为“实际损失 / 血条 → 精锐身份 → 装饰”。精锐缩成金色小菱形 + 精锐，血条与名字合并成 58×22 标识；碰撞损失独立承托，山石118×28、敌兵82×26。标签之间至少6逻辑单位；视口边缘保留16。图形可以薄，数字不能缩到12以下。

接入时先收集可见对象投影的显示锚点，再在有限候选位置排布：默认上方、左上、右上，必要时侧移并加1px引线。排布只更新 Label/血条节点，不更新对象 x/z、碰撞宽度或实际生命。HUD、近战区、角色身体为禁入区域；短屏远处目标可使用不超过约88逻辑单位的引线，邻帧保留已选锚点以免跳动。超出排布能力时，先收掉装饰身份，仅保留损失和血条，不能隐去真实损失。

本包世界标签是固定场景样本，不是已经验证的通用运行时求解器；Codex 必须补最小的密集对象样例检查。不要将设计夹具写死为某个 obstacle id 的固定屏幕位置。

## 7. 动态状态

详见 `specs/dynamic-states.json`。最重要的是：

- 觉醒读原 `awakeningRemaining`，六秒自动结束；细环/暖金条没有交互热区，也没有“点击释放”。演示页可播放六秒 HUD 示意，场景仍为定格，不是实录。
- 增兵/损失读真实反馈事件；显示值不重新计算伤害。升阶短提示使用原通知优先级。危险 > 成长 > 聚兵，维持现有寿命和事件时序。
- 数字可作小幅视觉强调，但不移动计数列；动画不能改变热区。暂停时跟随原暂停状态冻结时间。
- 队友待命为中性灰绿，保持姓名，不能呈亮金出战。再胜不重复显示新解锁。

## 8. 资源与实现预算

- 既有角色/场景复用。`assets/world-*.png` 是设计沟通底图，**不进运行包**。
- `runtime-ui/ui-chrome.png` 是可选256×64色块图集，3块80×56，透明切角5；九宫格 inset：左右12、上下8。中段拉伸，四角不拉伸；文字用 Label 单独绘制。
- `runtime-ui/home-shade.png` 是可选8×256透明度渐变，只用于首页全屏承托；不用于战斗遮住世界。
- 所有图标可由简短矢量路径转为 Cocos Graphics。也可完全用 Graphics 绘制按钮而不引入九宫格纹理。
- 标题优先系统宋体类 fallback（设计机 Songti SC），正文与数字用系统清楚的黑体；不打包系统字体、不引入完整中文字库。跨平台标题宽度须重测，必要时只对少量标题字另做授权可用字标，不能以假字体许可蒙混。
- 实际新增可选 PNG 字节见 `specs/prototype-checks.json`，目标 <128 KiB。高清导出图、SVG样张、用户参考图、演示 HTML 都留 docs，不进微信资源包。

## 9. 最小接入验证

1. 核对游戏源码基线；采集实际窗口与胶囊参数，确认一次坐标转换。
2. 跑五个合成布局夹具：原尺寸字形 bbox、44热区、平台膨胀8后的禁入区、底部手势区、关键世界区域。
3. 检查新存档、有进度、三种待过渡、完成驻防、保存失败、无队友、待命、1/256兵、Ⅲ阶、六秒觉醒与长损失提示。
4. 一次短 UI 巡检：主按钮/重玩/设置/整备/暂停继续/返回，校验点击点等于可见位置，非交互 HUD 下拖动仍可移动。
5. 一段短战斗 HUD 录像 + 含真实系统遮挡的手机截图。按实际修改跑相应快速检查，不默认旧十局或再录完整三关。

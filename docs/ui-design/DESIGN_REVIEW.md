# UI-01：一页交付说明

**已完成首页、普通战斗、Boss战、觉醒状态，以及短屏与用户截图比例校验。** 采用墨青薄旗签、暖白文字、旧金成长标记、朱红主行动；保留现有人物和手绘世界。

两张用户原图已经实际查看：首页原先大块米黄双金线面板挤压角色，任务、身份与按钮层次相近；战斗原先标题与顶部系统区域相交，胶囊压住 HUD，世界标签叠在一起。新首页把任务收束到主按钮附近，以原主将为中心；战斗取消通栏大板，将兵力、行程/Boss与暂停放在第一行，武器、随军和自动觉醒放在紧凑第二行。世界标签有独立损失数字、精锐身份与血条层级。

所有主画面同时提供干净稿与平台遮挡稿。顶部关键 UI 放在安全区和胶囊较低边界之后，底部控件高于手势区。360×640 普通战斗采用两侧排布，Boss/觉醒用紧凑两行；没有通过缩小或移动战斗队伍让位。首页只重组展示比例，使用原有主将素材。名字采用军旗加全名，避免微小头像难辨。

交付包括可离线打开的交互 HTML、40份可编辑 SVG、PNG、组件页、精确布局数据、动态状态、热区与 Codex 接入说明。整备、重玩、设置、暂停、结果及关间过渡均映射到原有行为。没有新增货币、技能按钮或音乐。

验证结果：60组设计布局/状态检查无失败，离线页面无错误和外网请求；六秒自动觉醒示意、设置与暂停交互通过。可选运行 PNG 合计2,231字节。高分辨率场景和设计导出留在文档中，不增加游戏纹理包。

**待实现项：** 本轮没有改 Cocos 游戏页面。下一步按 `CODEX_UI_HANDOFF.md` 接入真实安全区和统一命中矩形，并验证动态世界标签。五个视口的系统参数都是合成条件，不能据此宣布手机刘海遮挡已修复；最终以当前微信预览和用户手机截图为准。

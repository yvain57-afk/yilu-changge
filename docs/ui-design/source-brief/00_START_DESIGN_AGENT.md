## 本轮目标

做出有三国武将气质、适合现有卡通手绘人物、手机上清楚而精致的UI。
采用一个主方向：**轻量三国军阵**。军旗、令牌、少量青铜/金属细节用作识别；深墨青/暗蓝提供承托，暖纸色用于少量文字承托，朱红与旧金只强调主行动、精锐或奖励。配色可调整，不把当前的大黄板加纹理当成重设计。
不要企业后台式卡片，不要满屏羊皮纸，不要手游充值首页，不要赛博、玻璃毛玻璃和夸张龙纹。

## 必须完成

1. 首页：现有主将作为视觉中心，标题有独立字标层级，一个清楚的“出征/继续征程”主按钮；当前章节和身份合并收束。保留既有整备、重玩关卡、设置入口，但降低视觉重量。不可增加账号、货币、体力、商城、红点任务。
2. 战斗HUD：去掉通栏大板；优先呈现真实兵力、行程或Boss血条、暂停。武器阶级、随军队友与自动觉醒整合为紧凑状态，不添加主动技能按钮。保持场地、主将和近战区域可见。
3. 世界标签：山石碰撞损失、敌兵血条、精锐标记做统一层级与避让；不隐藏实际损失，不移动碰撞对象。增兵/升阶/觉醒反馈要清楚，但不得改变触发规则。
4. 手机安全：刘海/灵动岛、安全区、右上微信胶囊、底部手势区都要避让。提供含平台层的设计稿与干净稿。设计稿不能删掉胶囊来假装修复。运行参数由Codex采集，别把截图物理像素当成逻辑像素。

先交一套完整方向，不重新出四套A/B；内部自行比较打磨，不逐个图标停下来要求用户批准。

## 输出

- 390逻辑宽的首页、行路HUD、Boss HUD、觉醒状态高保真画面；保持实际游戏内容和人物。
- 360×640短屏的首页与最拥挤战斗状态；再给当前941×2048截图比例的避让验证。
- 一页共用组件：主次按钮、武器/队友状态、精锐/血条/损失标签、暂停、结果、整备选择卡、关间整军面板。
- 结构可编辑的设计源，及尺寸/锚点/颜色/字体/交互/状态规范；必要切片标九宫格拉伸和透明区。
- 可用工具支持时给无需安装依赖、无外网请求的单文件HTML布局演示，并附PNG。HTML只用于设计沟通，最终运行仍是Cocos。
- `CODEX_UI_HANDOFF.md`：逐屏映射现有行为、动态安全区规则、资源清单、实现位置、最少验证。

交付的图必须包含关键数字、长队友名、同名Boss待命、觉醒和长损失提示等真实状态；不只交概念海报/文字建议。

## 不改的东西

不重选主角，不改三关、Boss兵器、近战/冲击波/齐射、门值、真实人数、碰撞、进度、奖励、存档、失败重开和整军—建营—驻防逻辑；BGM保持关闭。
画面上不新增“架空演绎/非史实/技术草模”等破坏沉浸的标签。调试说明留在交付报告。
敌人和队伍的截图如果作为底图，必须保持原尺度和位置，不能靠挪走它们制造空余UI空间。

设计稿不需要跑十局游戏。只做相关布局/状态/遮挡检查；没有实际运行就标为设计稿。当前包体已接近此前预览额度，优先小切片和系统字体，不默认塞大背景和完整中文字库。

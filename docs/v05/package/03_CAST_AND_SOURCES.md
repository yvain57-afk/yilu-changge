# 角色—兵器—地域依据（仅开发用）

这份表记录原著提供的对应。新招式、主角战役、武器波、三关归降和伙伴加入是本作设计，不能把它们标成原著情节。玩家界面不需要出现本文件或“架空演绎”等文字。

## 本轮实际使用

S52：《三国演义》第52回“诸葛亮智辞鲁肃 赵子龙计取桂阳”
https://zh.wikisource.org/wiki/三國演義/第052回
2026-09-22读取。邢道荣在零陵叙事中出战，兵器明确为开山大斧；陈应是桂阳一带人物，有撚叉迎战和回身掷飞叉的描写。它支持“邢道荣—零陵—大斧”“陈应—桂阳—飞叉”。不能把陈应直接当成无名弓手；未据此核实“梨花开山斧”等更具体名号，当前不用。

S53：《三国演义》第53回“关云长义释黄汉升 孙仲谋大战张文远”
https://zh.wikisource.org/wiki/三國演義/第053回
2026-09-22读取。杨龄在长沙战事中挺枪出马；黄忠在同回既有提刀交战也有开弓射箭。支持“杨龄—长沙—长枪”及“黄忠—长沙—刀/弓”。不把其他现代三国游戏给黄忠武器起的专有名直接归为原著。

S41：《三国演义》第41回“刘玄德携民渡江 赵子龙单骑救主”
https://zh.wikisource.org/wiki/三國演義/第041回
2026-09-22读取。赵云长坂一线用枪，并取得、使用青釭剑；支持枪与青釭剑在赵云形象里的联系。本轮赵云助阵用长枪，不强行写“龙胆亮银枪”是原著定名。白石会面/邀请助阵为本作承接已有v0.4的新情节。

## 后续人物约束，暂不生产新关

S01：《三国演义》第1回
https://zh.wikisource.org/wiki/三國演義/第001回
刘备双股剑、关羽青龙偃月刀、张飞丈八矛/蛇矛有明确文字。武器归属优先锁定，不把关羽名刀随意赋给其他人物。

S05：《三国演义》第5回
https://zh.wikisource.org/wiki/三國演義/第005回
吕布持画戟、骑赤兔，在虎牢出战；本回有“方天戟”的表达。吕布在游戏中可有弓箭招式，但主视觉与标志招式以戟为主。虎牢适合作为代表性相遇地点。

S42：《三国演义》第42回
https://zh.wikisource.org/wiki/三國演義/第042回
张飞在长坂桥持蛇矛；可形成桥头枪矛型关卡，不能把其攻击统一写成弩箭。

S74：《三国演义》第74回
https://zh.wikisource.org/wiki/三國演義/第074回
关羽与樊城战线、青龙刀相关；庞德则明确钢刀。地理/人物/武器关联可用于后续配置，不在本轮插入两个新增Boss。

## 使用方式

程序CastRegistry保持sourceRef、weaponId、regionTags、relationKind、encounterStory各自独立。加载检查能发现“吕布选了弩将默认皮肤”“赵云枪招式却显示长矛投掷标签”等错误。原著没有明确命名的武器，用通用名称，具体造型可以原创；依据缺口写入开发记录。

当前三关的迁营和白石事件保持短行军过渡；取胜不等于灭掉一郡，也不等于历史人物永远归属主角。赵云标为同行助阵。邢道荣/陈应在本作的归降是新故事走向，不能拿原著结局当作既有游戏剧情；不需要向玩家解释这一内部区别。

所有插画、动画、特效需原创或合法授权。原著人物名称/情节资料与现代游戏、影视剧、模型生成图的具体造型不是同一项资产，不直接复制商业角色外观、配音或音乐。

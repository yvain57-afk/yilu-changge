## 4. 值得优先解决的问题

### 优先一：让长刀近战、接触画面和碰撞距离一致

这是可从源码确认的实现缺口：`weapons.ts` 长刀近战距离 0.85；`model.ts` 第二关 Boss 接近后停在 0.9，陈应没有杨龄那种进步缩距。因此主将长刀在该 Boss 战中主要依赖刀气，缺少真正可达的刀刃接触。

本次第二关全局记录只有 1 次近战命中，目标是行进段敌兵 6；另有 36 次武器波命中，后者包含队友，不能当成主将独占输出。不要只提高长刀伤害掩盖问题。请规划统一武器锋缘、敌人体积、接近距离和接触判定的方案；保留同一攻击不重复扣血的规则。下一轮需有“长刀真实命中 Boss 的接触段”针对性证据。

### 优先二：补动作的完整性，不重选人物方向

当前主将长刀仍复用持枪上身帧，通过旋转和刀尖路径形成挥砍；并非独立完整的长刀动作组。队友背面主要共用一张准备姿态，身体摆动加兵器运动，步态与收招细节仍弱。Boss 使用数张姿态加模型移动，手部锚点含按身体比例估算的部分。

建议重点检查起手—命中—停顿—收招、持械手是否稳定、主将和队友侧后位置是否互相遮挡。新增图必须进入真实小屏战斗，不以立绘验收替代。Boss 在当前画面上明显大于主将，比例是否合适仍需要用户反馈，不能由 Codex 宣布审美通过。

### 优先三：让玩家看得出武器与队友的差异

长枪和长刀已经有不同轮廓、射程、宽度，但攻击周期相同。三位队友的基础单目标 DPS 按同阶主将约 20% 估算，通过不同节奏区分；这不是自然整局实测伤害占比。当前统计以命中次数为主，未完整分解主将/弓兵/队友的实际伤害。

建议先明确枪的纵向刺穿、刀的近身横扫、斧的慢重、叉的投掷、赵云快枪各自可感知的区别，保持相近总预算。必要时补最少量的按来源伤害统计，再决定数值；不要凭命中次数就调平衡，不加稀有度、装备或新技能树。

### 优先四：成长反馈与首次游玩理解

升级、觉醒有实际规则和 HUD 文字、轻量特效；是否能让第一次玩的用户立刻理解“为什么升阶、觉醒什么时候触发、六秒结束后发生了什么”，尚无盲玩证据。

优先考虑小屏可见的兵器变化、一次简短提示及战后明确的新增解锁反馈，避免长说明遮住战斗。第三关首精锐保留原位置 12/66=18.2%，略早于候选窗口；不要为凑比例擅自挪怪，先看实际体验。

### 优先五：建立微信手机实玩证据

用户是个人产品开发者，希望之后继续用现有小游戏测试号方便手机试玩。基于最新 v0.5 源码制作测试预览、核对原测试身份及包体后，让用户手机试玩；不要重新注册或切回旧游客身份。登录若需要扫码，由用户在官方窗口完成。

重点验证：首次启动、上下安全区、拖动与误触、实际帧率、三关存档、后台恢复和现场音效。预览回执、模拟器通过、手机实际通过必须分开。当前没有 v0.5 手机二维码可沿用。

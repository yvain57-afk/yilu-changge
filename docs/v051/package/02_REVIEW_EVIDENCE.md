## 4. 本轮额外执行的隔离规则检查

将包内model.ts、weapons.ts原样用TypeScript编译为独立JS，执行真实Journey。因为levels.ts导入了未随包附带的campaignData，直接编译完整levels失败；随后只读取文件本身的LEVELS数值JSON和v05尾部覆盖，省去缺失的旧叙事叠加。Boss名称、武器、攻击序列按提供的v05覆盖执行。没有伪造缺失campaignData后宣称整包构建通过。

夹具条件：每种组合12秒，初始化到Boss阶段，固定x=0，2人，Boss HP=1000000、敌方损失=0，移除行进段对象以隔离接触。这些改值仅属于测试夹具，目的是避免过早结束，不代表实际关卡、难度或通关结果。被测攻击/伤害代码未修改。

## 6. 视觉观察、设计建议与未知项分开

在主录像的正常战斗帧中，队友靠近第一排且轮廓重叠，长刀波在浅色路面上很薄；成长和伙伴信息主要挤在顶部细长状态行。可通过独立动作、适度侧前出手和精简状态层级改善，不能由截图推断武器DPS低。

Boss体型、队伍密度、武器风格与整体观感需要用户手机集中判断。没有新玩家盲玩资料，不能断言升级或觉醒已经容易理解。

本轮不替换角色、不增新兵器、不追加音乐；先修动作与接触，再做当前版本测试预览。

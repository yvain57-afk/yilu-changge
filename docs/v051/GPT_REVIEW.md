# 一路长歌 v0.5.1：接触、动作与手机预览

交付基于当前本地 v0.5 累积工作区；原有修改备份在 `.cache/v051-baseline`，没有回退到远端旧 S1。开发包原文与散列见 `package/`。本文件用于下一轮 GPT 规划，不进入游戏 UI。

## 本轮落实

- 主将长枪/长刀与近战队友使用同一套动作、手柄锚点和投影几何做表现与接触判定。近战先检查距离，再检查挥动中固定长度兵器是否穿过目标身体；命中点来自实际接触位置。没有把武器拉长到 Boss，也没有把波命中写成近战。
- 三位 Boss 的常规收招窗口前移到约 0.75，保留撤回；斧队友最多前迈 0.4，赵云 0.25。前迈只改变攻击者姿态和兵器位置，不移动队伍过门/受伤中心。保留枪 1.1、刀 0.85 的近战上限和原伤害/周期。
- 长刀三种衣装各有四张独立上身姿态；邢道荣、陈应、赵云各有四张背面动作。实测每张图的握柄位置并与固定兵器衔接。陈应飞叉出手后有空手收势；原有主将与弓兵步态继续保留。
- 近战和武器波仍共用一次攻击的命中账本与 1/1/2 目标预算。波改在五个 active tick 的中点发出，让真实接触有机会先发生；总攻击周期与冻结伤害不变。并新增实际伤害分账：主将近战/波、弓兵、每名队友近战/波，按实际扣血统计，不含溢出伤害。
- 360/390 小屏显示紧凑的枪/刀与三阶状态；升阶光带从实际精锐击杀处汇入武器，三阶武器亮边、觉醒闪光与六秒环形计时。危险提示优先于成长、成长优先于聚兵；结算只展示这次真正新增的解锁。
- 沿用三关、整军/建营/驻防、身份、保存、重玩与结尾，没有扩展系统；BGM 仍关闭，只有原有五路音效。

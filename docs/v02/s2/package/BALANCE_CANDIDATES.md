# 第二关拖时：隔离试验候选

本文件不授权覆盖默认关卡，也不声明下面的候选已经在模型或引擎中跑通。

## 已记录问题

trial-02的late策略，仓库日志记录损失[10,8,48]、最终16人、总220.42秒、Boss166.42秒。当前每0.25秒射出一支逻辑箭，伤害0.2×发射人数，固定人数N的理想持续命中DPS为0.8N。

1800/(0.8×16)=140.625秒。这是不计飞行等待、躲避与后续损失的伤害时间参考，足以解释低兵力长战斗，不能当作新实测。

## 先改早期惩罚，避免随手削弱末门破坏选择

不要简单把最后木障损失从48砍到32。在原设计常见112人状态下，未清障仍可得到(112-32)×2=160人，高于安全门112+32=144人，削弱了这处“清障换高收益”的风险区别。

优先在隔离配置比较：

|组|第17秒木障损失|第45秒木障损失|BossHP|意图|
|---|---:|---:|---:|---|
|基线|10|48|1800|保留现状作对照|
|候选A|6|48|1800|降低前段损失经两次倍增放大的影响|
|候选B|6|44|1800|再轻减末段惩罚，但保留预期人数下安全门价值|
|候选C|6|44|1500|仅当B仍拖时，再试有限降HP；检查高兵路线是否太短|

在原late路径选择和其他伤害均不变的假设下，第一排后28人，原过程为：
((28-10)×2-8)×2=56；(56-48)×2=16。
候选A对应：((28-6)×2-8)×2=72；(72-48)×2=48。
候选B对应：72→(72-44)×2=56。

这些是条件算术，策略会随兵力改变，必须重新跑源模型，不能把48/56写成已验证结果。

选择关系检查：第17秒在28人时，未清候选木障所得(28-6)×2=44，低于安全门28+20=48。第45秒在112人时，未清候选B木障所得(112-44)×2=136，低于安全门112+32=144；清障仍可得224。不同人数和上限256下还需分别检查，不承诺所有状态都是同一侧最优。

## 重跑要求

在隔离测试目录深拷贝配置，不改默认LEVELS。保持同一控制器和日志口径，每组都跑best/safe/late及真实失败策略，至少记录入Boss人数、逐次损失的对象ID与时刻、门前/门后人数、Boss时长、总时长。

再用独立Boss测试夹具检查1/8/16/32/48/56/88/112/172人的可玩时长；夹具结果单独标记，不当作关卡自然路线或真实玩家通过率。

判读：正常/安全策略不能因改善尾部而变得没有挑战；晚换路应明显改善，并仍然比提前准备吃亏。初期可把晚换路Boss约30—60秒作为比较区间，属于调参观察目标，不能变成硬超时。1人仍应保持规则允许继续，没有“低兵自动失败”。

不使用按入场人数动态缩血、隐藏保底人数、临时伤害加成或强制输赢。最终候选需真机/浏览器亲玩后决定，不在S2美术任务里顺带定稿。

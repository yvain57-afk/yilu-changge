# 首版亲验说明（待用户执行）

本页保留任务书的体验验收，不以自动控制或截图替代。浏览器入口为 http://127.0.0.1:43187；若服务已停止，在唯一工程目录运行 `npm run serve`。

1. 首页点「展开书卷」，选择「渡口送简」。开场最多两句，可直接点「跳过对白 · 出发」。在空白区域按住并左右拖动；自动前进与射箭，无需连点。先体验十秒，判断是否已理解操作。
2. 队伍中心决定左右门；第一排8兵选+12得到20，选×2得到16。木栅可对准射毁，山石需绕开，落墨条纹出现后横移躲避。人数归零才失败，没有强制失败倒计时。
3. 守关自动停步，保持对准墨影射箭，预告落墨时横移。可暂停、免费重开。通关立即解锁下页，翻页明确跨时代，阅读线索与否不影响继续。
4. 中途离开页面，回来应保持暂停，点「继续行路」才恢复。半程拾得线索，即使失败也保留；线索册返回应回到原处。
5. 体验反馈集中在：横移是否跟手、损兵原因是否清楚、增兵是否有满足感、是否愿意重玩，以及原创简化画面是否符合你期待的国风绘本气质。

已验收的自动规则与平台流程见 VERIFICATION.md。人工体验尚未被勾选为通过。音乐和音效已有原创资产及开关；音量、舒适度以及微信震动仍需亲验。

微信真机还需要专用小游戏AppID、相应开发权限和目标手机。届时用本工程重新构建，再分别记录开发者工具与真机结果；桌面Apple M5帧率不能替代手机性能。

# 攻防可玩性增量规格

## 核心体验

维持单指左右横移、自动攻击、数值门和路上拾取。玩家横移同时影响火力方向、躲避路径和选路收益。己方继续保留认可的兵器光波，敌方通过快慢混编和真实远程造成压力。

追求“看懂威胁→选目标/换位置→解决眼前危机→拿到成长→更复杂的下一波”。不要靠看不见的扣兵、隐藏锁血或提高所有敌人的血量做难度。

## 1. 场景实体与四个阶段

每个路线事件有不可重复消费的waveId。未进入战场的事件保持排队；实体生命周期为reserved/approach→combat→dead/retreat→removed。显示预算不能充当死亡规则。

远处生成后，在首次进入可读区域时才开始攻击准备。可读必须综合投影高度、HUD遮挡、雾化和实体alpha，不能只判断z<某值。建议弓手身体至少达到12逻辑像素高或其队伍有明确可见标记，再开始首次抬弓；此为待验证的视觉下限，不能靠放大所有敌人达成。

每阶段记录数量：计划、生成、可见、启动预警、实际发射、实际命中、提前击杀、被延迟、合法退出。主要成功条件是正常场景真的存在这些行为。

## 2. 七类敌军

| 兵种 | 进攻方式 | 玩家应对 | 实现约束 |
|---|---|---|---|
| 轻步兵 | 多列推进，部分分路；进入近战区出刀 | 横移聚焦清掉接近的一列，或让出冲线 | 多、快、薄；保留真实预备与回收；挥空不伤人，攻击后不会无条件自杀 |
| 近卫 | 更稳定的近身重击，短暂蓄力 | 集火、穿透，预备结束前换位 | 只在近身有效reach里命中，不能从18距离隔空扣兵 |
| 盾兵 | 正面减伤掩护弓手，接近后盾击露出窗口 | 钩镰/枪戟破盾，利用回收窗口 | 维持现有enemyArmor语义，不全程无敌，不强制唯一装备 |
| 弓手 | 中远程点射或小组齐射，锁定玩家当时位置 | 看抬弓/射线后移动，优先点杀/从侧路清后排 | 发射点跟随敌人，箭飞行可见，锁定后不追踪，不从屏外直接命中 |
| 骑兵 | 明示冲锋线，短蓄势后快速突入 | 横移避开冲线或提前击杀 | 真实世界轨迹，冲锋不瞬移；预警与撞击位置一致 |
| 旗手 | 维持现有附近敌军增益 | 选择优先目标切断强化 | 光环范围/加成不无限叠；死后撤掉未发生的增益，已射出箭按发射时状态结算 |
| 机关 | 固定地带短延迟攻击，与其他兵种错峰 | 读地面标记走安全带 | 单独范围和时序，不能与墙/已锁定箭同时封死所有路 |

不再用一个“elite”布尔值同时决定皮肤、HP、移动和清理。具体行为以enemyKind为权威；elite只保留明确用途，避免light皮肤/guard血量/archer清理混用。

## 3. 接敌与射击首轮参数

combat_tuning.design.json包含20关首轮波次范围。所有数字均是待校准设计，非已测结果。

轻兵本体行进速度从现有2.2提升到前期2.8–3.4、后期4.6–5.2世界单位/秒；实际接近速度还包括S.speed，不能再乘一次关卡倍率。目标为进入清楚可见的威胁区后约3–5秒接近队伍，特定冲锋更快但有预警。

数量靠分波持续增加。后期一波约22–30名，屏内活跃敌军目标不超过56–64，按设备性能下调装饰，不生成上百个不可见攻击者。注意一波人数和同时活跃人数是不同指标。延后预算应改变波次间隔，不直接消失或无限堆在Boss结尾。

第一平衡候选维持现有普通HP倍率和基础伤害，先看修复后的敌人有多大实际威胁，再逐项校准。HP和伤害不作为同时翻倍的默认项。

弓手首个射击周期采用可见后0.25–0.45秒准备＋关卡预警下限，随后释放真实箭。第一次攻击无需先等完整冷却的一半。后续冷却按3.8秒起点校准。射程起点建议28–36世界距离，必须在画面可读范围内；若窗口不足，调整进场位置/盾兵保护/首箭准备，不给射手不可打断的无敌期。

已释放箭使用sourceEnemyId、attackId、subAttackId、origin、lockedTarget、releaseAt、impactAt及trajectory。足迹、箭与队列碰撞共用坐标；弹体跨一帧很远时扫掠判定。武器镜头缩放不能改变命中位置。

## 4. 己方攻击保持特色

主将：枪矛重点穿线，偃月刀/刀弧重点扫群，戟兼顾穿刺与侧弧，弓弩重点远程点杀。先保留当前DPS和阶段增益，不靠削弱全部己方武器弥补敌人生命周期bug。

随军：吕布维持画戟双路穿刺的既有能力，但身体不巨化；马超/赵云等沿各自实际发射点发出攻击。弓手随军应有张弓/放箭，持戟者用戟动作，禁止相互借用人形帧。

部曲：保持弓/火箭/连弩升级。原生弓矢目标提前量使用敌人实际速度与当前世界速度，不再固定所有敌兵2.2；修近战接敌后也需允许合理的近处目标参与选取，不能让进入9以内的敌人被弓手永久忽略。保留弹体实体命中及原burst次数，避免新增射击次数假升级。

瞄准倾向保持简单：主将按玩家横向位置；随军保留各自已定义优先目标；部曲优先当面危险、再选中远目标。不得自动瞬移主将或全场追踪，让横移仍有作用。

## 5. 防守与失误成本

使用现有兵力池、回血/救兵、盾刀和宝物能力。正常战损需要肉眼关联到箭/刀/冲撞；每次日志能追到攻击者和攻击编号。多个同批攻击可聚合数字，不能把同一刀每帧重复结算。

少量普通命中表现为士兵闪烁/倒下和兵力下降；大额命中给一次受击提示与简短镜头反馈。无伤害不播放hurt。主将身体不能每次发刀就倒向后方；败退动作只属于真实失败状态。

总减伤、护心镜、七星灯和医生救回仍按原规则。伤害归因必须先按实际受防护后的数值写账。不得为了“必须有损耗”额外扣兵；高水平玩家完成无伤应合法。

## 6. 预警与公平性

继承EncounterDirector并扩大到实际命中窗口：从可见预警产生到最后弹体命中结束；射手死后已射出的箭仍占据危害预算。

检查玩家当前位、最大横移速度、可见队列的真实脚点/身体碰撞区域、0.30秒反应预算、当前与即将到来的墙段、全部已承诺危险。预警之后保持方向锁定，不能挪动安全缝惩罚正确闪避。

前2关最多1个显著威胁；3–16关通常1–2个；17–20关最多3个但仍要可达。不能把“所有杂兵的接近”都变成大预警框；只给近身抬刀提示，高威胁才占明显地面带。

门箱文字不能压住危险：门值优先，箱名在可读距离内展开，重叠时挪牌并用短引线指向箱体。必要时错开路线生成时序，数值/奖励不改。中近处主将身体始终可追踪。

## 7. 二十关递进

每两关保留原里程碑。奇数关建立威胁读法，偶数关做组合考核；已经学过的远程与接敌不在后续模板里全部消失。

1广宗：较密轻兵和单线预警。2虎牢：两侧轻兵分波，奖励前留喘息。
3下邳：出现可读点射弓手。4宛城：少量盾兵保护弓手，优先目标开始重要。
5官渡：旗手增益和可破盾阵。6曲阿：左右步兵/弓手错峰。
7赤壁：火区和箭矢分开到达。8长坂：途中名将交锋，杂兵只在非致命窗口施压。
9荆州：有预警骑兵冲线。10隆中：上篇已学威胁综合，仍保留成套奖励。
11神亭：快步兵与短戟双段时序。12濡须：岸路冲锋配远程点射。
13街亭：旗手+盾兵+弓手的优先级。14樊城：重甲近卫必须真实靠近，盾阵露口。
15阳平：中远弓手为主要威胁，扇形箭与单线点射交替。16定军山：密集步兵压近与远程错峰，重刃Boss考验收势追击。
17雒城：机关与步兵错峰，路线可达。18剑阁：机关/盾阵/箭矢轮替，控制同时威胁数。
19天水：已知军令组合顺序可读，不突然换规则。20洛阳：沿用原三阶段，破阵/交锋/决胜，每阶段组合不同，避免全靠堆血拖长。

Boss计划给每个既有bossId显式配置。建议复用：侧翼夹击、锁定横扫、两段交替、直线突刺、扇形箭阵、地面区域、近卫支援等有限基元。血量先保留。没有绑定专属行为的Boss不能静默fallback，验收中报错；正式恢复路径也不得变成零伤害敌将。

## 8. 第16关具体编排（原行军82秒，保留门/箱/奖励节点）

0–8秒：12–16轻兵进入视线，保证第一波有足够读图时间。
8–18秒：18–22混编，约3名弓手错峰抬弓，玩家开始换位；盾兵不超过2。
18–27秒：靠近既有墙段，降低同时高威胁到1；让轻兵形成接敌压力，不用箭雨封死剩余半路。
27–39秒：围绕既有宝匣/粮车，20–24名混编分两路，少量护卫与弓手。挑战路清怪成本可见，奖励维持原值。
39–55秒：22–26名推进，2组小弓手错峰，主将需要在清近兵与避射线间取舍。
55–68秒：近卫/旗手带队推进，仍保持轻兵为主；击倒旗手能明显取消后续强化。
68–74秒：一次短组合考核，以现有己方二/三阶输出可解决；新的大攻击需在最后整军门之前结束。
74–82秒：不再注入新的强制大范围威胁，保留既有连续门/军械转换与整军可读空间。
Boss：保留魏延/两阶段/350HP的第一候选，第一阶段重刃横斩，第二阶段加入方向锁定直线重击；近卫仅在Boss回收期间分批进场。不能用Boss正在高危横扫时再补一条无解射线。

这些是排程目标，实际route以世界距离映射到行军时间，遭遇停步与游戏时钟分别记，不把测试墙钟等同剧情时间。

## 9. 校准与判断

采用合法章节配装（只能用此前已解锁物品）、对应永久等级1–3两档，同时保留用户c16偃月刀Lv.3这一例。不要按该用户装备动态匹配敌军；两档仅用于离线测试。

策略：站定；只追正收益但不读预警；读取实际可见预警并有300ms反应延迟的正常躲避/选路。三个策略用同种子同配装。

中后期目标：站定应经常失败、正常操作明显更好，熟悉打法的强配装仍有成长优势。可用参考区间为11–20关站定胜率不高于25%、正常操作70–90%；这是自动测试目标而非真人统计，样本不足不报概率已证实。若站定也低于早期基线但正常操作仍难，先查可达/命中/读图问题，再调数量。

保留无伤可能；不设置强制损耗下限。记录gross_loss、实际救回、获得援兵、进Boss兵力、败退来源，避免只看结尾高兵力误判无压力。

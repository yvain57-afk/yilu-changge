# 动作与持械制作规范

## 1. 工作顺序与范围

优先：步战偃月刀正确ready及完整出刀周期；随军吕布与马超阶段尺度/朝向；随后全16主将兵器、全可上阵随军、20Boss的语义与比例矩阵；76键继承清单继续按原键关闭。

这次新增工作不能算成“只剩76键”。76键主要覆盖骑乘和过渡，用户这次的步战偃月刀握杆、随军Boss帧混用是另一个范围。先枚举现有键、失败键和新增依赖，唯一键计数，不以图片文件数冒充完成。

## 2. 标尺和源图

同一actor及视角建立一个model sheet：身份、盔甲、发型、披风、武器形制、肩宽、骨盆、膝/脚底、武器握点。画布保留统一原点，切图保存untrimmed尺寸、trimOffset、pivot，不用每帧alpha外框高度充当人物身高。

每帧标注：actorId/role(camera-facing ally/enemy/menu)/semanticPose/sourceSha、canonicalScale、feetAnchor、pelvisAnchor、bodyHeight（不含武器）、两手与遮挡层、weaponRoot/weaponTip/grips。

屏幕体积只允许由同一角色设计标尺和proj(worldDepth)决定。身体前倾/蹲下会改变外接框，不要求所有帧外框等高；需对骨段/肩宽等稳定尺度核验。建议5%以内的非透视尺度漂移为警告阈值，最终用真实播放看是否跳变，不凭一个阈值替代人眼。

## 3. 偃月刀重新绘制

最终只能有一把偃月刀，刃根—直杆—杆尾是一条刚性连续轴。杆可以在身体或披风后被遮住，但遮挡前后延长线必须一致。

展示姿势：主将站稳，双脚重心明确，一手持主握点、一手扶同一根杆；也可单手稳持、另一手自然放松，但不能握住悬空多余短棒。优先固定符合现有角色身份的后3/4视角，兵器整体可辨认。

制作顺序：
1. 从认可蓝披风主将和偃月刀本体提取干净参照，保留身份和色彩；截图圈线只作问题说明，不作为纹理。
2. 先制作一张正确ready/inspect，验证两手和长杆。再以同一身体/兵器标尺做run0–3、wind、rel、rec、show。
3. wind重心轻转、刀身蓄势；rel是沿明确弧线出刀；rec把刀带回准备位，躯干保持战斗控制；不跪倒、不低头瘫软、不反向倒退。
4. hurt仅短暂保护或受力偏移；defeat只在真实失败场景使用。不能将hurt/defeat作为常规rec补帧。
5. 若用独立兵器，身体去掉全部旧杆/旧刀像素；每帧武器仅刚性平移/旋转，比例固定。双握点用已校准源图，不为适配漂移手点把刀伸缩。
6. 对所有必要帧检查手指遮挡、刀杆共线、透明边缘，再打包实际运行。展示和战斗分别用合法pose，但外形一致。

候选建议独立命名namespace r3_hero_guandao_*，实际键在导入清单确定。不得直接把g_run_guandao0全局覆盖而不核对其其他引用。

## 4. 随军不变身

随军采用后方或后3/4追随视角，禁止wind一瞬间变成面向玩家的Boss立绘。吕布身体不因共鸣或出招放大，只有光波可以按既有技能增强。

使用role-scoped映射 ally.lubu.run/wind/rel/rec/hit 与 boss.lubu.*。图鉴全身图保持展示资源，不能拿去做一个混在连贯动画中的攻击帧。

来源有合格旧帧则校准复用；视角、解剖或语义不匹配必须补绘。不能简单把大Boss图缩到相同外框后就说修好。其他角色也禁止借赵云或吕布fallback。

## 5. 76键制作方法

原76键在 INHERITED_ASSET_WORKLIST.json 中原样保存。
- 6个赤兔/的卢连弩wind/rel/rec：先固定同一连弩刚性道具、握点跨度与马匹身份，再对身体/前后手局部编辑。后手遮挡前的构图须有可审查证据；完整成品可以自然遮挡。
- 40个其余骑乘键：跑姿马腿左右支撑交替，wind/rel/rec身体与武器动作明确，不能复制同一静态马腿虚报循环完成；不同坐骑不换色冒充。
- 30个passing过渡：12人物及3主将持械类型各2帧，插在两相支撑之间，四相顺序连续；不用纯透明交叉淡入制造双腿/双身体。

生成/绘制办法：固定源角色图、镜头、画布和道具；每次只改目标肢体/动作区，先完成一组角色的循环再铺开。连续两次相同握点/身份错误，停止重复整图生成，改分层躯干/手臂/兵器/马腿的定向绘制与合成；不转用未经授权的外部付费API。

资产QA需同时有原图、锚点检查图、透明底帧、实际图集映射、引擎里的完整循环。检查图是素材证据，实际战斗视频才是运行证据。

## 6. 动画状态与命中

语义标签严格分开：ready、run、wind、release、recover、hurt、defeated、victory。普通出刀仅可用ready/run/wind/release/recover。获得时的show不持续阻塞危险输入，不复用跪伏hurt。

视觉状态读取逻辑事件：attackId、release tick、actualDamageReceived、battleOutcome。视觉hurt短暂覆盖不能让attackId递增或重新出弹；不能为同步动画改逻辑攻击次数/伤害。

敌方近战挥空也应完整收刀；角色可以退让，但没有实际伤害不能显示受击闪红。Boss真实血尽后才能力竭/收服。

逐帧验收：至少连续20次出手，含无敌人空挥、命中、真实受击、减伤、过门、升阶、换兵器、骑乘与左右边缘。输出actorId/pose/frameKey和逻辑事件时间条，严禁用自动阶段截图当完整循环通过。

# v0.3 三关试玩候选

## 直接开始

Mac 上双击项目根目录的 `启动一路长歌.command`。启动器会定位所在项目、检查 Node.js 和预构建包，只在 `127.0.0.1` 启动服务，再打开浏览器。已有本项目服务会复用；其他程序占用端口会明确报错，不会杀进程。也可在项目根目录运行 `npm run serve`，打开 http://127.0.0.1:43187/play/ 。

从预构建包试玩需要 Node.js 18 或更新版本，不需要安装 Cocos。源码重新构建需要 Cocos Creator 3.8.8 和 `npm ci`，然后 `npm run build:web`。编辑器可执行文件路径见 `tools/build.mjs`，另一台电脑需按安装位置调整。项目可放在另一处本地普通目录，启动器不写死作者的个人路径。

端口另有用途时可用 `PORT=43190 npm run serve`。启动器也支持 `PORT=43190 node tools/launch.mjs`。127.0.0.1 是本机地址，不是对外部署或手机访问地址。

## 一次完整试玩

1. 新存档：首页“开始闯关”，山道 8 人出征。左右拖动，自动射箭。击败投矛头目后晋升头领。
2. 直接点击“下一关：拿下营寨”，以 12 人重新整队。弩兵的蓄力可打断，已射出的箭仍需躲避；击败弩将晋升统领。
3. 点击“下一关：夺下首城”，以 16 人出征。击败弓将后开城门、换旗，显示“首城已得”“起步篇完成”，当前身份城主。
4. “重玩关卡”可回选三关。重玩使用当前最高身份外观，人数仍按关卡重置，没有身份攻击加成；重复胜利显示“再次取胜”。

暂停可继续、免费重开或返回选关。归零失败后直接重开当前关。关闭页面、刷新后，首页“继续闯关”前往首个未完成且已解锁的关卡；三关通关后为“再次挑战”。已有 S2-B 首关进度自然衔接第二关，沿用原存档键。

本次只完成起步篇三关。第三关没有登基、皇帝结局或第四关按钮。美术与操作感受等待你的集中试玩反馈。

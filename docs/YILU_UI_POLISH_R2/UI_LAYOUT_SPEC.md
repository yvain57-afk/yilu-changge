# 页面布局与立体层次执行规格

适用：现有UI-FINAL增量改造。尺寸为本轮设计约束，均须用实际Cocos像素验证；本文件不是运行结果。

## 1. 统一度量

逻辑像素使用平台已有窗口度量；禁止按交付JPEG的540×960当游戏逻辑尺寸。
四边先去安全区，随后再布局。统一外侧间距12–16，组间8–12，文字与实际金边/卷角至少留8，普通正文优先14–16，必要辅助说明不小于12。
主标题22–26，单主动作高52–56，可操作完整热区≥48。极小可见残片不扩热区抢占固定栏。
正文行高由实际字体与换行函数统一返回；数字、长标题与混排需测量，不用字符数一刀切。
白色正文与浅金标题置于稳定深色底，避免把下一关文字直接压在亮山河上。

UIComponents已有content输出，使用步骤：
外框 → 九宫格content → 语义padding/卷角避让 → 内容矩形。
文字包围盒、人物实际alpha外接框、兵器端点与按钮均对内容矩形核验；热区在屏内不等于内容在框内。

## 2. 材质层次

L0：环境与柔和压暗。
L1：轻量说明与分隔线，避免厚金框。
L2：人物、物品、编组卡，保留细边和少量阴影。
L3：单个主按钮或主奖励，高光、厚底、纹理完整。
L4：需要确认的弹窗和资源独立错误层。

同屏最多一个强金色主按钮；常规说明区不再逐行重复大金框。
高亮表示选中/新获得/主要动作，不表示所有物品都稀有。
角色、物品、文字不预烘焙进整屏图片。

## 3. 紧凑整备预算（主规格）

以可用高度usableH=H-safeTop-safeBottom计算；四页签固定在配装摘要后。
初始预算：
- 关卡标题/威胁：64
- 间距：8
- 紧凑配装摘要：112
- 间距：8
- 页签：48
- 间距：8
- 底栏（含提示与主动作）：72
- 剩余全部给予唯一可滚动列表。

在360×640，隔离边界safeTop44/safeBottom34时，可用562，列表预算242。
两张完整条目各80、间隔8，仅168；仍有空间提示后续内容。长文可自增高，不能隐形。
这是一项空间预算，不以强迫所有信息塞入112高卡替代实际排版。

摘要分区：
左侧小型合法主将持械预览；右侧兵器名、永久等级及本局阶位。
下方两随军/支援使用可读姓名胶囊，三宝物槽用紧凑图标和可达详情。
如果现有素材端点无法在合法比例下容纳，将完整编组放到“编组详情”，摘要只保留真实装备信息。
兵法快捷条可在摘要下折叠展开到同一列表，展开重算高度并保持滚动锚点。

条目：
图标/人物48–56；姓名、简短用途、永久等级分区。
选中条置前或默认定位可见，避免玩家拿连弩而列表停在长枪产生理解障碍。
详情按钮独立放置；长名换行时条目增高。
从详情返回不跳回列表首项；更换页签记住各自位置。

## 4. 地图

顶部高度根据真实三行文本测量，不写死“提示中心恰好在底边”。
返回/定位两侧预留各48–56宽；中间标题不能侵占点击区。
底部抽屉标题、威胁、奖励各占一行。面板内容高度+语义padding决定外框高，底部主按钮单独排。
当前选择城点、最高进度、下一未领取里程碑分属不同字段，文案标清：
“当前选择·第11关 神亭”
“征程进度·13/20”
“下一里程碑·第14关”
不把三个上下文混成同一条无说明的“再胜一关”。

## 5. 图鉴与详情

图鉴卡保留两列；图片、姓名、关系徽章形成三个不重叠矩形。
关系徽章在卡内，优先图像左上角安全位置或姓名旁，禁止贴下边框。
底部分页固定；减小卡区与分页之间无用空白但不牺牲触控。
详情采用一个主图舞台+一个说明区。经历、能力、共鸣均保留，可滚动内容有渐隐/位置提示。
兵器详情首屏能知道“我有什么、升一级得到什么、需要多少军功、怎样选择出征”；升级/选择不混用。
未知人物不暴露名称，未拥有物品不显示可装备按钮。

## 6. 获得与结算

获得首屏空间建议（按可用高约562）：
页头54+间距8；可选有效标题横幅44+间距8；主奖舞台132；
奖励摘要24；两列奖励行至少两行，每行64、行距8；
提示/底栏72。合计约578，紧凑安全区时优先将横幅并入页头节约52，不缩小必要文字。

不要固定照抄上述总高：先测量，超过可用空间就收起重复横幅或轻量摘要，再用单一内容滚动。
主奖是同一奖励集合中的一项；“共N项”按唯一kind+id计算，军功单列不当作人物/物品数量。
长奖励名称保留全名，转两行或详情，不靠截掉关键字。
同一事务已入库时，成功状态轻量显示；错误状态重试阻断，保留原事务ID。

奖励动画建议：
0–0.2秒背景与有效标题；
0.2–0.65秒主奖显现/轻回弹；
0.65–1.3秒其他奖励依次呈现，数量多时聚合，不线性延长等待；
1.3秒后静态展示，按既有0.3秒门槛允许跳过。
里程碑增加一次军旗/印章动作和地图推进，降低动态时直接完成显示。
这些时序只改变表现，不触发第二次发奖。

结算主次：
大标题/真实胜利焦点 → 兵力及军功 → 实际新获得或重游信息 → 下一目标 → 整军。
普通保存成功不是大卡；放在战果旁小标识即可。
不得把未签名版本或Web状态写成“手机已升级”。

## 7. 验收截图状态

每个重点页固定至少：顶部、滚动半项、到底、从详情返回、长名/多项。
对照图同时记录：
pageId、dataFingerprint、selectedId、chapterContext、scrollOffset、animationTime、
logicalViewport、safeInsets、platform、buildId、codeFingerprint。
同构建legacy比较仅作受控布局比较；候选对历史已归档截图必须保留不同指纹。
PNG原始运行截图保留一份；JPEG可读预览不二次伪造状态。

# 一路长歌：三国 · 界面重构开发包

先读`00_START_HERE_CODEX.md`。主规格为`01_IMPLEMENTATION_SPEC.md`，附美术、工程、验收文档及机器可读清单。

本包是用户已经认可视觉方向之后的开发交接，不是另一轮纯图片提案，也不是已修改的游戏代码。全部数值和接口均是待在真实工程验证的初值/合同。

- `references/`：用户认可方向、用户选择局部图和辅助旧海报；`crops/`只作视觉对照。
- `sources/`：用户提供的v0.9入口及此前全局设计，保留原文，不能覆盖当前本地工程。
- `config/`：主题初值、页面状态、待制作资源、待执行验收。
- `contracts/`：建议只读视图接口，没有模型或引擎实现。
- `一路长歌_界面重构开发文档.docx`：便于阅读的分页版，与主规格同内容。

不要把参考图里的货币、星级、章节、角色阵容和封闭道路当成自动批准的新系统。第2章已明确图像到实际功能的映射。

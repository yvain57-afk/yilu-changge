# 本轮设计决策与优先级

D01 视觉目标采用用户确认的五屏总图以及四张用户截取的局部图。此前概念/开发海报中冲突的信息不会自动进入产品。

D02 当前主角身份、连续三关与当前左右滑玩法保持；图片里的角色名、章节编号、奖励数字不视为新数据需求。

D03 首页可以使用背身/侧背红披风主将与城寨全幅图，更新旧全局设计中对首页背身展示的限制。大地图、肖像卡、胜利舞台等视觉重排都是本轮范围。

D04 页面导航允许明确优化：整备增加/强化独立“开始出征”主动作时必须复用现有启动/继续解析，原卡片选择即保存与返回行为保留。若当前状态需要过渡，按钮文案和目的地一并改变。

D05 不新增经济、体力、星级、多副将、马匹、兵法、稀有度、活动/背包等系统。若本地经核对已有合法实现，先写真实差异再适配；不能凭概念图偷偷新增。

D06 战斗图中的“分路”仅转化为现有多列目标/真实障碍的空间表现。下方自由横移保持，不恢复已撤下的独立难易路线。滑动用于火力与风险选择，无新技能。

D07 参考箱体取材质和轮廓，运行时按兵员/武器/连门/战地同袍的真实类型标识。无宝箱稀有度侧栏。

D08 结算采用标题、氛围、边框、卡片和按钮层级；没有真实评分不显示星级，没有真实奖励不显示示意货币。三关完成后进入真实驻地。

D09 本包颜色、字号、逻辑尺寸、动作时长、素材尺寸、目录、接口和测试样本均为本轮实施提案，尚未运行验证。禁止称为原版精确参数或用户逐项审批值。

D10 资料优先级：用户后续明确文字 > 本包的映射决策/实施合同 > 用户选中的视觉构图与风格 > 旧需求保留的逻辑边界 > 助手先前海报中的辅助文案。遇到当前本地实现与旧文档差异，先核对当前合法修改，禁止回滚覆盖。

本轮来源已经原样或以原图放入sources/、references/，来源文件只用作阅读，不拷贝覆盖现有工程文档。最终运行页面不得出现本任务编号、源资料编号或测试标语。

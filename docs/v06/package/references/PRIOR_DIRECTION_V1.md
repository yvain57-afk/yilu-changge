# 《一路长歌：三国》兵海、双路与武器兵法规划 v1

状态：策划草案，尚未修改或验证当前游戏代码。
依据：用户2026-09-23最新澄清。本文中的密度、速度、升级门槛均为试制建议，不代表用户已批准的最终数值。

## 1. 本轮方向

一局始终是一段连续的带兵推进战：越来越多的小兵迎面进入战场，玩家左右移动、清敌、选择难易路线、获得成长，最后迎战本关Boss。

“割草”是这段战斗应有的基础体验：敌人够多、推进够紧凑、清敌够利落。关底Boss仍是同一局的终点，沿用玩家在途中形成的武器等级、兵法搭配、队友与兵力。

纠正此前理解：不把割草和Boss设计成两种游戏，不把草图中的500/80直接定为实际敌我数量，不自动确定五级装备或击杀100人升一级。

## 2. 确认项与本稿新增提案

用户已明确：
- 敌军数量和移动速度提高，要形成连续收割敌兵的体验。
- Boss攻击方式更丰富，攻击范围明显可读。
- 前进道路有左右两侧的选择，一侧略难，另一侧较易。
- 武器升级及武器、兵法搭配帮助玩家挑战更难的路线。

本稿建议：
- 每关先做三次分路；每段路线约8—12秒，之后重新汇合。
- 先做长枪/长刀与两种兵法，验证四种组合，不增加新装备经济。
- 武器沿用三阶结构，改用队伍击杀累积推动；100击杀不直接作为通用门槛。
- 首轮验证第一关，已有二、三关保留；体验成立后复用模块，不删除或覆盖既有内容。

## 3. 敌军与清敌体验

### 3.1 改的是来兵和清敌节奏

提高敌人的接近速度，先保持我军前进速度、触控响应与相机投影稳定。不能用全局加速掩盖敌人稀疏，也不能重新引入场景整批回跳。

普通兵应能被清楚、快速地击倒。用数量、队形和来兵间隔形成压力，避免给所有小兵堆高生命。

普通兵的多目标命中容量应随新密度重新设计；旧的单目标/少目标限制不能不加调整就套在兵海上。同一攻击对同一目标只结算一次，兵器接触和武器波共用账本的公平规则继续保留。

弓兵仍然有真实伤害和可见齐射。通过主将波形覆盖、敌人队形和来兵密度，让主将有自己的清场价值；不增加专门针对弓兵的隐形免疫。

### 3.2 首轮负载初值

以下仅是第一关新原型的起点：

|阶段|稳进路线每批来兵|强攻路线每批来兵|敌人接近速度|
|---|---:|---:|---|
|前段|8—10|12—16|新原型基础速度|
|中段|12—16|18—24|在基础上提高约10%|
|后段|16—20|24—30|在基础上提高约15%—20%|

同一时刻真实活跃敌人先设约48人的软目标、64人的硬保护上限；这些是首轮性能预算，不是已经达到的效果。来不及清理时停止后续出生，不能让人群无界累积或让隐形敌人造成伤害。出生限制引起的战斗差异要记录，不能用隐藏加速补齐队列。

数量是每批实际敌人，不是数字牌和装饰人群。整局累计可超过100人，不要求同时显示几百人。

同屏小兵多以后，碰撞损失需要相应减轻并检查峰值。不能沿用旧精锐级别的单体损失，造成密集小兵同帧碰撞后瞬间清空队伍。同一敌人只触发一次接触损失，已有Boss攻击结算继续独立。

### 3.3 先使用四种编排，不新增四套兵种系统

散兵群：脆、数量多，提供连续击杀。
纵列兵阵：让长枪贯穿更有价值。
横向密集阵：让长刀横扫更有价值。
少量快兵或现有远程兵：在中后段制造需要注意的威胁。

可以复用现有敌兵，只改变出兵队形和节奏。第一段不同时介绍大量新威胁。

## 4. 真正的左右路线

### 4.1 一段路线，而非只换两扇门的数字

每次分路按“提前看见 → 选择 → 本段迎敌 → 汇合”的过程展开。

提前约2秒让玩家看见两个入口和简短信息。穿过入口线后，由真实队伍中心一次性决定本段路线。选择本身不暂停战斗，不弹出菜单。

选中路线逐步展开到正常可战斗宽度，让玩家继续左右躲避；不把玩家锁进狭窄半屏。另一条路线退出本段，不能跨回去重复取得两侧收益。屏幕变化保持连续，不瞬移队伍或改碰撞位置。

分路确认前留出反应窗口，不在同一瞬间叠加敌人突袭。之后两路在共同地点汇合，面对同一个关底Boss。

### 4.2 稳进与强攻

稳进：来兵较稀、阵型较散、额外威胁少；获得稳定击杀成长与少量增兵。

强攻：敌军更多、部分队形更密，偶尔加入更快的敌人或一个已认识的远程威胁；有更多可获得的击杀成长，出口可给略多的增兵。

第一版不让强攻同时显著提高数量、速度、生命和伤害。优先用数量与队形，再少量提高接近速度。

强攻路线不设强制装备门槛。装备弱仍可试，但玩家能提前理解风险；稳进也能正常打Boss、解锁后续，不成为惩罚路线。

### 4.3 路牌信息

示例：
- 稳进 / 疏散步兵 / 援军 +8
- 强攻 / 密集枪阵 / 援军 +14

以上奖励数字仅作演示。进入前显示收益与主要威胁，出口按已展示条件兑现。不得突然改变奖励、重复发放或增加隐藏扣兵。

稳进与强攻的位置在不同岔口可以互换，但标识必须一直明确，不靠背“永远右边更好”。

原有+N与×2可以继续作为路线内部的增兵节点，不能取代整段路线。路口不同时堆分路说明、装备选择和数字门三层判断。

满阶后也要检查强攻回报是否仍有用。先使用原有增兵回报，不额外加货币或新的长期资源；如已经满兵且满阶，允许玩家选择更稳路线，不强迫每次强攻。

## 5. 武器和兵法构筑

### 5.1 出征前只选两样

一把武器、一种兵法。已有随军队友保留，但本轮不增加第二套队友养成，也不开放抽卡、稀有度、强化材料和新武器槽。

先测试两把武器：
- 长枪：较窄、较长的前向枪芒，适合贯穿纵列敌军。
- 长刀：较宽的月牙刀气与近身横扫，适合接近队伍的横向密集兵群。

真实近战与向前武器波都保留；不改回只有主角射箭，也不把所有武器波变成同宽长方形。

### 5.2 两种兵法（游戏设计名）

贯阵：增加主将一次攻击可穿过的普通敌兵数量。不得穿过不可穿越地形，不能对同一个Boss叠加多次伤害。

震军：主将有效命中普通兵时产生短暂击退/迟滞，提供清理近身兵群的时间。只由主将攻击触发，不让每名弓兵都触发控制；同一目标需要控制间隔，避免永久压制。Boss不受无限击退或眩晕。

组合效果：
- 长枪＋贯阵：纵列、密集推进路线更有优势。
- 长刀＋震军：近身、横向拥挤路线更容易控制。
- 长枪＋震军：前方窄通道保持距离。
- 长刀＋贯阵：增加连续清理数排普通兵的能力。

四种组合都可用，不做“错误搭配无法通关”。先比较覆盖与控场区别，不把所有效果写成简单的攻击力百分比。

### 5.3 击杀驱动武器升阶

建议本轮用整队真实击杀推动成长。主将、弓兵、队友击杀都记入同一累计；同一敌人只记一次，伤害次数、装饰敌人、逃离的敌人不计击杀。

候选初值：累计30次击杀升二阶，累计80次击杀升三阶。该门槛须与实际来兵量一起调整，不能直接机械套用手稿中的100。

这是替换旧版“两名精锐直接升阶”的新增提案，不应让两套升阶规则同时重复触发。保留三阶显示和六秒觉醒；不立即增加到五阶。

稳进路线的正常击杀应足以形成可用的二阶组合；适配武器、持续清敌的强攻路线能更早到三阶。未三阶、未觉醒仍可击败Boss。

二阶强调普通波形和输出改善；三阶让当前兵法的优势更明显。先复用已有觉醒作为本局爆发，不再加一个主动合体技按钮。

已解锁武器、队友与兵法保持局外记录；击杀累计、阶级、觉醒按每局重置，不能失败就删除永久解锁。

## 6. Boss多样化与范围可读

Boss是当前关卡的终点。进入Boss战时保留所选装备、兵法、兵力与局内等级，不切换成另外一套操作。

现有人物和兵器关系保持：邢道荣大斧，陈应飞叉，杨龄长枪。下面是本作的招式设计，并非新增原著事实。

|Boss|第一招|第二招|范围形态|
|---|---|---|---|
|邢道荣|转肩横扫|举斧下劈并释放短地裂波|扇形/薄弧；向前逐段传播的裂痕|
|陈应|单点锁定飞叉|有可见空隙的两叉分射|叉的实体轮廓；短方向标线/落点|
|杨龄|压枪直刺|带完整准备动作的突进枪芒|狭长尖头路径；枪尖及窄波|

先每人两招，最多同屏一个主要Boss危险，不同时堆叠三种大攻击。

每招有完整因果链：身体蓄势 → 地面或武器提示真实范围 → 武器/波实际移动 → 命中反馈 → 收招空隙。

候选准备窗口约0.9—1.3秒；具体数值由触控速度和安全路径验证决定，不随意缩短现有已可用窗口。锁定落点后不能在最后一刻继续追着玩家走。

攻击区用有方向的边缘、低透明填充与武器轨迹共同表达。正常游戏不出现大面积实心矩形红框；也不能为了好看删除可判断的范围提示。

横扫按扇形/弧形范围，枪刺按窄走廊，飞叉按实体移动区域计算，画面与碰撞读取同一参数。亮边和拖尾不得把安全区伪装成危险区，透明角落不能伤人。

每种攻击留有从玩家当前位置可达的安全路。Boss不靠增加血量拖长战斗，也不让强攻路线才获得的装备成为强制钥匙。

## 7. 三关应用节奏

第一关：三次左右选择，主要使用散兵、纵列、横向兵群，验证连续清敌与枪刀差异，最后邢道荣。

第二关：在同一模板里加入少量快兵和既有远程兵，强调升级后的组合更适合某类强攻路线，最后陈应。

第三关：组合前两关已认识的威胁，进一步提高后段来兵密度；不给每一批敌人都加一个新规则，最后杨龄。

三关整军、建营、驻防、结交队友和保存保留。章节、全武将库与更长故事本轮不扩。

## 8. 视觉与验证重点

普通敌兵不逐个显示名称、伤害数字和血条；保留精锐、特殊兵和Boss的关键信息。长枪刺穿一列、长刀扫开一片应在手机上看得懂。击败后短促退场，尸体与碎片及时回收，不遮住下一批来兵。

保留已认可的角色方向。UI设计agent继续处理首页、HUD、安全区和平台胶囊避让；本轮新路牌/击杀成长/兵法标记复用该组件体系，不另造一套通栏面板。

先通过改造第一关验证下列画面：
1. 一小段原速录像能看见连续来兵、武器清群和一次左右选择；不是只有两个敌人和一个增长数字。
2. 分路预告清楚，选中后还有足够走位空间，不可反复收取两侧收益。
3. 同一路口用长枪＋贯阵、长刀＋震军各做一个短片，能看出清理方式不同；不以固定脚本结果代表人类玩家偏好。
4. Boss的动作、攻击范围与实际命中一致；预告时间和安全路径不靠猜。
5. BGM保持关闭，原有游戏音效保留，密集命中时限流，不让几百次音效同时启动。

验证按变化运行：出兵/回收上限、分路一次结算、击杀去重、多目标一次账本、Boss范围、存档兼容。用一个短密度场景和一次代表性流程，不默认十局长测或反复自然三关。真实手机与浏览器结果分开记录。

本轮未读取新的仓库实现、未进行游戏试玩或构建；以上均是待用户讨论确认的设计方案，不是开发完成报告。

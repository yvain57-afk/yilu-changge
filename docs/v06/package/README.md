# 《一路长歌：三国》v0.6 Codex 开发包

**用途：在现有游戏上实施“真实兵海—左右分路—武器兵法—同局Boss”。本包是开发交接与配置，不是已经编译好的游戏。**

## 使用
把此文件夹放入已授权游戏工程的文档目录，将`00_START_WITH_CODEX.md`全文交给当前Codex会话。继续最新本地工作区，保留UI agent、战斗动作与存档成果；不要求先切换到远端历史提交。

## 内容
- `00_START_WITH_CODEX.md`：开工指令、连续交付顺序、权限与快速迭代边界。
- `01_SPEC.md`：三关九处分路、出兵、成长、兵法与奖励。
- `02_ENGINE_CONTRACTS.md`：动态敌人、移动碰撞、攻击账本、存档与现有模块接入。
- `03_BOSS_AND_VISUAL.md`：三位Boss各两招、共享范围几何、小屏及UI协作。
- `04_ACCEPTANCE.md`：最小模型、片段、三关及手机验证。
- `config/horde_v06.json`：18个左右路线变体、54份候选批次、波次时机、敌人和武器兵法初值。
- `config/boss_v06.json`：六个招式的准备、范围、运动和恢复初值。
- `contracts/reference.mjs` / `.test.mjs`：无引擎的独立参考合同和16个自检，不是替代项目模型的假测试。
- `tools/check_package.mjs`：本包配置关系校验。
- `evidence/`：上述自检结果；不含Cocos、微信或用户体验通过声明。
- `references/`：上一轮方向原文、实际核对的仓库范围。

## 数据优先级
本轮用户明确要求 > 当前包的实现合同 > config中的试制初值 > 更早版本的固定体验参数。
当前本地工程与用户成果始终保留；本包未授权删测试、购买、发布、推送、改账号或清存档。
数值不合理时可在本轮有限调参，保留原因与同场景对照，不再次发一份策划等待审批。

## 交付预期
同一批次先把第一关内部打磨到可玩，再复用到现有后二关。最终给可玩三关、两段搭配对照、一次完整录像与现有测试身份的当前预览（或具体阻塞）。不要只交草模、图标或文字报告。

## 本包自检
在本文件夹中运行：
```
node tools/check_package.mjs
node --test contracts/reference.test.mjs
```
无网络、无安装依赖。只验证包内配置与参考函数，不代表当前工程、最终伤害平衡或手机运行已通过。

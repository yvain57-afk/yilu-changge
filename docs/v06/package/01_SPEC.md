# v0.6 产品与关卡规格

## 1. 这一版的目标
整个关卡始终是同一场连续推进战。小兵数量和自身接近速度逐段提高；玩家左右移动，射箭/近战/武器波自动工作；三处分路让玩家结合兵力与搭配选择稳进或强攻；所有成长带入最终Boss。不得分成独立割草小游戏与另一个Boss小游戏。

本包把上一轮规划落实为可执行默认值。新数值与招式属于试制设计；本包自检只验证配置和独立合同，不证明Cocos手感、关卡胜率或手机帧率。

## 2. 保留与删减
保留3关、当前人物/武器身份、枪刀真实接触和向前波、弓兵各自弓口齐射、一个随军队友、三阶/六秒觉醒、兵力0失败/最高256/最多48可见含主将队友、免费重开、关间整军建营驻防、已解锁物品与战绩、连续场景、已有UI设计成果。
仅增加“真实敌群＋左右路段＋一个兵法位置＋Boss两招”。不加货币、背包格、强化材料、稀有度、五级装备、二技能栏、抽卡、自动变阵、经营、联网服务。音乐继续关闭。

## 4. 路线从选择到兑现
preview → committed → segment → merge。一路不中断，不打开选择弹窗。
- 入口前是左右两条可见道路，显示“稳进／强攻＋敌阵提示＋出口援军”。标签始终配形状/文字，不只用颜色。
- 队伍中心跨入口线一次判定；x<0为左、x>=0为右。提交后不能收回选择，不可拿另一侧敌群经验或出口奖励。
- 只生成所选路线的战斗内容；未选侧可以有远景轮廓，不能生成隐形敌人和伤害。
- 用约0.4秒让选中道路在画面上展开，另一侧退出；保持主将真实x、触控映射和地形碰撞不跳变，不瞬移主将。随后仍有全宽走位空间，不能困在半屏。
- 路内约2.8秒有一排普通数字门，和路线选择错开。它按现有队伍中心一次判门，固定+N/×2，不被射击改值。当前路线没有受阻门守卫；不要重复载入旧版木障门。
- 穿出口且仍有兵时，发已预告的固定援军：稳进+8/+10/+12；强攻+14/+18/+22。不是清光所有敌人才能领，不在未出生敌人上补击杀。0兵失败不得被援军复活。
- 奖励ID为runId+forkId；刷新/恢复/动画重播不可重复发。满兵时提示“满编”，不得伪造增加数。
- 出口仍活着的敌人继续运动到实际越过队伍，不瞬间消失、不算击杀。下处分路前需通过时序安排收干净残余，不能转场时后台删怪当完成。

稳进与强攻终点相同，通关与人物解锁完全相同。强攻不设武器门槛、不强制选，不根据玩家强弱暗调难度。满兵满阶后，选择稳进是合法策略。

## 5. 出兵与基本节奏
新模式替换旧稀疏敌兵与旧固定门表；本轮默认不再摆旧版固定山石/受阻门，但地形素材和遮挡合同保留供回归与后续复用。不要把两套事件叠着跑。

普通兵批量出现但真实有血量、位置、命中与击杀记录，不是一个血条带几十张装饰图。第一关每段稳进9/13/18人一批，强攻14/21/27人一批，每段3批；后二关小幅加密并混入快兵/弩兵，详见配置。数量均包含替换成的特殊兵。

初始普通兵HP按阶段3/4/5，主将基础攻击仍先用5、36tick周期及1/1.2/1.4阶级倍率。目标是一阶能明确打倒小兵，成长主要来自覆盖与控场；普通敌人没有独立浮动名字、常驻长血条和逐个扣兵文字。

敌人的世界速度独立于我军：enemy.worldZ -= speed*dt；玩家z仍按原速度推进。相对接近速度是两者之和，不能又把它乘进相机。三个阶段速度倍率1/1.10/1.20，二、三关再用1.08/1.15；快兵只少量混入。兵法击退/迟滞影响敌人，不影响场景。连接段按最近已选路段的阶段倍率，首岔口前按第一阶段。

弩兵距队伍约3.0开始蓄力，完整预告75tick后发射、18tick实际飞行；瞄准在开始时冻结，蓄力中击杀会中止，已经投出的箭不中途消失。同时最多两条远程预告，后来的弩兵等待而非缩短前摇；Boss开始之前全部解决。

硬上限64个活跃敌人（含特殊兵、不含Boss），软目标48。满载时推迟未出生敌人，队列最多32、最多等72tick、每tick补生最多6个。到期未出生记录为spawnSkipped，不给伤害/奖励/击杀，不瞬间补一大团。正常代表路线的推迟或取消应接近零；明显触发说明配表/清敌有问题，要调而非长期靠上限削怪。

普通碰撞每个敌人至多记一次；12tick内普通兵接触总扣兵最多2，队伍短促受压闪动并汇总损失。超过合并限额的越线兵记录为breached并退出，不算击杀。此规则只限制普通/快兵拥挤冲撞，精锐、弩箭和Boss依然独立。N=1实际吃到伤害仍然失败。

## 6. 枪刀与两种兵法
装备界面只增加一个兵法槽：“贯阵／震军”。两个从本版本开始即开放，默认贯阵；先不造解锁材料。长刀仍沿用首关通关解锁，旧存档已有长刀则直接可用。兵法在出征瞬间冻结，本局不能靠回到设置偷换。

普通目标预算：
|武器|I/II/III阶普通目标上限|特性|
|---|---|---|
|长枪|4/6/8|窄而长，按前后顺序贯穿纵列|
|长刀|5/7/10|较宽近身扇扫与前行月牙，能碰到同一排多兵|

精锐/特殊兵/可毁障碍仍用独立1/1/2预算；Boss始终一攻击一次。普通与特殊都写入同一hitTargetIds，近战与波共用，碰到山石或未破木障按遮挡终止，不允许穿山或对Boss多段灌伤。预算是最多命中数量，不是保证自动命中那么多；所有目标先过真实形状检查。

贯阵：在主将普通目标预算上再加2/3/4，不改同目标伤害，不影响Boss和地形。
震军：仅主将命中普通/快兵时，向敌人来向推回0.18世界单位，并按60%速度迟滞12/15/18tick；每名敌人54tick内最多生效一次，不能叠加时长。精锐、特殊兵和Boss免于这项位移控制，不加隐藏减伤。弓兵和队友不触发此兵法。

队友攻击保留独立动作及原单体预算，不新增养成。弓兵继续每0.25秒一次合并伤害、排除主将队友，视觉保持多弓口；本轮暂不重写逐兵寻敌/弹道。主将的群体覆盖负责让其在兵海中发挥价值，不对弓兵偷偷加免疫。

## 7. 击杀升阶
有效击杀来自整支队伍。只有真实敌兵hp从正变为0的一次死亡，计1；木障、石头、Boss、尸体、越线兵、未出生队列都不计。
累计30杀升II，80杀升III。一次波跨两个门槛按有序事件发出，画面可合并显示最新阶，不能丢事件。每一发攻击在开始时冻结阶级/兵法/伤害；同一波杀到升级线，剩余途中不升级旧波。
新模式不加载旧精锐实例；已有eliteIds可在旧版本夹具中保留作为精锐标记，但horde-v06下不再调用“精锐直接升阶”。精锐也只算1击杀。
III阶主将首次真实命中Boss触发一次六秒觉醒，复用现有表现/倍率；不增加人数、无敌、碰撞体和新按钮。不到III阶仍可正常胜利。局内状态每次重开重置，永久解锁与最佳成绩不退回。

## 8. 最小可见差异
正常画面必须看见敌群和不同队形；长枪一束穿过几人，长刀一弧扫倒数人，命中/退场不能只显示总数下降。尸体最多16、约0.3秒退场。
同一路口，“纵列兵阵”对枪＋贯阵有合理优势，“横向密集兵群”对刀＋震军有不同的解法；四种组合都能玩。不能靠一条隐藏的对号入座伤害加成制造差异。
HUD只加“兵法图标/名称”和“击破N／下一阶门槛”，沿用已有安全区/组件。普通兵不堆标签；精锐、远程、Boss仍保留危险和实际损失。BGM不加载，密集命中音效合并，原有声音开关有效。

## 9. 范围优先级
P0第一关真实兵海+双路+杀敌成长+两种兵法；P1同模板扩二三关并接两招Boss；P2小屏和最终微信预览。三者同批次推进，没有人为审批停点。美术普通细节自行修；新付费/权限/发布停在边界。
如果UI agent正在改Game.ts，先独立实现纯规则与数据，通过小适配接入，最后合并。不要等它完成整套UI才开始，也不要把它新界面覆盖为旧米色面板。

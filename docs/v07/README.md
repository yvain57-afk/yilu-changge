# v0.7 · 射击变门与军械补给

参考：用户提供的 [Last War 实机视频](https://www.youtube.com/watch?v=3hrg3sz_SrE)，重点转译左右移动、瞄准、门值与奖励的关系，沿用《一路长歌》的三国角色与美术。

## 本次变化

- 三关中的固定加兵/翻倍门改为可以射击变值的门。红色表示损兵，打到非负数变为蓝色；每座门有增长上限。
- 新增援军箱与军械箱：大数字为剩余耐久，顶端小字说明奖励。打破才给奖励，未打开的箱子不会凭空赠兵，也不是隐藏的致死墙。
- 军械箱提升本局弩阵等级与实际齐射伤害；原本已经发出的箭不会追溯变强。原有枪刀近战、武器波与击杀升阶继续共存。
- 连营箱打破后生成连续 +1 门，需要沿同一路线通过，奖励不会瞬间全给。
- 移除这三关分路出口的自动赠兵。路的区别仍由敌方阵形和压力体现，成长来自命中与路线选择。
- 队长脚下金色标记是过门位置。跟随队形不会触发玩家看不清的额外门碰撞；负数门会扣实际人数，归零就失败。
- 普通敌人、障碍和门/箱遵守前后遮挡次序。奖励对象不计为敌人击杀。

## 试玩

入口：http://127.0.0.1:43189/play/?v=07

1. 首页点击开始；第一只援军箱在右侧，按住并向右拖动瞄准。
2. 随后尝试把右边红门打成蓝门，再用队长脚下标记穿过它。
3. 看清箱顶奖励：援军增加兵力，弩阵箱提升火力，连营箱生成连续增员路线。
4. 第一次先以存活为目标；来不及打正的红门应换路。
5. 三关胜利后按原流程整军、建营、驻防；失败可免费重来，暂停可继续。

电脑可按住鼠标拖动，触屏可用手指拖动。此入口是本机浏览器测试，不是手机微信二维码。

## 复现命令

先按README安装本地依赖并准备Cocos 3.8.8。下面均在唯一工程内执行。测试顺序运行，避免不同浏览器争夺前台。

```sh
npm run typecheck:core
npm test
npm run test:negative
npm run build:web
npm run build:wechat
npm run typecheck
npm run serve
# 另一个终端，保持同一工程目录
npm run test:edge
npm run test:browser
npm run test:failure
python3 tools/verification-report.py
python3 tools/package-release.py
```

构建封装仅将官方成功退出36转换为shell退出0；构建成功不作为试玩成功。临时反向夹具预期有1个失败，其后正式18项仍全过，没有skip/todo或放宽断言。

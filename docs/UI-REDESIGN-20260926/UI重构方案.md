# 《一路长歌：三国》移动端 UI 重构方案 v1

> 适用：竖屏手游（微信小游戏 + Web），Cocos Creator 3.8.8，工程设计分辨率 720×1280、fitWidth。
> 配套文件：[wireframes.html](wireframes.html)（6 张关键界面中保真线框，浏览器直接打开）、[tokens.json](tokens.json)（色彩/字号/间距/动效令牌）。
> 本文所有尺寸以 **pt** 为主（参考画框 360×780pt），**1pt = 2px@720 设计宽**。最小适配屏 360×640pt。

## Part 0｜先说结论：现状诊断 + 对现有设想的直接意见

### 0.1 当前版本的核心问题（基于 `evidence/BATTLE-FIX2-20260925` 实图）

| # | 问题 | 位置 | 根因 | 本方案处理 |
|---|---|---|---|---|
| 1 | 顶部三行大框（关名/距离/火力）横贯全宽，压住远景和目标出现区 | 战斗顶部 | 把"说明文字"当 HUD；信息无优先级 | 拆成角落小件 + 一条行军进度条，顶部占高从 ~9% 降到 ~6%（非 Boss 态） |
| 2 | "86人"牌悬浮在主角头顶偏左，和队伍关系弱，还会进入门/箱的决策区 | 己方 | 没有屏幕分区规则，靠"避让算法"补救 | 引入**五区制**（见 3.1），兵力牌只允许在己方区 |
| 3 | 中间隔墙是一根细木桩，像临时道具，终点无收口 | 路中 | 墙只有碰撞意义没有造型语言 | 改为**连续矮木栅 + 端头旗墩**，按章节换材质 |
| 4 | 门是一面红布幡，+/− 只靠颜色和符号，门没有"门"的结构 | 门 | 只做了标签 | 门改为**辕门结构（双柱+横梁+幡）**，增/减在颜色、幡形、边饰三维区分 |
| 5 | 箱子上方是米色小纸签 + 进度条 + 裸数字"37"，玩家不知道 37 是什么 | 箱 | 数值直出 | 箱种靠**外形**区分，奖励用图标预告，耐久用分段条，不显示裸 HP |
| 6 | 敌将（杨龄）像一个大号小兵站在路上，Boss 条是顶部一根细红线 + "973/1600" | 敌将/Boss | 没有登场、没有舞台 | 敌将有**阵台 + 靠旗 + 名牌 + 登场预警**；Boss 有独立 Boss 牌 |
| 7 | 首页"开始征程"与"征程"并列，语义重复；"整备"与出征流程割裂 | 首页 | 入口按功能堆，不按玩家动线 | 首页只留一个主行动；整备并入出征流程 |
| 8 | 暂停键在右上角 | 战斗 | 未考虑微信胶囊 | 微信右上角是系统胶囊，**暂停移到左上** |

整体结论：**世界美术（山景、城关、人物立绘）基础是好的，问题主要在 UI 语言和战场信息编排**。所以本方案不推翻美术风格，而是在其上建立统一的"军阵信息系统"。

### 0.2 对你现有设想的直接意见（不合理处 + 替代）

1. **势力之主不应"收服"**。无名之人收服曹操、刘备、孙权，玩家会出戏。替代：名将分三种获得关系——
   - **收服**：战场击败敌将后归入麾下（吕布、典韦、张辽、赵云、关羽……）；
   - **寻访**：地图事件/结算获得的支援人物（华佗、貂蝉、郭嘉、诸葛亮）；
   - **结盟**：势力之主（曹操、孙策/孙权、刘备），不上阵，结盟时赠送本势力兵器/宝物并解锁下一势力。
   图鉴里用三种不同的印（收 / 访 / 盟）标识。
2. **"兵器页升级"和"战斗中获得武器"必须定义成两层，否则玩家困惑**：
   - 局外（兵器页）：决定哪些兵器**进入本局武器匣掉落池**，以及每把兵器的**常驻等级**（基础伤害）。
   - 局内（战斗）：武器匣决定**本局用哪把**，以及**临时阶级**（一阶→三阶，对应代码 `TIER_FACTORS`）。
   - 因此战前整备页**不能出现兵器选择器**，只展示"本关可能出现的兵器"。现有 `RunLoadout.weapon`（战前选刀/枪）应改为"起手固定长枪"，否则违背"不是开局选武器"。
3. **宝物槽要分类型**，否则玩家会带两匹马。建议 3 个类型槽：**典籍 / 器物 / 坐骑**，分别在第 1/2/3 关解锁，刚好对应第 1 关太平要术（典籍）、第 2 关传国玉玺（器物）、第 3 关赤兔马（坐骑）。
4. **支援人物不要做成战斗内主动技能按钮**。本游戏是单指拖动，加按钮会打断操作、增加误触。支援技能一律**自动触发**，只在 HUD 宝物/支援位显示可用次数与冷却。
5. **随军武将上场上限 2 人**（+主角 = 3 个"大人物"）。更多会让己方区失去层级，普通兵也会被淹没。
6. **现有三关的敌将（邢道荣、陈应、杨龄）辨识度低**，与"优先高辨识度人物"冲突。建议：现有三关的**玩法节奏**复用为第 1–3 关模板，换皮到群雄篇；这三人降为普通敌将，放到第 9 关荆州篇（长沙黄忠线）做客串。
7. **"兵器先到、本主后来"是好设计，要刻意利用**：例如第 4 关得双铁戟、第 5 关才收服典韦，拿到典韦那一刻双铁戟"神兵归主"首次触发，是强记忆点。
8. 现有代码里的**兵法（贯阵/震军）**是第三套局外选择。建议并入主角卡作为"主角兵法"二选一，不单独占一个整备区块；否则整备页会有 5 个区块，超出小屏承载。

## Part 1｜整体设计方向

### 1.1 风格定义：「墨底金线 · 军阵秩序」

一句话：**深墨蓝承底、羊皮纸承载信息、暖金只标身份与稀有、朱红只标危险与敌方**；战场是明亮的手绘国风世界，UI 是克制的"军中文书与旗帜"。

- 世界层（战场、地图、立绘）：东方手绘轻写实，暖色、有空气透视，保留现有画风。
- UI 层：三种材质，不再增加——
  1. **墨绢**（深墨蓝半透明，带极细织纹）：HUD、按钮底、页面底；
  2. **羊皮纸**（米白，轻微纤维纹，无污渍）：说明、卡片正文、弹窗内容；
  3. **旗布**（纯色布料，边缘轻微飘动）：门幡、敌将靠旗、Boss 牌、预警竖幅。
- 金色只作为**线**（1–2pt 描边、分隔线、角花）和**字**（重要标题），不做大面积金底。唯一例外：主按钮。
- 装饰规则：每个面板最多 **1 处**角花/云纹；战斗 HUD **零装饰**。

### 1.2 视觉关键词

史诗而克制 ｜ 旗与印 ｜ 墨色留白 ｜ 金线勾边 ｜ 布、木、铜、纸四种物料 ｜ 大字少字 ｜ 军阵秩序 ｜ 正负一眼分明

反关键词（评审时直接否决）：塑料高光、彩虹品质色、满屏粒子、霓虹描边、Q 版大头、科技网格、双层金框、繁体书法做正文。

### 1.4 字体与排版

| 层级 | 字体建议 | 字号 pt | 用途 |
|---|---|---|---|
| 书法标题 | 委托书法或已购商用授权书法字，**切成图片字** | 按图 | Logo、关卡名大标题、名将名（收服弹窗） |
| 标题 | 思源宋体 Heavy（OFL，可商用，按实际用字子集化） | 20 / 24 / 28 | 页面标题、卡片名、门副标 |
| 正文 | 系统黑体（PingFang SC / 思源黑体） | 13 / 14 / 16 | 说明、按钮、列表 |
| 战斗数字 | BMFont 位图字（粗黑体 + 2pt 深描边 + 1pt 投影），等宽数字 | 18–36 | 门值、兵力、Boss 血、飘字 |

硬规定：
- 正文最小 **13pt**；战斗内任何可读文字最小 **12pt**；门值远处最小 **18pt**。
- 当前工程依赖"系统宋体"，**安卓多数机型没有宋体**，会回落成黑体，风格不统一。标题宋体须打包子集（只收实际出现的约 600–900 字，目标 ≤ 400KB，放分包）。
- 数字全部用位图字：不依赖系统字体、描边可控、`+`/`−` 字形统一（用真正的减号 U+2212）。
- 中文不做字间距拉伸；标题允许 +2% 字距；不做竖排正文（竖排只用于预警竖幅和印章）。
- 单行战斗提示 ≤ 10 个汉字；门副标 2 个汉字。

### 1.5 按钮风格

- **主按钮**（每屏最多 1 个）：暖金底 `gold-500` → `gold-700` 竖向微渐变（仅 8% 明度差，不做塑料高光）、墨字 `ink-900`、高 56pt、圆角 6pt、两端各一个极小云头缺角。
- **次按钮**：`ink-800` 底 + 1pt `gold-500` 描边、`text-hi` 字，高 48pt。
- **文字按钮**：无底，`gold-300` 字 + 下划线，用于"跳过""查看详情"。
- **图标按钮**：44×44pt 热区，可见 32–36pt 墨绢圆角方。
- 按下：底色加深一级、内容下移 1pt、无缩放；热区不动。

### 1.6 为什么这样设计

1. **战场本身是暖色明亮的**（黄土路、青山），UI 用冷的墨蓝才能从世界里"浮出来"，同时不抢世界颜色；这也是现有版本的正确方向，本方案把它系统化。
2. **红/蓝是玩法语义**（减员/增援、敌/我），必须把它们从装饰色里剥离出来独占；所以装饰只能用金和墨。
3. **"旗、印、纸"是三国最强的视觉符号**，且都是平面的、易做九宫格、易本地化长度，比雕花边框便宜得多、也更有辨识度。
4. 小游戏包体受限，三种材质 + 位图数字的方案资源量小（UI 常驻贴图目标 ≤ 1.5MB）。

## Part 2｜页面级重构方案

页面总动线（替换现在的"首页三入口"）：

```
首页 ──主按钮「出征·第N关」──► 战前整备 ──「出征」──► 战斗 ──► 胜利结算 ──► 获得弹窗(0~N个) ──► 天下地图(新节点点亮) ──► 战前整备…
  ├─ 天下（地图，选关/重玩）
  ├─ 名将（图鉴）
  └─ 军械（兵器 / 宝物 两个页签）
```

四个一级入口：**出征 / 天下 / 名将 / 军械**。设置在首页右上（微信胶囊下方）。

### 2.1 首页

- **目标**：3 秒内知道"我是谁、打到哪、下一步点哪"。
- **版式**（从上到下）：
  1. 顶栏（安全区内，胶囊左侧）：身份牌「屯长 · 下邳已克」左对齐；设置图标在胶囊正下方。
  2. Logo 书法字「一路长歌」+ 副题「三国 · 由一人成一军」，位于上 22%。
  3. 主角立绘（保留现有 hero-home），占中部 45%，身后是**当前章节的场景**（群雄=黄土城垣，魏=许都宫阙，吴=江面楼船，蜀=蜀道栈桥）——首页背景随进度变，是"天下局势推进"最便宜的表达。
  4. 当前目标条（羊皮纸窄条，高 40pt）：「第四关 · 夜袭宛城｜敌将：典韦」+ 敌将小头像。
  5. 主按钮「出征」56pt，左右边距 16pt。
  6. 二级入口一排三个：天下 / 名将 / 军械，等宽，高 48pt，带图标；有可操作收益时显示红点。
- **层级**：主按钮 > 当前目标 > 立绘 > 二级入口 > 身份。
- **交互重点**：主按钮直达整备；立绘可轻点播放一次亮兵动作（彩蛋，不做功能）。
- **避免**：公告轮播、活动 banner、签到弹窗、多个金按钮、Logo 与立绘抢中心。

### 2.2 天下地图（10 关）

- **目标**：让玩家看到"天下被我一块块拿下"，同时是选关页。
- **版式**：竖向长卷（约 2.5 屏高），自下而上推进（起点在下，终章在上，符合拇指上滑"往前走"）。四个区域横向分段：群雄·中原（最下）→ 魏·许洛 → 吴·江东 → 蜀·西川（最上）。地理示意化，不追求精确。
  - 顶部固定栏：返回 + 「天下」标题 + **四势力印进度**（群雄 3/3、魏 1/2 …，未开势力印为灰墨剪影）。
  - 关卡节点：圆形城池印（直径 56pt），节点间用朱砂虚线行军路连接。
  - 未开区域覆盖**墨云**（半透明墨色云层 + 区域名淡字），不是纯黑遮罩。
  - 主角棋子（小旗 + 骑马剪影）停在当前关。
- **节点状态**：已克（朱印"克"字 + 本关获得人物小头像） / 当前（金圈呼吸 1.6s 周期 + 主角棋子） / 可重玩（同已克） / 未开（墨云内，只显示剪影城池，不显示名字）。
- **点节点** → 底部抽屉（高 42%）：关名、地点、敌将头像与名、本关可得（人物/兵器/宝物图标，未得为剪影+"？"）、最佳战绩（最高兵力）、主按钮「整备出征」。
- **关键动效**：解锁新势力时**墨云散开**（1.2s）+ 势力印落下盖章（0.3s）；这是全游戏第二重要的仪式感时刻（第一是收服名将）。
- **避免**：可自由拖拽缩放的大地图（小屏迷路）、节点旁堆星级和奖励小字、每个节点都放 Boss 立绘。

### 2.3 战前整备

- **目标**：在一屏内完成"带谁、戴什么"，并预告本关对手；不做数值海洋。
- **版式**（360×780 参考）：
  1. 顶部关卡条（高 64pt）：「第三关 · 白门楼 · 下邳」+ 右侧敌将头像（红圈）「Boss 吕布」+ 一行克制提示「敌将横扫，宜分散阵型」。
  2. **阵容区**（高约 300pt，羊皮纸浅底上的"军阵沙盘"感）：
     - 中间：主角半身像（大，120pt 宽），下方身份与兵法（贯阵/震军二选一的小切换）。
     - 左右：随军武将 ×2 槽（90pt 宽卡），显示名、势力印、持有本主兵器图标。
     - 右下角：支援人物 ×1 圆形槽（64pt），显示名与技能一行。
  3. **宝物栏**（高 88pt）：三个类型槽横排——典籍 / 器物 / 坐骑，每槽 64pt 方形，下方 12pt 类型字。
  4. **本关可能出现的兵器**（高 56pt）：一排小兵器图标（本主在阵中时图标带金色"归主"角标），右端「军械图鉴 ›」文字按钮。
  5. 底部主按钮「出征」。
- **交互**：点任一槽 → 底部抽屉选择（同一套"选择列表"组件）；长按人物卡看详情；槽位推荐用"本主"角标提示，不自动替玩家换装。
- **需要避免**：战力数字总和（本游戏胜负看操作与兵力，战力数会误导）；属性六维雷达；兵器选择器（见 0.2-2）；让支援人物和随军武将长得一样。

### 2.5 胜利结算

- **目标**：1 次确认爽感 + 清楚告诉玩家得到了什么 + 下一步。
- **版式与节奏**（按时间顺序出现，总时长 ≤ 3s，可点击加速）：
  1. 0.0s 墨色压暗战场 60%，**朱印"大捷"盖章**（书法图片字，印章落下 0.25s + 轻微震 2pt）。
  2. 0.4s 关名一行 + 身份晋升「屯长 → 军侯」（若有）。
  3. 0.7s 战绩三项（羊皮纸条）：**最高兵力**、**生还兵力**、**击破敌将**。不做星级评价——星级会逼玩家重刷，与"推进天下"的调性不符。若必须做评价，用"甲/乙/丙"一字等第。
  4. 1.0s 获得物横排卡（人物 / 兵器 / 宝物，最多 4 张，超出滚动），逐张翻出 0.12s 间隔；新获得的点击进入对应**获得弹窗**（2.9）。首次获得会自动依次播放弹窗，之后可在此重看。
  5. 底部：主按钮「继续征程」→ 天下地图（播放新节点点亮），次按钮「再战此关」，文字按钮「返回首页」。
- **避免**：结算里再放大段剧情文字、数字滚动超过 0.6s、分享按钮（无授权前不做对外）。

### 2.6 名将图鉴 / 收服页

- **目标**：收集欲 + 看懂每个人在战斗中的作用。
- **版式**：
  - 顶部页签：全部 / 群雄 / 魏 / 吴 / 蜀（势力色小印做页签图标）。右上计数「已得 12 / 30」。
  - 网格 3 列人物卡（3:4，约 104×138pt），卡面：半身像、名字（思源宋体 16pt）、势力印、关系印（收/访/盟）。
  - 卡片三态：**已得**（彩色）/ **已遇未得**（墨色剪影 + 名字 + "第 N 关可收服"）/ **未遇**（剪影 + "？"，不显示名字）。
- **详情页**（点卡进入，全屏）：上半立绘（带势力色旗布背景）；下半羊皮纸面板：名 · 字 · 称号（例「吕布 · 奉先 · 飞将」）、关系与获得关卡、**战场作用**（1 行：如"随军：横扫前方扇形"）、**本主兵器**（图标 + 是否已拥有 + 共鸣效果 1 行）、典故 2–3 行（标"史载"或"演义"）。底部按钮「编入随军」（若可上阵）。
- **避免**：人物升星/碎片系统（与本作推进方式不符，会让图鉴变养成页）；把典故写成长文。

### 2.7 兵器页（军械·兵器）

- **目标**：看懂"我有哪些兵器进了掉落池、各自多强、谁是本主"。
- **版式**：
  - 顶部页签：兵器 / 宝物（与 2.8 同页）。
  - 列表为**横向兵器卡**（全宽，高 72pt），兵器横陈在锦缎上：左兵器图、中名与品阶（金属色字）与常驻等级「Lv3」、右本主头像（未得本主为剪影）。
  - 排序：品阶高→低，未获得的放最后显示剪影 + "第 N 关获得"。
  - 点卡 → 详情抽屉：大图、攻击形态示意（小动图：直刺/扇形横扫/连射）、局内三阶的变化一句话、**共鸣效果**、升级按钮（消耗与效果差值，写成"伤害 120 → 138"）。
- **避免**：武器能"装备"（它不能开局装备）；多种升级材料；品阶用彩虹色。

### 2.8 宝物页（军械·宝物；同时是整备的宝物选择界面）

- **目标**：一个页面两种模式——**浏览模式**（从军械进入）和**佩戴模式**（从整备宝物槽进入）。不要做两个页面。
- **版式**：
  - 顶部三个类型槽（典籍/器物/坐骑）显示当前佩戴，点击切换筛选。
  - 下方 3 列宝物卡（方形 104pt），物件放在漆盘上，下方名称。
  - 选中后底部固定详情条（高 120pt）：名、类型、效果 1–2 行（带具体数值）、典故 1 行、按钮「佩戴」/「卸下」。佩戴模式下同类已佩戴的会显示"替换 赤兔马"。
- **宝物效果建议稿**（数值由策划定）：
  - 典籍：太平要术（每过一扇增援门额外 +10%）、青囊书（减员后 3s 内回复所失 25%）、孟德新书（武器匣开启所需击打 −30%）
  - 器物：传国玉玺（开局兵力 +20%）、七星灯（全军覆没时复起一次，保留峰值 30%）、木牛流马（募兵箱与宝匣奖励 +1 档）
  - 坐骑：赤兔马（横移速度 +25%）、的卢（每局一次，兵力 ≤10% 时免除本次损失）
- **避免**：宝物随机词条、宝物等级、同类型叠戴。

### 2.9 获得弹窗（收服人物 / 获得兵器 / 获得宝物）

统一模板「展卷」：遮罩 `ink-900` 70% → 中央卷轴从中线向上下展开（0.3s）→ 内容 → 0.8s 后才接受点击（防误跳）→ 底部"点击继续"。

| 类型 | 主视觉 | 文字 | 按钮 |
|---|---|---|---|
| 收服名将 | 全身立绘从势力色旗布后走出；书法名字图片字；左上关系印"收" | 名 · 字 · 称号；一句话战场作用；本主兵器（若已拥有显示"神兵可归主"金字） | 「编入随军」（主）/「稍后」 |
| 寻访人物 | 半身立绘 + 圆形锦囊框；关系印"访" | 支援效果一句话 | 「编入支援」/「稍后」 |
| 结盟 | 两枚势力印相合动画；盟主半身像 | 「与曹操结盟」+ 赠礼列表 | 「受礼」 |
| 获得兵器 | 兵器横陈锦缎，品阶金属光扫过一次 | 名、品阶、攻击形态、本主提示「若随军有典韦：神兵归主」 | 「收入军械」 |
| 获得宝物 | 物件置于漆盘，缓慢自转 15° | 名、类型、效果 | 「立即佩戴」/「收入军械」 |

多个获得物按 **人物 > 兵器 > 宝物** 顺序依次弹，每个之间 0.2s；提供右上「全部跳过」。

### 2.10 失败 / 暂停 / 设置（应简化）

- **失败**：不用"失败"大字，用"兵散"墨字 + 本局最高兵力 + **一条具体建议**（从本局数据推：如"第 3 扇减员门损失 64 人，可从左侧绕行"）。按钮：「再战」（主）/「调整整备」/「返回」。无体力、无复活付费。
- **暂停**：半屏羊皮纸面板：继续（主）/ 重开本关 / 设置 / 退出关卡（二次确认）。显示本关宝物与随军一览（只读）。
- **设置**：底部抽屉，只放 4 项：音效、音乐（当前无 BGM 时隐藏）、震动、画质（标准/省电）。外加存档说明一行。不做独立页面。

## Part 3｜战斗界面深度方案（重点）

### 3.1 屏幕五区制（所有战斗元素的放置法则）

> **2026-09-27 更新**：战斗界面的分区公式、HUD 两行结构、字号阶、宝物槽位置和预警竖幅位置，已由 `docs/BATTLE-PREVIEW-20260926/战斗规格.md` 取代。其中分区改为按安全区计算，HUD 改为两行，宝物槽移到左侧竖列，预警竖幅移到 Z2 右缘。本节与 §3.2 仅保留作设计缘由参考。

以屏高 H 计（参考 780pt，最小 640pt），T = 安全区顶（微信取胶囊顶部）。

| 区 | 纵向范围 | 放什么 | 禁止放 |
|---|---|---|---|
| Z0 顶部 HUD | T ~ T+96pt（Boss 态 T+120pt） | 暂停、关名、行军条/Boss 牌、兵器签、宝物位 | 任何世界物体标签 |
| Z1 远景预告区 | ~11%–28% H | 远处城关（终点）、敌将阵台、Boss 登场、名将预警竖幅 | 门值（太远不显示，只显示幡色） |
| Z2 决策区 | 28%–58% H | 门、箱、墙、敌阵及其标签；这里的信息决定玩家往哪滑 | HUD、兵力牌、提示条、飘字 |
| Z3 己方区 | 58%–88% H | 主角（锚点 y=70% H）、随军、士兵、兵力牌、增减飘字、升级反馈 | 大面积特效遮挡门值 |
| Z4 底部区 | 88%–100% H | 一行提示条（B−56pt）、教学手势 | 关键数字（会被拇指挡） |

这条规则直接解决现状的"人数牌遮门""提示遮挡"类反复修补问题：**不是做避让算法，而是让每种信息有固定的领地**。

### 3.2 HUD 结构

**常规行军态**（线框见 wireframes.html · 图 1）：

```
Row1 y=T      h=32   [暂停32×32] [关名牌：第三关｜白门楼]              (微信胶囊区 ≈ 96pt 宽，留空)
Row2 y=T+40   h=20   [==== 行军条：起点旗 ···· 敌将节点◆ ···· 城关终点 ====]
Row3 y=T+64   h=32   [兵器签：图标 方天画戟 ◆◆◇ | 军械:火矢]          [宝物位 □□□]
```

- **暂停**：左上，可见 32pt 墨绢方，热区 44pt。（右上是微信胶囊；Web 端也放左上，保持一致。）
- **关名牌**：墨绢胶囊形，高 28pt，「第三关｜白门楼」思源宋体 14pt。不显示距离米数。
- **行军条**：x=12→348pt，轨道高 4pt（`ink-800` 70%），已行进部分 `gold-500`；只标 3 类节点——起点旗、敌将 ◆（红）、终点城关（Boss 关为 Boss 头像小印）。**不标门和箱**（太多节点等于没标）。主角小旗随进度移动。
  - 若本关胜利条件是"剩余敌军"，行军条右侧追加小字「敌 52/120」13pt。只此一处。
- **兵器签**：40pt 圆角方图标位（品阶金属色描边）+ 兵器名 13pt + 阶级 3 颗菱形点（◆◆◇）。下方 11pt 小字「军械·火矢」表示队伍火力（现有"队伍火力 · 火矢"文字改为此）。整体宽 ≤ 150pt。
- **宝物位**：右侧，最多 3 个 32pt 小方，显示佩戴宝物图标；有次数的显示右下角数字徽标（七星灯"1"）；冷却中显示顺时针扫描遮罩；已用尽变灰。支援人物作为第 4 个圆形位（不同形状区分"人"和"物"）。
- **全部 HUD 非交互**（除暂停），不拦截拖动。

**Boss / 敌将交战态**（线框图 2）：Row2 的行军条被 **Boss 牌** 替换（进度此时已无意义）：

```
Row2 y=T+40  h=48  [Boss头像40 红圈][吕布 · 飞将]  [████████████░░░░ 分段血条]  二阶段
Row3 y=T+96  h=32  [兵器签]                                        [宝物位]
```

- Boss 牌：左侧 40pt 圆头像（`red-600` 2pt 圈），名 16pt `text-hi` + 称号 11pt `gold-300`；血条 8pt 高、宽至右边距，底 `ink-900`，血 `red-600`，**受击后的残血段用 `paper-300` 缓降 0.4s**（让玩家看到每刀的量）；按阶段分段刻度（竖线）；右端阶段字「二阶」。**不显示 973/1600 裸数值**（小屏无意义且显得像测试版）；如需数值，放在暂停面板。
- 普通敌将（非 Boss）**不进 HUD**，血条在脚下（见 3.5）。

### 3.3 中部战场可视区：让它像三国战场

**路面**（L0）：
- 路是"行军道"而非跑道：以车辙、马蹄印、碎石、零散箭矢、踩倒的草作为质感，**明度保持中间调**（HSL L 55–65%），饱和度 ≤ 35%，为门箱人物让出对比。
- 路缘与草地之间做 12–20pt 的自然过渡（土坡、碎草），不要硬边。
- 按篇换材质（同一套 UV/切片，换贴图）：群雄=黄土道；魏=夯土官道 + 局部石板；吴=江岸泥滩 + 木栈段；蜀=山道石阶 + 栈道。

**路边景**（L1）：
- 每侧每屏最多 **1 个大件**（营寨、箭楼、营帐、残车）+ 2–3 个小件（旗杆、拒马、石堆），且只在路外。
- 远景加 10–20% 雾色，近景不加；所有路边景饱和度低于门箱。
- 终点城关常驻在 Z1 顶部，随行进缓慢放大，Boss 关的城楼上有 Boss 本势力大旗。

**中间隔墙**（L3，重做）：
- 造型：**连续矮木栅**——立柱（每 1.2 个士兵宽一根，顶部削尖）+ 两道横木 + 麻绳绑扎，高度约 0.6 个士兵，**不高于门幡的下沿**，所以永远不挡门值。
- 端头收口：起点和终点各一个**石墩 + 小旗**（旗色中性土黄），让玩家看清"墙从哪到哪"。
- 按篇换材质：群雄=木栅；魏=夯土矮墙；吴=水渠（两岸木桩，墙变成一条窄河，末端一座小木桥收口）；蜀=山石垄 + 栈道护栏。
- 投影与路面透视一致；不做发光描边。墙若可被射毁（木障），被击时木屑 + 分段塌落，塌落后留下残桩（不瞬间消失）。

### 3.4 目标元素统一设计系统

统一语法：**结构（木/铜/布）决定"这是什么"，颜色决定"好还是坏"，数字决定"多少"**。所有目标元素的标签都挂在元素自身结构上（幡面、签牌），不再用飘在空中的米色小纸框。

#### 门（辕门）

| 部件 | 增援门 | 减员门 | 零值/中性 |
|---|---|---|---|
| 结构 | 双木柱 + 横梁 + 铜箍，柱顶小旗 | 同结构，横梁有断裂/缠铁蒺藜 | 同结构 |
| 幡 | `blue-600` 布幡，底边整齐带金色回纹 | `red-600` 布幡，**底边撕裂锯齿**，无金纹 | `paper-300` 幡 |
| 数字 | `+24` 白色位图字 + 深蓝描边 | `−94` 白色位图字 + 深红描边 | `0` 墨字 |
| 副标 | 「援兵」 | 「伏兵」 | 「空营」 |
| 冗余符号 | 幡顶一面小旗 | 幡顶一枚断箭 | — |

- 数字尺寸：近处（进入 Z2 下半）32–36pt，远处最小 18pt；进入 Z1 时只显示幡色不显示数字（避免远处糊成一团）。数字字号按透视缩放但**夹在 18–36pt 之间**。
- 幡宽 = 所在车道宽 × 0.8；门柱不进入相邻车道。
- **可射击成长**（现有 window 规则）：幡底边一条 3pt 细进度线，填满 → 数字 +1 档并脉冲放大 1.08×（0.12s）。数字滚动用 0.15s 翻牌，而不是逐个递增（逐个递增在大数值时太慢）。
- **负转正**：数字经过 0 时幡**翻面**（scaleX 1→0→1，0.25s），颜色红→蓝、底边锯齿→整齐、副标"伏兵"→"援兵"，伴随一次金色尘点（≤ 12 粒子）。这是门上最有爽感的瞬间，必须做。
- **连续门/多列门**：同一排的门幡上沿对齐；两门之间必须有隔墙或 ≥ 0.5 车道空隙；同排门的数字字号一致（取较小者），避免"看起来大的更好"的误导。
- 通过门：幡向后翻飞 + 数字化为飘字飞入兵力牌（0.35s）。

#### 箱（四类，靠外形区分，40pt 缩略时仍可辨）

| 箱种 | 外形 | 标签（签牌，挂在箱顶） | 开启反馈 |
|---|---|---|---|
| 募兵箱（+N 兵） | **粮车**：带两个木轮的小车 + 麻袋 | 蓝底签「+12」+ 兵卒小图标 | 麻袋打开，士兵从车后跑入队列 |
| 兵器匣 | **长条木匣**（宽:高≈1.6:1），匣面刻兵器剪影，铜包角 | 纸签：兵器图标 + 名「偃月刀」；若本主在阵，签角金色"归主"小印 | 匣盖弹开，兵器竖起旋转一周飞向 HUD 兵器签 |
| 军械箱（火矢/连弩等队伍火力） | **方木箱，顶部插着一束箭** | 纸签：「火矢」+ 箭矢图标 | 箭束散开化为全队箭头换色 |
| 宝匣 | **黑漆描金方匣**，金扣 | 金边纸签：宝物图标或"？"（未见过的宝物） | 匣开出金光（仅一次、0.4s），物件飞向 HUD 宝物位 |

- **耐久**：箱下方 5 段分段条（宽 44pt、高 4pt），每段对应 20%；**不显示数字**。被击时箱体抖动 2pt + 对应段熄灭。
- 签牌字号 13pt，签牌宽随内容、最大 88pt；签牌与箱体用一根细绳相连（视觉上"挂着"，解决现在签和箱分离的问题）。
- 与门冲突时：箱标签避让规则 = 下移到箱体下方，而不是上移进入门的范围。

#### 宝物提示

- 宝物**触发**时（例：青囊书回复）：HUD 对应宝物位闪 `jade-500`/`gold-500` 光圈 0.4s + Z3 兵力牌旁一行 12pt 小字「青囊书 · 回复 16」，停留 1.0s。
- 不在屏幕中央弹任何宝物横幅。宝物是被动的，反馈必须"在身边、不打断"。

#### 名将预警

- 触发：敌将进入 Z1 前 1.5s。
- 表现：屏幕**右侧**（或敌将所在侧）从上滑入一条**竖幅**（宽 56pt、高 200pt，`red-800` 旗布 + 金色书法竖排名字「吕布」+ 下方小字「方天画戟 · 横扫」），停 1.2s 后收回；同时 Z1 敌将阵台位置出现红色地面光圈。
- **不暂停游戏，不压暗全屏**，不遮挡 Z2。竖幅只在屏幕边缘 56pt 宽的带内。
- 仅"首次在本关出现的敌将"触发；Boss 用更长的版本（1.8s，竖幅加宽到 72pt，加一次鼓声）。

#### Boss 血条

见 3.2。补充：Boss 进入二阶段时，Boss 牌红圈加粗 + 竖幅短闪一次「二阶 · 怒」，场上 Boss 身后旗阵变多。

#### 关卡提示

- 位置：Z4，y = B−56pt，高 32pt，墨绢胶囊，居中，宽 ≤ 280pt，14pt 字，≤ 10 字。
- 同屏最多 **1 条**。优先级队列（沿用现有 `BattleNotice` 的"高优先级不被低优先级覆盖"逻辑，扩展为 5 级）：
  1. 危险（Boss 投矛锁定、兵力 ≤10%）— 红左边线，1.6s
  2. 神兵归主 — 金左边线，1.4s
  3. 兵器升阶 — 金，1.2s
  4. 宝物/支援触发 — 按 3.4 宝物提示走 Z3，不占提示条
  5. 教学/普通 — 墨，1.2s
- 教学提示只在前 2 关出现，且每条只出现一次。

#### 升级反馈（武器箱开出 → 兵器升阶）

时序（总 0.9s，不暂停）：
1. 0.00s 兵器从匣中竖起（世界层）
2. 0.15s 沿弧线飞向左上兵器签（0.45s，带 6 帧拖影）
3. 0.60s 兵器签金光描边闪一次，阶级菱形点亮一颗（◆◆◇→◆◆◆），图标换成新兵器
4. 0.60s 主角同步播放一次**亮兵**动作（已有动作帧可复用）+ 脚下金圈扩散一次
5. 0.65s Z4 提示「方天画戟 · 三阶」
- **神兵归主**（本主在随军，且拿到其本主兵器）：在上面基础上，本主武将身前出现 **金色书法字「归」**（图片字，48pt，0.6s 渐隐）+ 其靠旗变金边 + 本主专属一次大招光波（例如关羽的偃月横斩）。每局每位本主只演一次全套，之后只做金边闪光。

**敌将的舞台感规则**（解决"敌将像小兵一样挤过来"）：
1. **登场**：名将预警竖幅 → 阵台在 Z1 亮起 → 敌将从城关/营寨后走出站定（0.8s）→ 敌兵在其两侧列阵。
2. **对峙**：敌将停在阵台，与玩家队伍保持 ≥ 30% H 的纵向距离，期间发动 1–2 次有预警的技能（地面红圈 → 锁定变实线 → 落下），给玩家"躲"的操作空间。
3. **出阵**：敌兵清完或计时到，敌将单独前冲一次（冲锋轨迹有地面红箭头预警 0.6s）。
4. **败北**：敌将跪地或持兵后撤（不做"倒地消失"），靠旗倒下；若可收服，头顶出现金色"收"印 0.5s——在战斗中就预告"结算可收服"。

脚下血条（普通敌将）：宽 48pt、高 5pt，名牌下方；Boss 不用脚下血条。

### 3.6 视觉层级组织（渲染顺序 + 对比预算）

```
L0 地表（路面、车辙）            对比最低
L1 路边景（营寨、箭楼、远山）      低饱和、有雾
L2 地面标记（阵台、预警圈、门影）
L3 可交互物（门、箱、墙）         世界内对比最高
L4 单位（按 y 排序）
L5 特效（刀光、箭雨、尘土）       加色混合，alpha ≤ 0.8
L6 世界标签（门值、箱签、名牌、兵力牌）  ← 放在特效之上！
L7 HUD
L8 提示条 / 预警竖幅
L9 弹窗
```

- 关键改动：**世界标签（L6）必须在特效（L5）之上**。刀光箭雨再多，门上的数字也不能被盖住。
- 对比预算：同一屏中"最高对比"只给 L3 可交互物和 L6 数字；单位靠轮廓（1pt 深色描边）而不是亮度突出；特效同屏粒子上限 120（参考现有 decorative 48 池做分池）。
- 灰度测试：截图去色后，门的正负仍能靠幡形（整齐 vs 锯齿）区分；主角仍能从士兵里一眼找出。

### 3.7 兵力牌（最重要的数字）

- 形态：一面**小帅旗**（墨绢底 + 金色 1pt 边，旗杆由队伍中的一名旗手持着），旗面上位图字「86」26pt + 右侧 12pt 小字「兵」。
- 位置：锚定主角头顶上方 6pt，**被夹在 Z3 顶线（58% H）以下**；队伍横移时跟随，但带 0.08s 平滑，不抖。
- 增减飘字：`+12` `blue-400` / `−94` `red-600`，从旗面上方升起 20pt、0.6s 渐隐；0.3s 内连续多次合并成一个数字。
- 兵力 ≤ 10% 峰值：旗面转 `red-800` 底并缓慢脉动，Z4 出现危险提示一次。
- 四位数以内显示完整数字（完整数字更有爽感）；≥ 10000 才缩写为「1.2万」。

### 3.8 "爽感、清晰、三国感"如何同时成立

| 目标 | 手段 | 边界（防止失控） |
|---|---|---|
| 爽感 | 门负转正翻幡；通过门时人从门后涌入队列；兵器飞入 HUD；神兵归主"归"字；敌将败北靠旗倒下；击中敌将 40ms 顿帧 | 屏幕震动只在 Boss 败北（2pt、0.2s）；全屏闪白禁止 |
| 清晰 | 五区制；正负三重冗余（色/形/字）；标签在特效之上；HUD 只剩 5 件；同屏 1 条提示 | 任何新元素要先回答"它在哪个区" |
| 三国感 | 辕门、粮车、兵器匣、靠旗、阵台、战鼓、朱印、书法竖幅——**用物件而不是边框**表达时代 | 不加雕花边框；书法只用于名字和印 |

   - [ ] 所有正文 ≥ 13pt、战斗文字 ≥ 12pt
   - [ ] 新元素标注属于五区中的哪一区
8. **交付物**：Figma（或同类）组件库，组件名与 Part 4 一致（如 `GateBanner/Plus/Near`），变体覆盖全部状态；切图 @2x PNG，九宫格标注切线；动效用关键帧表（见 5.2 动效表）而不是只给视频。

### 5.2 给前端/游戏开发：规格摘要

**节点结构（Cocos）**

```
Canvas (720 设计宽, fitWidth)
├─ WorldRoot                 // 现有 BattleView 世界层，按 L0–L6 分子节点
│   ├─ L0_Ground  L1_Scenery  L2_Decals  L3_Interactables  L4_Units  L5_FX
│   └─ L6_WorldLabels        // 门值/箱签/名牌/兵力牌，必须在 L5_FX 之上（现有 WorldLabels.ts 落此层）
├─ HudRoot (SafeArea + 胶囊避让)  // 不拦截触摸，仅 PauseBtn 可点
│   ├─ Row1: PauseBtn, StageName
│   ├─ Row2: MarchBar | BossPlate（互斥）
│   └─ Row3: WeaponChip, TreasureSlots[3], SupportSlot
├─ NoticeRoot               // Toast（Z4）、WarnBanner（屏边竖幅）
└─ PopupRoot                // 暂停、结算、获得弹窗、抽屉
```

**布局与适配**
- 顶部基准 T：微信用 `wx.getMenuButtonBoundingClientRect().top`，Web 用 `safe-area-inset-top`（最小 12pt）。HUD 行按 T 偏移，不按屏高百分比。
- 世界分区按屏高百分比（Z1 11–28%、Z2 28–58%、Z3 58–88%）；主角锚点 70% H。短屏（640pt）时 Z2 保持 ≥ 30% H，压缩 Z1。
- 兵力牌：`y = clamp(heroHeadY − 6pt, Z3Top, …)`，横向 0.08s 平滑。
- 门值字号：`clamp(perspectiveScale × 36pt, 18pt, 36pt)`；深度在 Z1 时隐藏数字。

**数据绑定（HUD ↔ 模拟状态，只读，不改规则）**

| HUD 元素 | 数据源（按现有模块名） | 更新时机 |
|---|---|---|
| 行军条进度 / 敌将节点 | `runner` / `levels` 的关卡长度与敌将位置 | 每帧插值 |
| 敌剩余计数 | `horde` 剩余量（仅"歼敌"胜利条件关） | 变化时 |
| 兵器签 | `weapons` 当前 `WeaponId` + `tier` | `upgrade` 事件 |
| 军械小字 | `tactics` / 队伍火力标识 | 军械箱事件 |
| 宝物/支援位 | 局外存档佩戴 + 局内次数/冷却 | 触发事件 |
| Boss 牌 | `BOSS_TARGET` 生命与阶段 | 受击事件，残血 0.4s 缓降 |
| 提示条 | `BattleNotice` 扩展为 5 级优先级 | 事件驱动 |

**字体**
- 数字：BMFont（0–9、+、−、×、万、兵），两套描边色（蓝/红）+ 一套墨色，单张图集 ≤ 256KB。
- 标题：思源宋体 Heavy 子集（构建脚本从文案表自动抽字），放分包。
- 正文：系统字体。
- 书法：PNG 图片字，按需加载。

**性能与包体预算**
- UI 常驻贴图（HUD、按钮、九宫格、位图字）≤ 1.5MB，放主包；立绘、书法字、地图长卷、章节路面放分包按篇加载。包体上限以微信当期官方限制为准。
- 同屏特效粒子 ≤ 120；世界标签节点池化（门/箱/名牌 ≤ 16 个同屏）。
- HUD 文本不每帧 `string =`：数值变化才更新（小游戏 Label 重排开销大）。

**与现有代码的落点建议**（按文件职责名推断，实施前需逐一确认）
- `BattleView.ts`：拆出 L0–L6 子层；把门/箱标签从当前绘制逻辑迁到 `ui/WorldLabels.ts` 并置于 FX 之上。
- `ui/UiLayout.ts`：实现五区与 HUD 三行布局常量；替换现有顶部大框。
- `core/battleNotices.ts`：`BattleNotice` 扩展优先级与分通道（Toast / 宝物近身提示 / 预警竖幅）。
- `WorldScenery.ts` / `BattleRoad.ts`：章节材质切换、隔墙木栅与端头。
- `core/weapons.ts`：`RunLoadout.weapon` 战前选择改为固定起手（需策划确认后再改规则）。

### 5.3 最值得先做的 6 张关键界面（按优先级）

| 顺序 | 界面 | 为什么先做 | 必须包含的状态 |
|---|---|---|---|
| 1 | **战斗 · 常规行军态** | 玩家 90% 时间在看它；门/箱/墙/兵力牌/HUD 的视觉语言都在这张定下，其它页面照此延伸 | 左右两扇门（一增一减）+ 中间木栅 + 一个兵器匣 + 一个募兵粮车 + 兵力牌 + 完整 HUD |
| 2 | **战斗 · 名将登场与 Boss 交战态** | "名将舞台感"是本作区别于同类跑酷的核心卖点，也是当前最弱处 | 预警竖幅、敌将阵台、敌兵两侧列阵、Boss 牌、地面攻击预警 |
| 3 | **战斗 · 获得与升级瞬间（状态表）** | 爽感来源；门负转正、兵器飞入、神兵归主必须在一张状态表里对齐节奏 | 翻幡 3 帧、兵器飞入 3 帧、"归"字、宝物近身提示 |
| 4 | **战前整备** | 连接局外养成与战斗，结构最复杂，需要尽早验证一屏能否放下 | 主角 + 2 随军 + 1 支援 + 3 宝物槽 + 兵器预告 + 敌将预告 |
| 5 | **胜利结算 + 收服名将弹窗** | 每关的情绪顶点，也是"一路崛起"的主要表达 | 大捷盖章、晋升、获得卡、收服展卷 |
| 6 | **天下地图** | 10 关推进感与四势力开图的唯一载体 | 已克/当前/未开三态节点、墨云、势力印进度、选关抽屉 |

第 7、8 优先：首页（现有立绘可复用，改动最小）、名将图鉴。兵器/宝物页用 Part 4 组件直接拼，不需要单独高保真。

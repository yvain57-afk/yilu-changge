# 主将近战与弓兵齐射：必须共同成立的规则

## 1. 为什么要改到规则层

当前基线将N人的伤害合并为每0.25秒一支逻辑箭，单箭伤害N×0.2，视觉由Volley展开到每人弓口。
新版本主角已无弓，不能继续把他算作一个弓手，再附送刀枪伤害。

新版唯一计数：总兵力N = 1名主将 + max(0,N-1)名弓兵。N=0败；N=1时只有主将且零弓箭；N上限256，可见上限48且包含主将。
本轮无独立主将HP，不做“主将倒地但队伍还在”的第二套生命。

弓兵每0.25秒齐射一次，合并伤害 `0.2 * max(0,N-1)`，按发射帧冻结。N=1时不产生新的零伤箭、shot事件或假弓口；此前合法发射且仍在空中的箭，继续按冻结的发射伤害结算。
主将长枪每次命中固定5伤害，初值0.6秒一个完整动作周期，只在近战有效区内产生伤害。身份只改外形，不增加隐藏倍率。
这不是维持旧DPS的等价换皮。近战使近距离总火力变化，属于用户授权的新战斗合同；旧版纯数值轨迹要保留为历史，不强求逐事件相同。

理想近身持续输出算例：N=8时弓兵5.6 DPS、主将约8.33 DPS；N=48时弓兵37.6 DPS、主将约8.33；N=256时弓兵204 DPS、主将约8.33。只有目标一直在枪尖范围且每次刺击命中时才成立，不能当作真实通关成绩。

## 2. 长枪近战状态机

使用固定60Hz模拟tick，初值如下：
- 前摇10 tick；有效5 tick；恢复21 tick；总周期36 tick（0.6秒）。
- 最远攻击距离1.10个前进单位，近端0；横向半宽0.14。
- 当前项目一个前进单位是逻辑行程单位，**不是米**。不得把屏幕像素直接当模型距离。
- 起手检查时最近候选位于距离0～1.25内，且落在枪道横向范围，才开始动作；1.25为准备距离，有效段仍只到1.10。
- 每轮最多一次真实命中，最多一个目标。长枪本轮不穿透，不横扫。

主角沿玩家输入横移；攻击不锁输入、不自动追踪走位、不冲刺到敌人身边。有效区随当前主角中心移动，始终朝前，与所显示枪尖一致。
在有效段每tick检查最近的相交物。命中后给本轮标记spent；剩余有效tick不重复扣血。
主角移开、目标退出范围、目标先被弓箭击败时允许这一枪落空。下一次起手再选择目标，禁止为“确保主角有用”瞬间补伤害。

候选按当前前向距离、稳定ID排序。最近的是山石时，该枪被阻挡，消耗本次命中机会且不伤山石；不能穿石刺到后方。木障、普通敌兵、弩手、Boss均可被枪命中，数字门不参与伤害。

受阻门的整个半侧由现有rowId/side定义，近战同样使用这条形状合同。不能在木障一端画细木棍，却让另一端出现无形挡击。

## 3. 动作与伤害的对应

模型产生：`meleeStart`、`meleeActive`、`meleeHit`、`meleeEnd`，携带attackId、tick、sourceId='hero'、命中targetId、真实worldZ和实际伤害。
可以沿用既有命中/击破事件总线，但远程projectileId与近战attackId必须区分，不伪造箭作为近战实现。扩展Feedback.kind和sourceId联合类型，更新全部相关消费者；未受影响消费者应安全忽略不认识的表现事件。主将动作不得再由全队lastShot切换为持弓射箭姿态。

表现层按模型相位播放收枪/前刺/伸展/回收。枪尖在有效段伸到真实交点；短残影仅覆盖兵器扫过区域，不脱离枪尖飞行。命中火花出现在实际目标，受击位移仅作表现，不把敌人逻辑位置推过门。
动画回调不得触发第二次伤害。Cocos动画事件只用于声音/局部表现或调试；杀伤由固定步模型作唯一决定。
攻速/伤害不能随渲染帧率、动画帧数、设备或素材加载速度变化。

## 4. 弓兵视觉与伤害契约

保留现有Volley冻结起点、真实通道、最近目标、地形阻挡和销毁规则。
新的shot快照至少包含totalCount、archerCount、发射tick、发射x/世界z和目标呈现数据。若保留旧volley.count字段，它仍表示总人数，禁止偷偷换成弓兵数使旧调用错位。
采样阵型后显式过滤`u.hero`：最多47个可见弓口；每次合并逻辑箭的伤害由全部N-1弓兵贡献。N>48时不能按可见47人截断伤害。
`Volley.groups`仍最多5组，视觉箭上限235（5×47）；可保留原240容量缓冲，但诊断必须报告实际峰值，不能从主将枪尖出箭凑数。
齐射不随主角近战动作暂停，也不让弓兵改成近身枪兵。主将、弓手上身动作分别使用各自的状态。

## 5. Boss接敌：模型和画面一起靠近

目前Boss目标深度固定4；仅在渲染中拉近会制造假命中。
新版本为Boss保存相对队伍的`depth`及前一tick值；进入守关后1.0秒从4移动到0.90，随后保持该交锋距离。
默认第一击仍在守关进入2.0秒后开始蓄力。这两秒包含1秒接近与至少1秒观察，不额外叠加两个2秒等待。

三位现有Boss均在进入交锋距离后使用已有攻击模式与损失参数。第一版不加无敌阶段、空中飞行、无限后撤、狂暴或全新AI。
投矛/弩箭/长弓武器及提示沿用本关配置，主将靠近后持枪还击。Boss交锋距离0.90只是模型初值，需要以真实人物/武器比例检查遮挡；可在0.70～1.00内修正并记录。
Boss体型可小幅修正，禁止为了让枪够得着而画一根横贯全屏的武器，或把Boss缩成普通兵。

共享目标几何：Boss x（本轮固定0）、横向半宽0.42、动态depth。主角枪和箭都读取同一模型。Boss图片脚底、武器发射点、血条、预告起点使用同一状态。
Boss移动过程中箭命中需做相对运动的扫掠：
`r0 = arrow.prevZ - boss.prevWorldZ`，`r1 = arrow.z - boss.worldZ`；在横向相交且r0<=0<=r1时发生交会。
有多个目标时按本tick交会时间先后取第一项；不因目标后移/前移产生穿透。视觉箭终点跟随真实碰撞事件，不能冻结成永远落在旧depth=4的图片；发射起点仍冻结，禁止飞出的箭跟手平移。
N=1时主将仍能走到Boss横向位置并持续真实命中，不需要自动恢复弓兵，不添加远程冲击波兜底。

## 6. 帧内结算顺序

单tick遵循：输入/位置与场景行程 → Boss接近位置 → 弓箭飞行/命中 → 主将有效段/命中 → 胜负提前退出 → 门和接触 → 敌方警告/落点结算 → 清理。
在同tick枪刺死敌人时，后续接触不能再扣兵；若枪未击破，仍按显示碰撞损失正常处理。
Boss被我方合法攻击击败后，本tick尚未落下的攻击清理，保持现有胜利优先语义；不要同帧一边结算胜利一边归零失败。
重复restart/leave销毁状态，未命中的近战事件不能在下一局补发。暂停冻结前摇、有效段、恢复、Boss接近及预告；回到前台等待显式继续。

## 7. 一次可见的近战入门

现有第一关敌人容易在很远处被齐射清掉。增加一个独立ID=901的近战展示敌兵：at=3.0、x=0、width=0.20、HP=14、碰撞损失4。
它从远处可见，显示损失；开局没有必须点击的教程。默认直行者在第一排门之前可看到一枪真命中，左右移动者可以主动绕开。
这是显式新内容，不属于“绝对不改关卡”的旧合同；无强制挨打、假无敌、锁定玩家或伪造命中。
初值需要用当前模型核对：若仍被弓兵提前击败，优先只调这一个敌兵HP/距离或把出枪准备时机对齐；不得暗中关闭弓手或整关提高敌方生命。普通敌人、Boss阶段也必须能发生真实近战，不能只靠这个演示敌兵假装完成机制。

## 8. 平衡与调试边界

首关/二关/三关原行路42/54/66、门、起兵8/12/16默认保留，第二关早期木障损失5保留。
近战为角色新增实际能力，不要求旧录像的58.42/66.92/81.42秒逐一重现。
用正常/安全/晚切三种纯模型策略和1人Boss夹具比较：可通、有明确失败、低兵仍能造成伤害、近战有使用空间。模型可以快进迭代；真实交付录像不快进。
时长目标仍约60/75/90秒，只作调参参考，绝不作为硬超时或自动胜利条件。

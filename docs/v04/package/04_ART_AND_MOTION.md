# 美术与动作生产：先看见一个真正带兵作战的主将

## 1. 不重新做选型

继续现有主角的脸型、发型和蓝色识别布料，改为窄袖战袍、短甲、护腕、长枪。三国武将感通过头肩、甲片大形、武器比例和持械重心建立，不靠纹理密度。
角色设计认可只代表方向，现有小屏观感不自动通过。本轮直接制作并试装，不再要求选择A/B。
主角枪是普通制式长枪，不冒用赵云的专属名器，不把名将兵器当开局赠品。

## 2. 在现有渲染规模里完成

主角沿用约108设计单位高度作起点；手机360/390宽分别约54/58.5 CSS像素。普通友军70设计单位高度继续使用原共享图集。
保留N=1/8/24/48/256的阵型语义，48可见含唯一主角，主体与武器边缘不得溢出屏幕或挡住门数字。

主角可用分层Sprite：下身六帧步态 + 持枪上身 + 枪身/前臂（必要时少量附加层）；弓兵维持现有上身射箭与六帧步态，不给47个弓兵加复杂骨架。
主角每阶段尽量≤5个Sprite；这只是本轮成本上限建议，不引入新渲染框架。上身、手与枪的握点必须一起校验，不能让枪漂在手外。

布衣/领队/统领三套战斗状态使用同一轮廓基础，改变短肩甲、腰带、旗标等部件。第四显示状态白石驻将可以沿用统领战装加营地礼姿；无皇帝冠服、全新骑乘或第二把武器。

## 3. 长枪必须制作的姿态

|姿态|画面要求|逻辑来源|
|---|---|---|
|持枪前进|枪随重心轻动，腿真实交替；没有原弓藏在背面|行路时间+步态|
|准备|手向后收、躯干微转，枪尖仍指向目标通道|windup phase|
|前刺|前臂向前，枪杆平移/小转动，枪尖真实到敌身|active phase|
|命中|目标局部短闪/轻退，枪尖小火花，声音短促|meleeHit事件|
|落空|仍完成一轮，不冒出伤害数字|attack结束且无命中|
|回收|前手带枪归位，肩背恢复|recovery phase|
|收枪立旗|同一个人收枪、接旗或站定|transition/promotion|

前摇、有效、恢复必须从模型状态采样；手机掉帧后应跳到正确相位，不能累计渲染dt把枪刺慢了。
“击中暂停”只能慎用局部表现，不能冻结输入、模拟时钟、箭速或整张画面。首版优先短闪/回弹，少用全屏震动。

## 4. 空间一致性检查

武器枪尖、Boss脚底、敌人脚底与实际判定全部使用共享投影。
调试视图在同一画面显示：主角有效枪域、枪尖、目标可碰撞轮廓、箭轨迹；正常游戏隐藏这些线。
Boss靠近后血条和名字不能压在主角头上。近战交锋区留出轮廓差，弓手排在主角后方，投射物能看清从后排飞出。
Boss的远程攻击轨迹从武器发射点飞到锁定地面，不从屏幕上方凭空落下，不把缩短距离误作缩短预告时间。

## 5. 场景延续

保留WorldScenery已经采用的世界距离和离屏回收。换三国包装不重新引入“每几秒一整排塔回跳”。
第一关山道、第二关粮营、第三关城门，主体资源继续使用；添加少量军旗、箭架和粮械即可交代背景。
营地过渡复用上一关环境：突围后路边整队、夺营后原营门落旗、解围后原城门与县城节点。避免突然切成一张完全不同画风的菜单。
全图地图只是一块可操作的军略板，显示曹操/刘备/孙权方向与当前白石节点；不是精确疆界图，不写真实年份，不放几十个锁定空关。

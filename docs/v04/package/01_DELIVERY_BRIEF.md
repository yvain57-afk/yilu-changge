# v0.4 总任务：先把主将带兵作战做成立

## 1. 这一版玩家的旅程

首页“带兵破阵，逐鹿三国”。八人上路，主角持枪，七名弓手跟随。
三局连线：乱军突围 → 整军 → 夺粮立营 → 落旗驻营 → 白石解围 → 驻防白石。
最终目标仍为逐鹿天下，本轮结尾是获得立足之地。玩家尚未成为与曹操、刘备、孙权平起平坐的第四方。

四章母结构保留在内部：无名立足 → 三国夹缝 → 三面破局 → 天下归一。约32战只作未来内容容量设想；不建空32关，不画等待加载的空地图节点。

本轮不重写整个BattleView，不将2D改成3D，不制作独立网页战斗壳。

## 2. 优先级与工作量取舍

P0：持枪主将的真实近战 + 完整弓兵齐射 + Boss物理接近 + 360/390宽真实画面。
P1：同一轻量过渡组件的三种配置，保存可靠，能继续下一关。
P2：一次赵云战后会面，三国旗号/军报提示，细节收束。

P0的动画、武器接触和队伍可读性优先于复杂营地场景。预算紧时减少过渡装饰和镜头数量，不得取消真实近战或把过渡退成“胜利—下一关”两个按钮。三种过渡均只需一个拖放动作；触摸不便者可点击等效按钮。

不再次要求用户选A/B。以已认可脸型、发型、蓝色识别布料为底，去掉主角弓箭，制作枪将。设计变更为用户本轮明确授权，旧“主角必须保留弓”的文档不再有效。

## 3. 必交内容

### 战斗
主角自动近战、兵力计算拆分、全队远攻、三位Boss接近交锋、第一关早期出枪机会。
既有固定+N/×2、每排一次事务、先扣兵后增益、零兵不复活、地形挡箭、明确危险、暂停与即时重开持续有效。
后两关只复用已有敌人与场景，不加新战斗系统。已获认可的改进不可回退。

### 美术
主角三阶段持枪战斗上身/武器、既有下身六帧步态、一次进攻/受击/收枪或举旗动作；Boss接近和恢复的可读动作；友军仍为共享图集。
共用营地图包含营火/空地、兵列、旗杆、粮械堆、简化县城节点。可复用现有资产并少量补画。
赵云只做一张原创半身像和“赵云”名牌，不做独立AI、骑马或招募系统。

### 叙事/流程
开场最多两句；中途不暂停读长文；战后过渡直接承接战场对象。
新手第一次体验过渡，重复挑战默认不强迫重复。跳过装饰动画与直接出发的结果一致。
第三关结尾打开白石驻地，三个完成关可重玩；无第四关空按钮，无天下统一/称帝庆典。

### 交付
一个可运行的三关版本和一个启动入口；一次完整原速有声录屏；第一关真实近战、弓口齐射、Boss接敌、一次拖旗的短片裁自同一录像即可。
此处成品范围为“首段可玩体验”，不能声称全部三国内容已制作。

## 5. 调参权限

data/combat.v04.json中的数值全部为试制初值。先实现再用规则策略比较。
允许在配置中小幅调整主将固定伤害、动作时长、枪长、Boss交锋距离和“新增展示敌兵”的生命/出现位置；理由写一次简表。
既有门值、三关起兵和第二关已调到5的早期受阻门损失默认不改。确有必要改Boss HP时需在同一交付变更表明确列出，不能运行时按剩余兵力缩血。
禁止新增硬超时、隐藏补兵、阵营隐藏倍率、付费复活或强制玩家看剧情才能解锁。

## 6. 连续执行顺序

先核对最少入口与实际命令；制作可用的枪将素材并把近战接入第一关；使用相同合同改三位Boss距离，保留弓兵与连续地面；把过渡组件连入三关与存档；最后短检查和一次自然三关录像。
源代码/素材有真实变更才针对性复测。不能因为文档同步、图片文件名改变而再重跑旧全量长测试。
若素材工具确实不可用，记录缺项并完成独立规则工作；未有正式素材时不能将草模写成正式画面完成。

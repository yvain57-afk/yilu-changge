# 从打赢一场，到有地方立足

## 1. 玩家看到的世界

天下有曹操、刘备、孙权，各自有旗号、军队和道路。你的旗一开始只在一小队人手里。
首页题名《一路长歌：三国》，主按钮“出征”或“继续征程”，一句目标“带兵破阵，逐鹿三国”。不报年份，不解释人物为什么同处一个世界。

本轮只讲荆州一带的三场局部战斗：乱军突围、夺粮立营、白石解围。白石是本项目的剧情地名，开发文档可记录来源属性，正常游戏无需挂说明。
原著关系和未来四章留在内容档案，本轮不讲曹刘孙在第二局就亲自拉拢你；地图也不把你的新驻地涂成占据半个天下。

## 2. 三局剧本（最终运行文案见JSON）

### trial-01 乱军突围 / 场景沿用山道 / 8人
前营已散，你带七名同袍冲开追兵截路。主将一开始持枪，队伍后排用弓。
开场：同袍“前面还有伏兵！” 你“跟紧我，杀出去。”
当前目标：带队冲出山道。
Boss显示名：截路头目；仍用投矛动作。
结算一句：这一仗，弟兄们认了你的旗。
称谓显示：无名小卒 → 领队。它是本作显示称谓，不修改基础存档数值。

### trial-02 夺粮立营 / 场景沿用营寨 / 12人
突围后收拢散兵，粮械不足。附近营地被同一股地方武装占据，先取营地稳住队伍。
开场：同袍“粮械都在营里，先打穿营门。” 你“弓手压住两翼，随我上！”
当前目标：夺下粮营，整备人马。
Boss显示名：守营弩将；对应弩箭和弩手行为。
结算一句：粮械齐备，终于有营可守。
称谓显示：领队 → 统领。

### trial-03 白石解围 / 场景沿用城门 / 16人
白石被围，通向营地的道路受阻。守营不是终点，你出兵解围，获得驻防的落点。
开场：同袍“白石就在前头，围兵堵着城门。” 你“先破围，再进城。”
当前目标：击退围兵，解白石之围。
Boss显示名：围城都尉；复用第三Boss现有武器与可读预告，不写与动作不符的招式。
结算一句：白石围解，这面旗有了立足之地。
称谓显示：统领 → 白石驻将。不是第四方势力、皇帝或一统荆州。

赵云只在胜后同场景会面，不作为免费武将掉落：
赵云：“城外的援兵已退。白石的百姓，还要靠诸位守住。”
你：“这面旗，会留在这里。”
对白是本作新写，不在知识卡中当作古人原话。第一版不做赵云战斗AI、骑马或临时替你清屏。

## 3. 一个过渡组件，三个不同后果

过渡必须连接到上一局的实际成果。玩家做一个短动作，局部场景出现改变，下一局目标变得有因果。
它不是额外经营游戏；不用金币、时间、建筑升级条、随机判定或失败条件。

### T1 整軍：从散兵到可出征的队伍
呈现：战场边缘变为整队空地；阵型收拢，旗在主角手边，远处粮营方向亮起。
动作：把军旗拖向整队空地，或点击空地/“整军出发”。
即时反馈：散兵向旗集结，展示下一局12人的先锋编制；道路指向粮营。
意义：你成为这支队伍带头的人，并确定下一步先去夺粮。
句子：收拢散兵，点齐十二名先锋，去取粮营。
下一局从配置12人开始，不把本关剩88人偷偷变成12人。过渡明确“其余弟兄留守，先锋出征”。不足12时由场景中的会合散兵补编；这是局外固定整编，不在战斗中暗加兵。

### T2 建营：从拿到粮械到有后方
呈现：上一关攻下的营门/粮械堆保留，敌旗撤下；白石方向出现急报标记。
动作：把己方旗拖到旗杆，或点击旗杆/“驻营出征”。
即时反馈：营旗升起、箭架/营火出现，16人先锋在道路口列队，其他军士留营。
意义：营地成为后方，前往白石的行动有了出发点；只是显示固定后果，不开放资源经营。
句子：粮械留营，十六名先锋随你驰援白石。
护甲变化只改外形，不加未说明的伤害系数。

### T3 驻防：从赢一场到真正有驻地
呈现：城门打开，白石局部地图和一小块驻军空地出现；曹、刘、孙三个方向以远处军旗/道路线索存在，不开放对应大军战役。
动作：把你的旗放进白石驻军点，或点击驻军点/“落旗驻防”。
即时反馈：据点从空白变为己方小旗，营地视图可常驻；赵云战后会面出现，离场后进入驻地首页。
意义：玩家有了可以回来的地方；下一步将从此出兵。
结束文字：“白石初定，立足荆州。”主按钮“返回驻地”，次按钮“重整旗鼓”（重玩已有关）。
不写“天下一统”“第四势力已建立”“全部主线完成”，也没有“第四关待制作”的不可用大按钮。

## 4. 交互尺度与取消行为

默认每个过渡只需一个动作，预计体验约5～10秒；这是设计目标，无强制等待或倒计时。
拖动起点与目标均需至少44 CSS px可点击区域，手机360宽也能清楚命中。吸附半径宽容，失败放手返回原位且不扣任何东西。
点击目标或主按钮与拖放调用同一`completeTransition(id)`，效果完全一致。玩家无需阅读台词才可出发；主按钮立即可用。
没有需要反复刷出来的不同奖励；不要用三个没有结果区别的“策略选项”伪装深度。第一版的互动是亲手整军、建立据点。
一根手指从战斗抬起不能触发转场按钮。每次切屏清touchId/dragging/pendingButton，忽略没有在新页面开始的touchEnd。后台自动暂停，无恢复瞬间误触。
自然拖旗成功后短反馈即可继续下一关，不再加一次“确认出发”。直接点击主按钮可缩短反馈，同样完成整编。
重复挑战默认只保留简短结算与“再战/下一关”，不强迫每次重新立旗；驻地允许重看过渡，但不重新发奖励。

## 5. 状态与持久化

保留基础存档键`yilu-changge-prototype-v2`、旧键及trial-01/02/03的cleared/best/settings，不清档、不重新锁关。
UI称谓改用显示映射 `[无名小卒,领队,统领,白石驻将]`；内部旧rank字符串可保留兼容，不得再从内部“城主”直接输出本版新故事。

新叙事状态独立存入sidecar键`yilu-changge-campaign-v04`，最小数据：
```
{ schema: 1, completed: { rally:false, camp:false, garrison:false },
  seen: { zhaoyunMeeting:false } }
```
据点外观、编制和解锁从基础通关+上述布尔项推导，不另存可重复领取的货币。

一次胜利的顺序：先更新并尝试保存基础通关 → 显示胜利 → 首次通关且对应过渡未完成则进入过渡 → completeTransition以幂等方式更新内存并尝试保存 → 下一关/驻地。
`completeTransition`必须校验对应关已通关；重复调用不追加数值，不跳过未通关关卡。下一关仍统一经过现有canStart。

新进度：中途关闭后首页优先返回“待完成过渡”；玩家用“整军出发”等等效入口即可继续，不要求逐句读文。
旧进度迁移：已有基础档、sidecar不存在时，为所有已通关关推导对应过渡完成；三关均通时推导已驻防和赵云会面已看。保留原成绩/设置，直接进入可继续关或驻地；不强迫老玩家重复三段剧情。
首次全新档cleared全false时不推导完成状态。sidecar坏档按已通关基础状态恢复，显示正常保存提示；不得连带重置基础档。
基础存储失败：内存胜利有效，提示本机暂不能保存，仍能过渡与出征；sidecar写失败同样可继续。两个存储写入不具备事务性，恢复须幂等，禁止因为缺一个标志卡死。

退出/重启后如果基础win已保存、sidecar未保存且完全不存在，按旧档推导会跳过这一次装饰交互，但不能丢通关或重复奖励。这是首版明确接受的降级；已有sidecar记录时则恢复pending过渡。

## 6. 内容和运行分离

`data/campaign.v04.json`为玩家可见文案与流程数据的权威本。不要把本开发包中的背景解释直接塞进游戏。
开发注记、证据性质、来源属性只在文档。正常界面保留版权署名/隐私/设置，本条不覆盖平台硬性要求。
没有一套完整32关或全武将系统上线，本轮不要声称已具备。后续可把营地扩成出兵/武器/人物入口，但现在不放空菜单。

# 按改动验证，不把每轮制作变成长测试项目

## 1. 本轮可以改的测试语义

用户明确授权主将近战、N-1弓手和Boss动态接敌。这些已改变原全员弓手伤害与固定Boss深度；对应旧golden不能直接比较新版数值。
保留旧测试/fixture作历史。对新增规格建立新断言并在迁移表逐条说明。其他门、人数、暂停、存档、公平性断言不放宽，不删除、不skip、不用假对象替换规则蒙混通过。

## 2. 需要新增/更新的快速检查

|类别|必须验证的行为|
|---|---|
|主将计数|N=1时仅主角、无新shot和无弓口；N=8时7弓手；N=48时47；N=256仍计算255弓手伤害|
|齐射快照|开火后损兵/增兵/横移不改变已经发出的伤害和起点；视效≤5组、235箭，不从枪尖出箭|
|近战距离|远处目标不受枪伤；有效范围内真实命中；横移脱离可落空；非有效段无伤害|
|近战重复|同一attackId的5个有效tick最多一次扣血，最近目标优先，无穿透|
|地形与门|山石阻挡枪且不掉HP，木障可被枪击破；门数字不受攻击；受阻门仍先扣后增益且0不复活|
|同帧|弓箭/长枪先击杀，后接触不再扣兵；Boss归零优先结束，无幽灵攻击|
|Boss移动|模型depth从4到交锋位，画面读取一致；移动中箭的相对扫掠不穿过目标；2秒前不攻击|
|预告|锁定之后不追踪，完整预告与飞行仍有效；杀死蓄力者取消，已飞出攻击仍有效|
|单人可通|1人Boss夹具可持续造成伤害并通过合法横移获胜；三位都验证；无隐藏补兵/波攻击|
|重开/后台|前摇、有效、恢复、Boss接近、预告均暂停；触摸取消/旧touchEnd不误触过渡|
|过渡等价|拖旗、点击目标、主按钮调用同一结果；无计时、阅读或坐标精度门槛|
|幂等与恢复|双击/反复进入过渡不重复领取；基础win先保存；中断恢复pending；坏sidecar不清旧档|
|旧档|已有三关成绩/设置原样保留，不重新锁关；只有新显示称谓变化|
|越权开关|手改查询参数/重复转场不绕过canStart开启未通关关或第4关|
|玩家文案|正常首页、开场、战斗、结算不含本包禁用的出戏说明，调试/版权区分开|

纯规则策略测试可以加速推进模拟时间。单人Boss用例生命较多时允许较长模拟上限，但只用于测试，不把上限写入游戏规则。
需要实机观察的动作不能由纯模型测试宣称通过。需要模型碰撞的内容也不能只凭漂亮截图宣称正确。

## 3. 快速工作节奏

修改中：只运行相关测试和必要类型检查；素材小改用编辑器/已有预览看相关动作，不反复完整构建两端。
合并后：一次完整快速规则集 + 类型检查 + 必要Web构建；同一源码未变不重复相同命令。
本轮确有状态机/动画/过渡缓存变化：做一次短的N=48/256密度夹具及连续3次重开，观察相同场景缓存是否稳定。预热状态有新增要记录，不能要求所有场景首次加载就永远同一节点数。
最终：一次真实输入自然三关，包含两次过渡与最后驻地，录像和验收共同复用。不默认十局长测、原verify-v03全量、游客微信双平台反复构建。
若真实发现内存持续增长、崩溃或跨端错误，再针对该问题扩大测试，写明理由；不是永远不做长期稳定性检查。

禁止用`|| true`隐藏错误。日志写项目内，只返回失败相关段；不要把全部TAP、base64图集和十几页历史复制进对话。

## 5. 实机证据只收这些

一条连续原速有声录像：从首页出征，经首关、整军、第二关、建营、第三关、驻防和赵云会面到驻地。
从该录像裁出一个短片，能看清至少一枪实际命中、后排多点齐射和一次过渡操作。不能为“看清主角”伪造关闭全队伤害的录像。
360与390 CSS宽各检查：战斗主将、Boss交锋、过渡目标、结尾界面；短屏另外做一次边界冒烟，不需要再走完整三关。
第一次近战机会在正常新档路径应该可见；主动绕开敌人的路径不强制拉回。

测量类型分开：开发机桌面帧时间/内存、目标手机性能、微信开发者工具、微信真机、用户审美分别列状态。Web不能代替手机，构建不能代替试玩。
不需要为每个小修订再生成一整套评审网页、九宫格和几十张截图。

## 6. 最终交付格式

更新一个入口文档 `docs/v04/GPT_REVIEW.md`，只包含版本/提交/工作区状态、可玩入口、连续录像、修改清单、简短验证、真实缺项及下步最多3项。
源码/构建/录像应能关联同一内容指纹。已有启动器继续复用并确认能启动；不要让用户翻源码找localhost命令。
最后更新PROGRESS.md和BLOCKED.md即可，不把历史通过结果改写成本轮通过。

交付用户时用不超过10行说明：现在能玩什么、如何打开、最明显的变化、是否仍缺素材/手机条件。美术和手感仍由用户亲玩判断。

## 7. 真正的完成条件

- 玩家看到自己是拿枪的大将，近战实打，弓兵参与，剩主将一人不会失去获胜能力。
- 三关之间有可操作并改变场景的承接；确实整军、建营、驻防，不是阅读三张卡片。
- 一路只需左右移动和每次一次简短过渡操作，无新经营负担。
- 第三关获得一个驻地，既不误宣称统一天下，也不在正常UI说明“架空试制”。
- 当前三关能完整完成、重玩、暂停、恢复；旧存档安全；快速验证与实际交付一致。

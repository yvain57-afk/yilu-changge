## 1. 屏幕分区（按安全区计算，不用固定百分比）

```
T        = safeTop + 4
HUD 行1  = [T, T+36)
HUD 行2  = [T+42, T+82)
hudBottom = T + 82
P0       = hudBottom + 8          // 战场可用区顶
z4y      = H − safeBottom − 48    // 提示区顶
ph       = z4y − P0
Z1 远景预告 = [P0, P0 + .22·ph)
Z2 决策区   = [Z1 底, Z1 底 + .40·ph)
Z3 己方部曲 = [Z2 底, z4y)
Z4 提示区   = [z4y, H)
heroY    = Z3 中线（主将脚底）
```

实测（自检报告）：

| 尺寸 | 安全区 上/下 | hudBottom | Z1 | Z2 | Z3 | Z4 | heroY |
|---|---|---|---|---|---|---|---|
| 360×640 | 20 / 0 | 106 | 114–219 | 219–410 | 410–592 | 592–640 | 501 |
| 390×844 | 47 / 34 | 133 | 141–278 | 278–526 | 526–762 | 762–844 | 644 |
| 430×932 | 59 / 34 | 145 | 153–306 | 306–585 | 585–850 | 850–932 | 718 |

**透视**：`proj(x,z)`，`s = c/(z+c)`。
- 视平线 `hy = T − 6`，藏在 HUD 之后。
- 世界距离 z = 6 落在 Z2/Z3 分界上，由此反解出 c。
- 主将深度处 1 世界单位 = 0.4W；路面半宽 1。
- 主将左右范围 x ∈ [−0.82, 0.82]。

## 2. HUD（L7，两行，任何状态下都不越过 hudBottom）

**行 1**（y = T，高 36；控件高 32）
- **暂停**：x 12，直径 32。
- **兵器签**：x 52，宽 `min(176, 胶囊左 − 60)`。内容依次为：
  - 26×26 兵器图标；
  - 兵器名，body 14；
  - 3 枚菱形阶位，已达阶为金色；
  - 右端「共鸣·关羽 / 张飞 / 吕布」，caption 12，绿色。长枪无共鸣，不显示。
- **平台胶囊预留**：87×32，右距 7，与兵器签不交叠。

**行 2**（y = T+42，高 40，同一槽位按状态切换）
- **行军条**（常规）：高 32。关名 body 14，后接进度轨。进度轨含 4 个节点刻度、终点红点，当前位置为蓝色菱形。
- **敌将牌**（交锋）：高 40。
  - 左侧 30×30 印章（「吕」）；
  - 名字 title 16，衬线加粗；
  - 名字后接「方天画戟 · 敌将」，caption 12；

**宝物槽**（3 格：典籍 / 器物 / 坐骑）

## 4. 世界元素

**体量**：以主将深度处的世界单位 u 计，均为脚底锚点。

| 元素 | 高度 | 相对普通兵 |
|---|---|---|
| 己方 / 敌方兵 | .37u | 1.00 |
| 随军（赵云 / 陈应） | .44u | 1.19 |
| 主将 | .50u（生成帧整帧 ÷ .80，躯干占 80%） | 1.35 |
| 敌将吕布 | .66u（÷ .9） | 1.78 |
| 辕门 | .98u | — |
| 箱 | .34–.46u | — |

随军固定 2 人，站在主将两侧 ±0.30，每 1.5 秒出手一次（赵云为枪气，陈应为叉气），出手强度约为主将的 0.8。

### 4.1 辕门（成对，x = ±0.5，门宽 0.88）
- **构成**：两根立柱 + 横梁 + 旗面。
  - 蓝旗「援兵」为正数；
  - 红旗「伏兵」为负数；
  - 白旗「空营」为 0。
- **数字**：层级 L6，高于所有特效。
  - 位于旗面 42% 高度处；
  - 旗宽 ≥ 64 时，下方加 12pt 小字（援兵 / 伏兵 / 空营）；
  - 门位于 Z1 时只显示旗色，不显示数字；
  - 接近部曲时淡出：条件为 `room = 兵力牌顶 − 24 − 数字底`，当 `z < 1.6` 或 `room < 0` 时隐藏，淡出系数为 `min(1, (z−1.6)/1.4, room/36)`。这样小屏上 Z3 变矮时，门数字也不会压到兵力牌。
- **通过判定**：`|heroX − gateX| < 0.46`。通过后门体渐隐，兵力牌出现增减飘字，并在 Z4 弹出提示。

### 4.2 箱（4 类，靠外形区分）

| 类 | 造型 | 血量 | 开出 |
|---|---|---|---|
| 募兵 | 粮车 | 6 | 援兵 +6 |
| 兵器 | 兵器匣 | 10 | 当前兵器升一阶 |
| 军械 | 箭箱 | 8 | 箭雨 8 秒 |
| 宝物 | 宝匣 | 14 | 宝物（示例：赤兔马，点亮「骑」槽） |

- 头顶显示 5 段血格；在 Z2 及以下时，血格上方再显示 12pt 箱名。
- 受击时白闪并抖动 2pt；打开后播放开箱帧，0.5 秒后渐隐。
- 密集门段内不放箱，避免箱名夹在两排门数字之间。

### 4.3 固定墙段（木栅营垒）
- **位置**：占右半幅路面（`side = 1`，x ∈ [0.06, 0.95]），长 26 世界单位，本段位于第 74 步。
- **构成**：
  - 正面一排、背面一排：尖桩，间距 0.13，内端放石墩；
  - 内侧一列：沿行进线每 1.6 设一根桩，桩间两道横木；
  - 内部：夯土色地面贴花，内侧纵列外沿画一道暗线。
- **阻挡**：经过墙段期间，主将 x 被夹在 `≤ 0.06 − 0.20 = −0.14`，只能走左半幅。

### 4.4 敌将（吕布，将台位于 z = 17，路中）

| 阶段 | 时长 s | 画面 |
|---|---|---|
| 对峙 | 1.1 | 立定帧；每 3.2 秒放出 3 名小兵 |
| 预警 | 1.2 | 蓄势帧；地面红色目标带脉动，白色充能线从敌将推向主将；右侧出现竖幅 |
| 出招 | 0.45 | 横扫帧；刀气向主将推进，镜头震动 0.5 |
| 收势 | 1.5 | 收势帧；将台出现金色破绽圈，头顶显示「破绽 ×2」，此阶段主将伤害 ×2 |
| 力竭 | 2.4 | 跪降帧；提示「吕布 力竭 · 可收降」 |

- **目标带**：按预警开始时主将所在位置决定。主将在左则为 [−1, −0.02]，在右则为 [0.02, 1]，在中则为 [−0.5, 0.5]。
- **判定**：刀气到达 z ≤ 0.2 时，若主将在目标带内（两侧各放宽 0.05），兵力 −10，并出现红色闪屏；否则提示「闪开横扫 · 趁收势反击」。
- **预警竖幅**（L8）：56×200，贴在右缘并从右侧滑入（0.2 秒），纵向位于 Z2 中部。
  - 内容：竖排「吕布」（title 16）、竖排「横扫」（body 14）、方向「左路 / 右路 / 中路」（caption 12），底部是充能条。
  - 不压 HUD，不越出 Z2–Z3。

## 6. 层级与标签规则

- **渲染顺序**：
  - L0 地面 → L1 路边场景 → L2 贴花（墙内地面、将台、目标带）；
  - L3 门、箱、墙 / L4 单位（按深度排序）；
  - L5 特效 → L6 世界标签；
  - L7 HUD → L8 竖幅与提示条。
- **数字高于特效**：门数字、箱名 / 血格、兵力牌、飘字都在 L6，任何刀光都不会盖住数字。
- **Z1** 只显示旗色和轮廓，不显示数字和箱名。
- **提示条**（Z4）：高 32，居中，最宽 280，位于 z4y+8 处，body 14。显示 1.6 秒，按优先级排队：中招 > 宝物 / 力竭 > 援兵 / 闪避 > 普通。

## 7. 每帧自检（`window.__layoutReport()`，面板实时显示）

1. HUD 各控件的底边不超过 hudBottom，控件之间互不交叠；宝物槽不压路面，也不与 HUD 行交叠。
2. 预警竖幅不压 HUD，且位于 Z2–Z3 内。
3. 提示条位于 Z4，且在底部安全区之上。
4. 所有文字字号都在 §3 的字号阶内；Z1 中不出现门数字。
5. 门数字之间、箱名 / 血格与门数字之间、兵力牌与门数字之间互不重叠。
6. 主将锚点位于 Z3。

**结果**：
- 3 尺寸 × 3 状态 × 4 兵器，每组连续 250 帧，并用正弦拖动主将，共 0 项违例；
- 10 张交付截图全部 0 违例；
- 页面无报错，无 404。

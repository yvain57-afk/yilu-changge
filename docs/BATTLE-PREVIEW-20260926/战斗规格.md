## 1. 屏幕分区（按安全区计算，不用固定百分比）

```
T        = safeTop + 4
HUD 行1  = [T, T+36)
HUD 行2  = [T+42, T+82)
hudBottom = T + 82
P0       = hudBottom + 8          // 战场可用区顶
z4y      = H − safeBottom − 48    // 提示区顶
ph       = z4y − P0
Z1 远景预告 = [P0, P0 + .22·ph)
Z2 决策区   = [Z1 底, Z1 底 + .40·ph)
Z3 己方部曲 = [Z2 底, z4y)
Z4 提示区   = [z4y, H)
heroY    = Z3 中线（主将脚底）
```

|---|---|---|---|---|---|---|---|
| 360×640 | 20 / 0 | 106 | 114–219 | 219–410 | 410–592 | 592–640 | 501 |
| 390×844 | 47 / 34 | 133 | 141–278 | 278–526 | 526–762 | 762–844 | 644 |
| 430×932 | 59 / 34 | 145 | 153–306 | 306–585 | 585–850 | 850–932 | 718 |

| 375×667 | 20 / 0 | 106 | 114–225 | 225–427 | 427–619 | 619–667 | 523 |

**透视**：`proj(x,z)`，`s = c/(z+c)`。
- 视平线 `hy = T − 6`，藏在 HUD 之后。
- 世界距离 z = 6 落在 Z2/Z3 分界上，由此反解出 c。
- 主将深度处 1 世界单位 = 0.4W；路面半宽 1。主将左右范围 x ∈ [−0.82, 0.82]。
- 横移最大速度 `MOVE.vmax = 3.0` 世界单位/秒；坐骑赤兔 ×1.25。

## 2. HUD（L7，两行，任何状态下都不越过 hudBottom）

**行 1**（y = T，高 36；控件高 32）
- **暂停**：x 12，直径 32。
- **兵器签**：x 52，宽 `min(196, 胶囊左 − 60)`。内容：26×26 兵器图标、兵器名（body 14）、3 个阶位菱形（升阶时对应菱形放大闪金）、共鸣行（caption 12）：
  - `on`：绿色「共鸣·本主名」；
  - `pact`：金色「盟约·盟主名」；
  - `off`：灰色「本主名未随军」；长枪无本主，不显示。
  - 换兵器时签整体闪亮，兵器图标从主将处飞入签内（.35 秒）。
- **胶囊**：右侧 87×32，平台保留区，不放任何控件。

**行 2**（y = T+42，高 40）
- **关卡进度条** + 关名（「第三关 · 下邳」）。
- **宝物槽**：x = 8，y 从 P0 + 4 起竖排，28×28，步距 34，依次 典 / 器 / 骑。状态：
  - `empty`：暗框 + 单字「典 / 器 / 骑」；
  - `worn`（已佩戴）：实框 + 宝物图标；
  - `trial`（本局试用）：虚线蓝框 + 角标「试」；
  - `used`（每局一次已用完，例：玉玺）：图标压暗 + 角标「用」；
  - 宝匣开出别的同类宝物、记入结算入库时：槽位闪一下。
- **支援环**：宝物槽下方间隔 4，「援」字圆环，冷却时按比例走圈；触发时闪亮。无按钮。

## 4. 世界元素

### 4.1 人物体量

### 4.2 主将与随军

- **主将**：四兵器各 4 帧跑步循环（`g_run_<兵器>0–3`）；攻击 蓄 / 出 / 收 三帧；换兵器时亮兵帧 `g_brandish_<兵器>` 0.55 秒。
- **随军**（演示阵容）：赵云 dx +.30、张飞 dx −.30。每 1.5 秒出手一次：蓄势帧 .35 秒 → 出手帧 .20 秒；2 帧跑步。
  - 共鸣本主：脚下绿色光环；本局第一次出手放共鸣技（刀气宽 2.2 + 2 道蛇行枪气），之后出手伤害 ×1.5。
- **支援**（华佗）：不在场上出现，只以 HUD 援环和飘字表现（减员 1 秒后救回 30%，至少 1 人，冷却 12 秒）。

### 4.3 部曲与齐射

- 弓手可见数量 = `min(12, 兵力/3)`，每排 4 人，行走 2 帧 + 拉弓（齐射计时 > .28）+ 放箭帧。
- 齐射每 1.6 秒一轮；连弩每轮 3 连射，间隔 .12 秒；箭数 `clamp(ceil(兵力/5), 2, 8)`；箭矢按目标位置提前量飞行，命中才结算；对敌将 ×.5。
- **兵力牌**：数字 24，牌旁武装标签（弓 / 火箭 / 连弩），换装时闪亮；有坐骑时左侧加坐骑徽记（牌宽 +16），横移 `|heroV| > .4` 时扬尘。
- 兵力归零：本局失败，停止攻防，预览 3 秒后重开当前状态。

### 4.4 辕门（成对，x = ±0.5，门宽 0.88，门高 `UNIT.gateH = .98`）

- Z1 只显示旗色和轮廓，不显示数字。
- 数字接近兵力牌时**停靠**在牌上方：`dockY = troopY − 23 − size/2 − (有副标 ? 18 : 0)`，结算前不淡出。
- 通过判定 `|dx| < .46`。**进入的门**：数字 .35 秒飞入兵力牌；**另一扇**：.3 秒淡出。
- 援兵门 + 太平要术：额外 +10%（至少 +1），副标显示「太平 +N」。

### 4.5 箱（4 类，靠外形区分；击碎后换开箱帧）

| 箱 | 血格 | 标签「名·内容」 | 效果 |
|---|---|---|---|
| 粮车 | 6 | 粮车·援兵 +6 | 兵力 +6 |
| 兵器匣 | 10 | 兵器匣·升阶 / 兵器匣·兵器名 | 不同兵器：换兵器、阶位保留、亮兵、图标飞入；相同：阶位 +1、菱形闪金；已 3 阶：援兵 +4。第二圈起只开当前兵器 |
| 军械箱 | 8 | 军械箱·换火箭 / 换连弩 / 援兵 | 部曲武装 弓 → 火箭 → 连弩，标签闪亮、下一轮齐射即生效；已连弩：援兵 +4 |
| 宝匣 | 14 | 宝匣·宝物名 | 槽空：试用并立即生效（赤兔：出现坐骑徽记和扬尘，横移变快）；槽被别的占：记入结算入库、槽闪；相同：援兵 +4 |

常规路线（`courseLen 256`）事件点：14、30、50、66、墙 80（长 26，封一侧）、90、112（宝匣·赤兔）、126（兵器匣·偃月刀）、142、158（兵器匣·蛇矛）、172、186、200、214、228、242。密集态 `courseLen 120`，6 对门。

### 4.6 固定墙段（木栅营垒）

- `WALL = {inner .06, outer .95, step 1.6, gap .13}`：栅柱从路中 .06 排到外侧 .95，每 1.6 世界单位一组；墙内地面贴花。
- 只挡人马，刀气和箭矢照常越过。经过期间主将被夹在 `inner − .20` 之外，只能走另一半路面；撞墙时抖动并提示。

### 4.7 敌将（吕布，将台位于 z = 17，路中）

- **将台**：程序绘制土台 + 铜沿（`drawBossDecal`）；收势时出现「破绽」光环与「破绽 ×2」标签。
- **循环**：`idle 1.1 → warn 1.2 → strike .45 → rec 1.5`，血尽后 `spent 1.4 → yield`。
  - 预警：右缘 56×200 竖幅位于 Z2 中部，地面显示目标带（±.15，判定容差 .05）；
  - 出招：刀气到 z ≤ .2 时判定，在带内中招 −10 人、红闪震屏；带外「闪开」；
  - 收势：受到伤害 ×2；
  - 承伤系数 `BOSS_DMG = .30`；大伤害后 .22 秒显示受击帧 `g_lubuHit`。
- **血条与靠旗**：5 段血条带拖尾；背后 4 面靠旗，每失 25 血断一面，断旗飘落。
- **亲兵**：每 3.2 秒 3 名，2 血；收服时转身退走并淡出。
- **收服**：力竭帧 1.4 秒 → 帅旗倒下、白旗升起 → 「降」印 2.2 秒 → 敌将牌变蓝「已收服 · 画戟本主」，标签「收服」，战斗结束。

## 6. 层级与标签规则

- **渲染顺序**：背景 → 地面 → 世界（按深度排序；墙内贴花、将台贴花）→ 刀气 / 枪气 → 箭矢 → L6 世界标签 → L7 HUD → 覆盖特效（图标飞入、印章）→ 预警竖幅 → 提示条。
- **数字高于特效**：门数字、箱名 / 血格、兵力牌、飘字都在 L6，任何刀光都不会盖住数字。
- **提示条**（Z4）：y = z4y + 8，高 32，居中，最宽 280，body 14，显示 1.6 秒，按优先级排队：中招 bad 3 > 宝物 / 收服 gold 2 > 援兵 / 闪避 good 1 > 普通 info 0。
- **反馈原则**：每个提示都对应一次真实状态变化（兵器 / 阶位 / 武装 / 槽状态 / 兵力 / 敌将阶段），且在世界或 HUD 上有对应的可见变化；不存在「只弹提示」。

## 7. 每帧自检（`window.__layoutReport()`，面板实时显示）

1. HUD 各控件的底边不超过 hudBottom，控件之间互不交叠；宝物槽、援环不压路面，也不与 HUD 行交叠。
2. 预警竖幅不压 HUD，且位于 Z2–Z3 内。
3. 提示条位于 Z4，且在底部安全区之上。
4. 所有文字字号都在 §3 的字号阶内；Z1 中不出现门数字。
5. 门数字之间、箱名 / 血格与门数字之间、兵力牌与门数字之间互不重叠；未结算门数字不被淡出、不压兵力牌；印章不压 HUD。
6. 主将锚点位于 Z3。

# 实现边界

- `assets/scripts/core/model.ts`：与 Cocos 无关的固定60Hz规则。人数真实值0–256，绘制计数≤48，箭伤害取真实人数。横移以连续坐标和速度上限执行；按过线时中心x决定门，一排Set防重复。
- `assets/scripts/core/levels.ts`：三个关卡配置、对白、结算、线索及来源。前进46/60/74秒后停步守关，守关无时间上限。模型可通路线总时长约60/76/90秒，不等于全部玩家通关时间。
- `assets/scripts/core/save.ts`：只持久化cleared/clues/best/settings。JSON校验失败恢复默认并提示，写入异常保留内存游玩状态。
- `assets/scripts/Platform.ts`：微信/浏览器存储、Cocos音频与生命周期、微信轻震动。后台冻结，返回必须点继续。无服务器/账号/广告/支付/排行榜/遥测。
- `assets/scripts/Game.ts`：Cocos界面、纹理、动作反馈、单指输入。Cocos已将桌面鼠标模拟为触控，只注册触控监听，避免同一输入重复接收。世界节点有界复用；切换非战斗页面销毁本轮节点，声音组件全局复用。
- `assets/scenes/Journey.scene`：源自本机3.8.8官方2D空场景，挂载Game组件；未另写网页游戏或平台运行壳。
- `tools/build.mjs`：直接调用已安装的3.8.8编辑器；退出36才视作构建成功。微信AppID明确游客占位，构建后不符即报错。真实项目接入须有用户小游戏身份。
- `tools/serve.mjs`：只向127.0.0.1:43187提供build/web-mobile的静态引擎产物，无业务服务。
- `__YLCG__.snapshot()`：只读诊断接口，用于记录节点、帧率和状态，无修改人数、获胜、跳时间或解锁入口。浏览器验收通过实际鼠标/触摸输入驱动。

## 配置与公平性
+12相对于首关8兵的×2更好，因此乘法并非永远最优。后续收益路径安排了木栅、山石与预告墨影；玩家要提前选路和对准射击。所有接触折损在屏幕注明，可绕行。木栅是可破坏物，石头只挡箭不受损；粮车只是随行视觉，不参与额外失败判断。

## 未接入的范围
没有任何账号、广告、内购、体力、商城、每日任务、装备、排行榜或服务端。史料URL只作文字出处，没有产品联网读取。

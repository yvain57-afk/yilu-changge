## 存档与版本边界

新旧成绩隔离，不把旧三关通关伪造成新十关奖励。旧收藏留在原键和备份中；新模式解锁遵循新版十关表。音乐始终关闭，五路音效沿用已有平台实现。

本轮发现并修复了 Cocos 节点池复用时的纹理失效：对同一个 SpriteFrame 修改 texture/rect 后，Sprite 的同对象 setter 会早退；现在在改变切片前解除绑定并重新绑定，更新实际纹理及 UV。失败的前段实录保留在 `pre-texture-fix-partial/`，不作为最终交付录像。

旧平台存档影子键保护另以真实 Cocos 的五类旧记录→设置修改→开战→暂停退出→重载定向验证，见 legacy-native-save.json。自然录像不是这一旧档夹具测试的替代证据。

另一个跨关渲染回归来自 Sprite.onEnable 自动恢复默认 assembler；GroundMesh.draw 现在在重新启用后恢复自定义网格及顶点分配。四次真实退出/重入断言通过。含该问题的十关逻辑成功录像保留在 pre-ground-fix-ten，不作为最终视觉交付。

最后收尾补充：整备页显示真实匣内兵器池、分页避让人物和宝物、主将兵法切换；地图不提前显示未开关卡名称。木牛流马粮车提示改为与实际+9一致。动态图集会重写小纹理的UV，手动切片的NativePaint和GroundMesh已禁止再次进入动态图集，修复菜单金按钮裁切。最终 UI/兵法/小纹理变化以 final-ui-control.mp4 定向补录，不把该夹具视频混称自然十关。

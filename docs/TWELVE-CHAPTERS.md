# 十二章文字总纲

所有主角为原创普通人，敌人统一是残页失序的墨影。每章是独立书页，跨时代明示；首版仅开放战国、西汉、唐三关，其他章节只在本总纲中规划，不在游戏中放空入口。下列情节是创作方向，不是已证实的历史事件；服饰器物细部随未来章节另做史料核验。

|章|人物愿望|玩家行动|场景方向|线索主题与史实边界|
|---|---|---|---|---|
|上古·火种未熄|少年希望夜归的家人看得见村落|护送火种，沿河岸寻找归路|土色聚落、河滩、星夜|把钻木取火等文化传说明确标作传说；可考部分仅取遗址出土的居址、陶器与用火痕迹，不将传说人物对应某件器物或精确年代|
|先秦·渡口送简|阿禾想把牵挂带给对岸阿兄|护送竹简穿过渡口|战国楚地意象、青山水岸|竹简书写与保存；送简人物与路线虚构，纸兵是史书幻想|
|秦·名在册上|小吏之女想确认远行父亲已抵达|找齐遗失的行程记号，送回一册记录|县城道口、简牍案桌|简牍中的普通人与行政记录；不能把秦简个例泛化为每个家庭经历|
|汉·关道护粮|阿麦盼远行者赶上热饭|沿西汉关道送粮车到灶边|土岭、驿置意象、粮车|简牍中的接待与粮食出入，制度背景和虚构送粮事件分开|
|魏晋南北朝·渡江旧碗|迁徙的祖母只愿一家人再坐到同桌|帮家人找回包着旧碗的行囊|渡船、江雾、临时歇脚棚|迁徙与生活器具；不以单一朝代、地域形象概括这段多政权时期|
|隋·河岸一灯|看船的小孩想等父亲收工一起吃饭|沿岸传递停泊消息，领人归岸|运河意象、堤路、夜灯|水路交通及普通劳动；不虚构具体工程人数或把后世桥形当隋制|
|唐·长街寻信|小满怕家书失落，让亲人误以为无人等候|在长街拾信送信|青瓦街巷、暖灯、秋树|书信问候、报平安与封题，原创信文不是文物释文|
|五代十国·隔岸借盐|摆渡人想让断了往来的邻里吃上一顿安稳饭|带一小包盐和口信过岸|江南水口、短桥、屋檐|割据时期的区域差异与日常交流；背景限定具体地域后再考证，不把乱世写成人人争战|
|宋·雨前收摊|做饼的母亲想早些收摊陪孩子|穿过巷道，把落下的食盒送回摊边|市井雨檐、桥街、店招|城市生活与市场，注意北宋/南宋和城市差异，不把画卷所有细节直接套作常态|
|元·远路同席|车队里的年轻人想学会向旅伴表达谢意|送一份饭、找一位掉队的同伴|驿路、车队、路边歇脚处|多语交往与交通；角色不用族群刻板外观区分，不让任何族群充当敌人|
|明·匠人的回程|学徒想赶在师傅回家前送还工具|找回装工具的布包，护送到河边作坊|窄街、木作坊、码头|手工业劳动和日常工具，器形依具体时地核验，不神化工艺或杜撰发明年代|
|清·窗前一碗面|远归的人想知道母亲还记不记得自己的口味|循着邻里口信找到旧居|街坊、院门、炊烟|普通人家书与生活记忆；辨别地区、时期，不让单一服装符号替代整个时代|

最后一章不宣称历史到此结束。书合上时写：「名字也许没有留下，牵挂仍在路上。」后续是否制作各章另立范围，本轮不加入锁定空关卡。

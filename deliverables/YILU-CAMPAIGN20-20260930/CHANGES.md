# 二十关扩展：实际改动

本轮在现有 dirty 工作区增量实现；没有重置、清档、提交、推送或发布。iOS Native / Cocos Creator 3.8.8；旧 c01–c10 身份、收藏及51个已认可音效文件保留。

- **20关与成长**：后十关实接正式路线、名将、Boss、首奖、场景与结算；总计42人物、16兵器、18宝物。第10关成为上篇，第20关终局。每双关60军功与唯一印章，首通+里程碑基础总1930军功；挑战路线另记最多4军功/局。
- **可搭配兵器**：整备选择已拥有的出征兵器，局内1阶入场并保留永久等级。同兵器匣升阶，异兵器匣须走同路拾取；胜利页可试用新兵器并恢复原选择。随军仍最多2名、支援1名、宝物3槽。
- **难度与威胁**：轻兵外的盾兵、弓手、骑兵、旗手、近卫、机关接入真实HP/攻击/预警。固定双关参数，不随玩家装备暗中涨血。预警含0.3秒反应及前线占位/墙段可达性，冲锋与箭矢实际运动；同源战损去重、统一减伤及真实损失恢复。
- **门与选路**：每章两次安全/挑战路线，挑战可获得额外补给和军功。射击门按本章额外+6至+10封顶，同一发招子攻击去重，画面值与到达结算同源。
- **奖励演出**：持久化事务先完成，再显示兵器/人物/宝物舞台。多人/物品同屏两排；0.8秒后可跳过。偶数关升旗盖章，第10关延伸下篇；失败从实际兵损来源生成建议。崩溃恢复待播奖励，不重复发放。
- **山河地图**：五段独立手绘山水纹理、城寨/营地/水寨/关隘、状态旗与十印章；真实拖动、定位、详情与锁关判断。最多3段地图缓存，文字单独渲染，首次征服换旗和道路延伸。20关后可选精兵、少援、双将重游军令。
- **旧档兼容**：FORMAL_KEY不变；旧schema2迁移为3，保存精确原始字符串、旧荣誉与未知字段。旧8关继续9关，旧10关开放11关；仅补发已到里程碑的新权益，可靠写入回读失败时保留原记录。
- **实际资源和音频**：新增角色/敌军/兵器动作图集、图标、地图纹理已进resources与manifest。新增6兵器18发招变体及3机关装填声；保持3声道、事件身份、暂停和后台清理。素材试听与实际游戏系统录音分开。
- **遮挡与预算**：近身门体淡化，门值优先避让箱牌；连续门分层；长兵器保留显示边距；高兵力阵型整体平移与随军纵深分离。远景敌军身体延后提交，模型实体/攻击保留，近景与预警不隐藏。

## 实证与边界

最终运行结果以 REPORT.md、acceptance.json 及其中指向的构建/运行指纹为准。早期预检截图和源码矩阵保留原始指纹，不能当作最终版本画面。960组模型矩阵来自冻结参数后、最后局部阶段清危与表现修复前；对应局部回归及最终原生主线另有记录。脚本通过率不是人类胜率，模拟器帧间隔不是iPhone GPU性能。

具体资源限制不藏在“审美待验”中：新人物每角色只有一个跑动姿态；新坐骑自带长枪，未制作16种兵器骑乘组合；盾兵蓄势红缨触源图顶边1像素。未测试的设备项目在acceptance独立标记。

# 十三类真实页面

所有链接打开当前 Cocos 真实页面；隔离入口仅使用内存示范存档，正常入口另有验证。原生编译与手机验收分列。

- **U01 营地**：真实进度、当前出征兵器、永久等级；独立品牌插画。操作：继续/地图/图鉴/设置。四尺寸检查通过；手机待验。
- **U02 山河地图**：五区域、二十关、已克进度、当前城、全局里程碑。操作：滑动/定位/展开保持地图位置/出征。四尺寸检查通过；手机待验。
- **U03 整备**：实际兵器等级、局内阶位、随军/支援、三槽、兵法。操作：四固定页签/选择与详情分离/完整编组。四尺寸检查通过；手机待验。
- **U04 军中图鉴**：42人物、收/访/盟/遇/未遇、真实收藏。操作：两列/筛选/分页/详情。四尺寸检查通过；手机待验。
- **U05 人物详情**：全身素材、真实经历、关系、能力、共鸣。操作：资格约束/替换确认/原位置返回。四尺寸检查通过；手机待验。
- **U06 兵器宝物详情**：当前与下级伤害增益、真实军功成本、能力与槽。操作：升级/选择独立/不足、满级、未获状态。四尺寸检查通过；手机待验。
- **U07 胜利与重游**：真实城池/军旗、归营兵力、军功、局部下一关与全局进度。操作：查看/试用/整军；战斗HUD不再留在结算。四尺寸检查通过；手机待验。
- **U08 获得**：唯一奖励集合、主奖一次、军功单列。操作：0.3秒门槛/详情返回/保存和恢复。四尺寸检查通过；手机待验。
- **U09 双关里程碑**：第10关上下篇、9项真实奖励、印章；第20关终局。操作：紧凑托盘/全部可达/收下只确认演出。四尺寸检查通过；手机待验。
- **U10 失败**：实战归因字段与真实军功，不编造星级。操作：调整编组/再战。四尺寸检查通过；手机待验。
- **U11 暂停与确认**：真实战斗暂停与当前编组。操作：继续/重试/退出/取消/长确认内容裁切。四尺寸检查通过；手机待验。
- **U12 设置**：本地设置、实际构建与指纹、兼容降低动态。操作：持久化/写失败回退；音乐保持关闭。四尺寸检查通过；手机待验。
- **U13 加载与异常**：加载/资源失败/存档失败/独立安全层/旧档迁移。操作：重试不重复发奖、菜单故障全帧清理。四尺寸检查通过；手机待验。

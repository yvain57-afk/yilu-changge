## 为什么截图看起来弓手骑马

实际旧版本截图 `before/pixels/before-stationary-t25.png` 的状态记录显示：骑兵 121/122 与弓手 143/144、145/146 被固定到同两个脚点 `(x=.305,z=5)` / `(x=.535,z=5)`。三个单位叠在每个脚点，较大的马遮住步行弓手。同一记录中“骑兵”“弓手”标签也分别完全共用 `(229.533,492.211)` / `(260.099,492.211)` 屏幕坐标，所以观者会把弓手标签读成马的身份。

这证明修复对象是实体的跟随/堆叠与标签绑定呈现，不应通过把正确弓手图换成另一套角色来掩盖。当前没有修改 MANIFEST，也没有改变已认可资产。

## 仍存在的动作与比例边界

所有 `bh` 仍由旧切片脚本按“整帧高度 × 0.88”初始化，未经过逐姿态躯干标定。旗帜、抬高的兵器与马匹扬蹄会改变整帧高度，因此不能把当前数值称为准确身体尺寸。每兵种只有一个 `run` 帧，完整的交替步态资源仍缺。机关 `rel` 源帧还含一枚独立出膛弩矢，应与后续运行弹体视觉核对，避免双重箭矢。

# 一页操作说明

1. 当前已启动本机试听页：http://127.0.0.1:43209/ 。页面分别提供最终资源试听、普通实录、密集实录；点击播放即可。
2. 关闭服务或重启电脑后，可双击同目录“打开试听页.command”重新启动。若提示端口占用，说明已有服务，直接打开上述地址。
3. 十兵器每件 5 秒一组，前三秒各播一个变体。试听统一到 -34 LUFS 以保留瞬态，可调播放器音量。该轨是资源试听，不能当游戏内证据。
4. 两段视频都含实际游戏进程输出的系统音轨；录的是原生模拟器 DEBUG 隔离样段，无后期资源配音。约25秒暂停两秒后恢复，后面继续换武器。
5. 已安装最终 Debug 到“Yilu Native Final”模拟器。正常启动游戏不带 --yilu-review 参数即回到正常菜单；录制夹具不写正式玩家存档。
6. 构建在 builds/：模拟器 Debug 可安装；iPhone Release 未签名，不能直接发给朋友装机。手机没有被本轮替换。
7. 真机扬声器/耳机、静音和后台恢复尚待签名安装后检查；具体听验请关注十种兵器能否区分、轻重音量、火箭尾音是否像轻燃烧。
8. GPT 核查先读新快照的 acceptance.json，再核对 REPORT.md 哈希、检查指纹和两段视频帧。MCP 读取帧不等于听过音轨；本轮实际状态在 REPORT.md。

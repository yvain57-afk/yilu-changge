## 安装与复建

本机专用模拟器“Yilu Native Final”已装最终构建、正常首页，保留实际十关已通档。视觉夹具仅Debug内存存档，Release不可启用。旧测试模拟器和源端玩家存档未删除。

已有arm64 iOS27模拟器启动后，解压模拟器包：

```sh
xcrun simctl install booted /absolute/path/CocosGame.app
xcrun simctl launch booted com.yvainair.yiluchangge
```

复建环境：macOS，Cocos Creator3.8.8安装于`/Applications/CocosCreator/Creator/3.8.8/CocosCreator.app`，Xcode27/iOS27SDK，Node依赖按package-lock.json。

```sh
npm ci
python3 tools/build-ios.py
npm run typecheck
npm test
python3 tools/build-ios.py --device --release --team YOUR_TEAM_ID
```

原生Xcode项目`build/ios-simulator/proj/一路长歌.xcodeproj`，scheme `CocosGame`。Bundle ID `com.yvainair.yiluchangge`固定，最低iOS16只是构建参数，低系统未测。iPhone包需匹配签名设备与有效开发授权，不能直接扫码分发给任意朋友。

# 首页整体调节

启动 `npm run edit:home`（原 `edit:home-button` 命令仍可用），打开 http://127.0.0.1:43228/ 。服务只监听本机。

## 可以调整什么

普通首页有 11 类可选内容：人物图、游戏标题、进度文字、设置按钮、关卡文字、兵器图标、兵器与等级文字、成长提示、出征按钮、地图按钮、图鉴按钮。有待领取奖励时，还会显示可编辑的待领奖按钮。

开启编辑模式，点选画面中的内容，或用右侧列表选择。拖动虚线框调整位置；滑块/数值输入调整宽、高、字号；文字框修改标题、说明和按钮文案。图片不显示字号/文字项。小屏和长屏都可预览；较窄的 Codex 面板也并排显示画面与调节项。

文案中的 `{通关数}`、`{关数}`、`{地点}`、`{关名}`、`{兵器}`、`{等级}`、`{成长提示}`、`{出征文案}`、`{关卡提示}` 会随真实游戏数据更新；也可改为固定文案。修改文案不改变通关数、解锁、编组或按钮功能。

试调只影响预览。点击“保存首页”才写入 `assets/scripts/formal/HomeEditorConfig.ts`，下次正常构建使用。“还原所选”清除选中内容的覆盖，“还原整个首页”清除本工具的所有覆盖；二者仍须保存才写回项目。`HomeButtonConfig.ts` 中此前用户保存的按钮基线继续保留，不由新版工具改写。

关闭编辑模式可以试玩按钮，点面板“回到首页”继续调节。位置、尺寸是相对当前基线的设置；控件可互相覆盖，调整后请查看是否遮挡。高度会限制按钮文字可用空间；文字区域的高度不等于字号，文字大小请用字号调节。

## 范围与实现

目前覆盖首页，整备、图鉴详情、战斗 HUD 等其他页面尚未接入该编辑器。背景素材替换、动画和碰撞不在此范围。

预览复用 `build/music-shanhe-web/` 的现有引擎/美术，在内存中重新编译 FullMenu 与相关 Home 模块；不复制底包、不生成新构建。它是首页开发预览，不代表所有源码的最新全量构建。修改其他模块或素材后需要更新对应底包，iPhone 仍需正常构建/更新并实测。

桥接仅在 Debug、本机域名、显式调节参数及 `UI:` 内存隔离场景启用。保存校验范围/文案变量，用文件摘要避免覆盖其他操作的新设置。未新增依赖或购买插件。

检查：`npm run test:targeted -- tests/home-button-tuner.test.ts` 和 `npm run typecheck`。本轮 20 项相关检查与类型检查通过；已实测点选、人物拖动缩放、标题/按钮改文案、保存刷新及改文案后真实地图按钮功能。
